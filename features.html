Features

Everything an applied analysis needs, in one place

Type a command or fill a dialog box: AURA writes every action as a command, so the whole analysis can be run again. Each command has a help page with examples you can run.

Data management

A workspace of datasets, never overwritten in silence

Open Stata, SPSS, SAS, Excel and CSV files; keep several datasets in the Workspace and switch between them. merge, reshape and collapse write their result as a new dataset, so the original is kept. Labels, value labels, formats and notes travel with the data.

use "bkf98I.dta"
bysort zone: summarize exppc size
egen mean_exp = mean(exppc), by(zone)
label variable mean_exp "Mean spending in the zone"
tabstat exppc size, by(zone) stats(mean sd p50)

Estimation

Regression, panel and instrumental variables — with their tests

Linear regression, logit, probit and poisson; fixed, random and between effects, random effects by maximum likelihood and the population-averaged model, with the Hausman test; two-stage least squares, LIML and GMM. Robust and clustered standard errors — in two dimensions, or Driscoll-Kraay, for panels —, weights (also as expressions), factor variables and interactions (i.zone, c.size#c.size), collinear variables left out with a note. After the estimation: predict, margins, test, lincom, nlcom.

regress lexp size i.zone c.size#c.size, vce(cluster psu)
logit poor size i.zone [pw=weight]
predict p_poor
quietly xtreg lexp size, fe
estimates store fe
quietly xtreg lexp size, re
hausman fe .

Tables of results

Models side by side, ready for the paper

eststo stores the models, esttab writes them side by side: coefficients with stars, standard errors or t statistics, the statistics you choose, variable labels. To the screen, or to a file in LaTeX (a document that compiles as it is), HTML, RTF for Word, CSV or Markdown. estpost turns summaries and tabulations into tables of the same kind.

eststo: regress lexp size
eststo: regress lexp size i.zone
esttab, se star(* 0.10 ** 0.05 *** 0.01) label
esttab using "models.rtf", replace

Survey data

The design of the survey, in every standard error

Declare the strata, primary sampling units and weights once with svyset — a .dta file brings its own design. svy: then gives means, totals, ratios, proportions and regressions with linearized standard errors, by subpopulation or by group if needed — also by quantile groups of exactly equal weight, the estimated cut points taken into account in the standard errors; bootstrap resamples the design.

svyset psu [pw=weight], strata(strata)
svy: mean exppc size
svy: proportion poor
svy: mean exppc, over(zone) nquantiles(5)
svy, subpop(zone == 1): regress lexp size

Graphics

Publication graphs, edited with the mouse

Two-way plots in layers, histograms, densities, bars, pies and interactive 3-D surfaces. In the Graph Editor, click a part of the graph — a title, the legend, an axis, a curve — to move it or open its own window of options; add texts, lines and arrows. graphmerge joins graphs into one figure sized for a page; a right click copies a graph to Word as a vector drawing.

histogram exppc if exppc < 300000
twoway (scatter lexp size) (lfit lexp size)
graphmerge -2 -1, cols(2)
graph export "figure.emf"

Scripts and reproducibility

Run it once, run it again tomorrow

.aur scripts with loops, conditions, macros and matrices, in an editor that flags problems as you type. Every action of a menu or a dialog box is written as a command in the Review panel. A log keeps the session; an html log keeps its graphs too.

log using "session.hlog", replace
foreach v of varlist exppc size {
    quietly summarize `v'
    display "`v': mean " %9.2f r(mean)
}
log close

Extend AURA

Your own commands, dialog boxes and packages

A new command is a small Python .auru file: it reads the data and the options, and writes its results like any command. Dialog Studio designs its dialog box; the module editor tests it, and its AI assistant can draft it from a description and check it against your numbers. Publish a package that others install with pkg install.

  • Help pages in a simple markup, with examples users run with a click
  • Packages with versions, updates and their own menu entries
  • The Python scientific stack inside every module
