The DAAP Reference Manual — Theory & Implementation

Distributive Analysis AURA Package

1 Introduction

The Distributive Analysis AURA Package (DAAP) is a package for AURA — the Applied Unified Research Analytics platform — designed to help researchers and policy analysts conduct distributive analysis. It is built to:

  • estimate the most widely used statistics — indices and curves — for the analysis of poverty, inequality, social welfare, equity, polarization, redistribution, targeting and pro-poor growth;
  • estimate the differences in such statistics between two distributions;
  • estimate standard errors and confidence intervals that take full account of the survey design;
  • support analysis over more than one distribution;
  • perform the most common decomposition procedures (by groups, by income sources, by components);
  • check the ethical robustness of distributive comparisons; and
  • unify the syntax and the parameters across all of these procedures.

Every estimation is available both as a command and as a dialog box. When a dialog is used, the equivalent command is generated and echoed in the Review panel, so any analysis is fully reproducible — it can be re-run, edited, or saved as a script.

1.1 Why DAAP in AURA

DAAP runs inside AURA, a Python-native analytics platform, and inherits its facilities — several of which are what make distributive analysis with correct inference convenient:

  • The survey design is a first-class object. Declare it once with svyset (sampling weight, strata, PSUs, optional FPC) and inspect it with svydes, which describes the strata, the number of PSUs and observations, and the resulting degrees of freedom. Every module then reads the current design and reports design-based standard errors automatically — the analyst never re-specifies it per command.
  • More than one distribution at a time. AURA keeps several datasets in memory at once (the Workspace), so comparisons need no merging or reshaping. Two-distribution modules pair their inputs with distset, which also records whether the two distributions are the same dataset (statistically dependent → the difference’s covariance term is used) or different datasets (independent → the variances add). See §2.2.3 and, for inequality, §3.1.3.
  • Learn by doing — demos. Each module ships interactive demos (demo <module>) that load example data and run a worked analysis you can step through.
  • Rich, linked help. help <module> opens a formatted help window; its Theory & Implementation link opens this manual at the matching section.
  • Reproducibility by construction. Every command — typed or generated by a dialog — is echoed to the Review panel and can be saved and replayed as a script (.aur).
  • Point-and-click and scriptable. Dialog boxes for every module coexist with a full command language (macros, scalars, matrices, stored results r()/e()), so casual and advanced use are both first-class.
  • Publication-ready output. Results render as clean tables, export to .xlsx, and feed AURA’s graphics (Lorenz, concentration, poverty and pro-poor curves, …).
  • Free, open and offline. AURA and DAAP are open-source (GPLv3) and run entirely on the local machine — no network and no licence server.

1.2 How to read this manual

The manual pairs, for every module, what is estimated (the theory) with exactly how DAAP computes it (the estimator and its standard error). The aim is reproducibility: the numbers — point estimates and design-based standard errors — should follow from the formulas alone.

Chapter 2 — Foundations is a self-contained chapter, separate from any single command, that collects the material every module reuses: the notation and sampling framework, the design-based inference machinery (linearization, the stratified ultimate-cluster variance, the delta method) and the shared numerical primitives (weighted quantiles, kernel density, the rank-dependent Gini linearization). The later chapters each treat one theme; a module section states its estimand, then gives its estimator and the linearized contributions behind its standard error, referring back to Chapter 2 for the shared steps rather than repeating them. From a module’s help window, the Theory & Implementation link opens this manual at that module’s section.

1.3 Installing and loading DAAP

DAAP is distributed as an AURA package. Once installed and enabled it adds a DAAP menu to the menu bar, grouping the modules by theme (Poverty, Inequality, Polarization, Redistribution, …). Packages are managed from Tools ▸ Manage Packages or with the pkg command (pkg install, pkg enable, pkg update). DAAP requires a current version of AURA and its scientific stack (numpy, scipy, pandas).

1.4 Data and the survey design

DAAP reads the data files AURA supports (.aura, .dta, .csv, .xlsx); a dataset is loaded with use "<file>". Before analysis a dataset should be initialised by (i) labelling variables and the values of categorical variables, (ii) declaring the sampling design, and (iii) saving it. The design — sampling weight, strata, primary sampling units (PSUs) and an optional finite-population correction — is declared once with svyset,

svyset psu [pweight = hw], strata(stratum) fpc(fpc)

and inspected with svydes (a description of the strata, the number of PSUs and observations, and the degrees of freedom). Every DAAP module then reads it from the current design and reports design-based standard errors (§2.2). A .dta file that already carries a survey design has it imported automatically. When no design is declared, DAAP assumes simple random sampling.

1.5 Main variables for distributive analysis

  • Variable of interest / welfare variable. The variable that captures living standards — income or expenditure per capita or per adult equivalent, calorie intake, an anthropometric score, household wealth, and so on.
  • Size variable (hsize). The “ethical” or physical size of an observation — how many individuals a household observation stands for. Weighting by the sampling weight times the size makes an index individual-level (every person counts once).
  • Group variable / subpopulation. A categorical variable used to restrict the analysis to a subgroup (a rural area, female-headed households, …) or to break a result down by group.
  • Sampling weight. The inverse of the sampling probability, set when the design is declared.
  • Poverty line. For poverty modules, the threshold below which a unit is counted as poor — a constant, a variable, or a share of a reference point.

1.6 Invoking commands and accessing help

A module is run by typing its command in the command window, for example

ineq pcexp, index(gini)

or by opening its dialog from the DAAP menu, filling in the fields and submitting — the generated command is echoed to the Review panel. Full syntax and options for a module are shown by help <module> (e.g. help ineq); the help window’s Theory & Implementation link opens the relevant section of this manual.

Anatomy of a single-distribution dialog — ipov. The figure below is the ipov dialog. It is typical of every one-distribution DAAP command: a few option controls at the top, the variables of interest in the middle, and the command-specific settings (here the poverty line) below, with a standard footer.

  • ① Tabs. Main (variables and the poverty line), Confidence Interval (the level and the interval type), Results (display decimals and optional Excel export).
  • ② Poverty index and options. The index — FGT, EDE-FGT, Watts or SST — the FGT/EDE parameter α, and Normalised vs the raw gap (§8.1.1). α and Type are disabled for Watts/SST.
  • ③ Welfare variable(s). The variable of interest y (income, expenditure, …); several can be listed to estimate poverty for each at once.
  • ④ Size variable. The household size (hsize) — weighting by it makes the result individual-level.
  • ⑤ Group variable(s). An optional breakdown: a section per group plus a Population row.
  • ⑥ Poverty line — Absolute. A fixed number or a per-household variable — an exogenous line, so the standard error is the plain ratio SE (§8.1.2).
  • ⑦ Poverty line — Relative. A fraction (% of) of the mean, median or quantile, taken over the whole population or within each group — an estimated line, so the standard error uses the delta method (§8.1.2).
  • ⑧ Footer. OK runs and closes; Submit runs and keeps the dialog open for another try; the ⧉ button copies the generated command to the Review panel (so the point-and-click analysis is reproducible). The ? and ⟳ buttons open help and reset the fields.

1.7 One or two distributions

Most modules work on a single loaded distribution — the dataset in memory, from which the user names the variables. Two-distribution modules (the differences commands) compare two distributions declared with distset; each may be the loaded dataset or one on disk. Two distributions are treated as statistically dependent for inference when they come from the same dataset, and as independent otherwise — a distinction that determines how the standard error of the difference is formed (§2.2.3, and §3.1.3 for inequality).

Anatomy of a two-distribution dialog — dipov. The dipov dialog (below) estimates the difference in poverty between two distributions. It shows the pattern of every difference command: the same options at the top, then two distribution selectors side by side, each naming its own dataset, variables and poverty line. On OK it emits a distset pairing followed by the dipov command.

  • ① Poverty index and options. The index, α and Type — applied identically to both distributions.
  • ② The two distribution selectors. Each names a Dataset (any dataset open in the Workspace), its Welfare and Size variables, an optional Condition (to restrict to a subgroup), and — crucially — its own poverty line. Distribution 1 and Distribution 2 may be the same dataset (two periods conditioned differently, or two variables) or two different datasets.
  • ③ Per-distribution poverty line. Absolute or Relative, set independently for each side.
  • ④ Group breakdown. An optional decomposition of the difference by a group variable, from distribution 1.
  • ⑤ Footer → distset then dipov. OK emits a distset that pairs the two distributions, then the dipov command. The pairing decides the inference: same dataset ⇒ statistically dependent (the covariance between the two estimates is used), different datasets ⇒ independent (the two variances add) — see §2.2.3. The ⧉ button copies both commands to Review.

2 Foundations

  • \(L\): the number of strata

2.1 Notation and the sampling framework

  • \(g\): a population subgroup

DAAP treats a sample of survey observations (typically households) drawn under a complex design. The core symbols are:

Symbol Meaning
\(y\) the variable of interest (income, consumption, …)
\(i\) observation index, \(i = 1,\dots,n\)
\(y_i\) value of \(y\) for observation \(i\)
\(hw_i\) sampling weight of observation \(i\)
\(hs_i\) size of observation \(i\) (e.g. household size; via hsize)
\(w_i \equiv hw_i \, hs_i\) the effective weight used by the indices
\(W \equiv \sum_{i=1}^{n} w_i\) total effective weight
\(s\) stratum index, \(s = 1,\dots,L\) (\(L\) strata)
\(m\) primary sampling unit (PSU) within a stratum
\(g\) population subgroup
\(d_i\) subpopulation (domain) indicator (\(1\) if \(i\) is in the domain, else \(0\))
\(n\) sample size

The distinction between \(hw_i\) and \(w_i\) is deliberate. Distributive indices are defined over individuals, but sampled at the level of observations (households). Weighting each household by \(w_i = hw_i\,hs_i\) makes the index individual-level (every person counts once); the sampling variance, however, is generated at the observation level and so is driven by \(hw_i\) and the design (strata / PSUs) — §2.2 keeps the two roles separate.

The estimand of most indices is a functional of the population distribution; its estimator replaces population sums by weighted sample sums. The running example is the mean,

\[\hat\mu \;=\; \frac{\sum_{i=1}^{n} w_i\, y_i}{\sum_{i=1}^{n} w_i}.\]2.1

When no survey design is declared (svyset), DAAP assumes simple random sampling: one stratum, each observation its own primary sampling unit, \(hw_i \equiv 1\).

2.2 Design-based inference

  • \(\theta\): the index (parameter) estimated
  • \(\hat\theta\): the estimator of the index, computed from the sample
  • \(M_s\): the number of PSUs in stratum \(s\)
  • \(\widehat{\mathrm{SE}}\): the estimated standard error

2.2.1 The linearization principle

Almost every DAAP standard error is a Taylor linearization (the influence-function method). An estimator \(\hat\theta\) that is a smooth function of weighted totals is approximated, to first order, by a weighted total of a per-observation linearized contribution (or influence) \(a_i\):

\[\hat\theta - \theta \;\approx\; \sum_{i=1}^{n} hw_i\, a_i .\]2.2

The design variance of \(\hat\theta\) is then the design variance of that total, which the ultimate-cluster estimator (§2.2.2) computes directly from the \(a_i\). The whole task of an index’s “implementation” section is therefore to state its \(a_i\) (and, for a ratio, its numerator and denominator contributions).

2.2.2 Stratified ultimate-cluster variance

Let each observation carry a \(k\)-vector of contributions \(A_i\) (a single contribution when \(k=1\)). Within stratum \(s\), which contains \(M_s\) primary sampling units (PSUs), let \(e_{sm}\) be the sum of \(A\) over the observations of PSU \(m\), and \(\bar e_s\) the mean of \(e_{sm}\) over the \(M_s\) PSUs. The stratified ultimate-cluster covariance is

\[\hat V \;=\; \sum_{s} \frac{M_s}{M_s - 1}\,\bigl(1 - f_s\bigr)\sum_{m=1}^{M_s} \bigl(e_{sm} - \bar e_s\bigr)\bigl(e_{sm} - \bar e_s\bigr)^{\!\top},\]2.3

where \(f_s\) is the (optional) finite-population correction of stratum \(s\). Strata with a single PSU contribute nothing (no within-stratum degrees of freedom): they are treated as certainty units, and a note under the output says so. This is the estimator behind every psu_cov call in the implementation sections; a scalar estimator uses its \(1\times1\) case, \(\hat V(\hat\theta)=\sum_s \frac{M_s}{M_s-1}(1-f_s)\sum_{m} (e_{sm}-\bar e_s)^2\).

  • \(A_i\): the \(k\)-vector of contributions of observation \(i\)
  • \(A\): the matrix of the contributions of all the observations
  • \(e_{sm}\): the sum of the contributions of the observations of PSU \(m\) of stratum \(s\)
  • \(\bar e_s\): the mean of \(e_{sm}\) over the PSUs of stratum \(s\)
  • \(f_s\): the finite-population correction (sampling fraction) of stratum \(s\)
  • \(\hat V\): the stratified ultimate-cluster covariance of the contributions

2.2.3 Degrees of freedom and confidence intervals

The design degrees of freedom are

\[\nu \;=\; \Bigl(\textstyle\sum_s M_s\Bigr) - L \;=\; (\text{number of PSUs}) - (\text{number of strata}),\]2.4

computed over the whole sample and reused for every ordinate of a curve. A two-sided confidence interval at the chosen level is \(\hat\theta \pm t_{\nu}\,\widehat{\mathrm{SE}}(\hat\theta)\), where \(t_{\nu}\) is the Student-\(t\) critical value on the design degrees of freedom (used when \(\nu>0\); the normal critical value is used when the degrees of freedom are undefined — e.g. a difference between two independent samples, §3.1.3).

2.2.4 Linearized contributions for totals, means and ratios

Three building blocks recur. With \(d_i\) the subpopulation (domain) indicator (\(1\) if in the domain, else \(0\)) and \(\omega_i = hw_i\, d_i\):

Total \(\hat T=\sum_i \omega_i y_i\): contribution \(a_i = \omega_i y_i\).

Mean \(\hat\mu=\sum_i \omega_i y_i / \sum_i \omega_i\): contribution \(a_i = \dfrac{\omega_i\,(y_i-\hat\mu)}{\sum_j \omega_j}.\)

Ratio \(\hat R=\dfrac{\sum_i \omega_i y_i}{\sum_i \omega_i x_i}\): contribution \(a_i = \dfrac{\omega_i\,(y_i - \hat R\,x_i)}{\sum_j \omega_j x_j}.\)

Feeding \(a_i\) to the ultimate-cluster estimator (§2.2.2) gives the standard error; a ratio’s \(\widehat{\mathrm{SE}}(\hat R)=\sqrt{\hat V}\) with the single \(a_i\) above. Most indices reduce to a ratio of two specially constructed contributions, so the ratio case is the workhorse.

  • \(T\): a weighted total, \(\hat T=\sum_i \omega_i y_i\)
  • \(R\): a ratio of two weighted totals
  • \(x_i\): the variable of the denominator of the ratio, for observation \(i\)
  • \(d_i\): the subpopulation (domain) indicator: 1 if \(i\) is in the domain, else 0
  • \(\omega_i\): the domain sampling weight, \(\omega_i = hw_i\,d_i\)

2.2.5 The delta method

When \(\hat\theta = g(\hat b)\) is a smooth function of a vector of estimated means \(\hat b=(\hat b_1,\dots,\hat b_p)\) with design covariance \(\hat V_b\) (from §2.2.2 applied to the mean contributions of §2.2.4 jointly), its standard error is

\[\widehat{\mathrm{SE}}(\hat\theta) \;=\; \sqrt{\,G\,\hat V_b\,G^{\top}\,},\qquad G = \nabla g(\hat b),\]2.5

with the gradient \(G\) computed exactly, by the chain rule: each mean \(\hat b_j\) enters \(g\) carrying its own derivative (the unit vector \(e_j\)), and every operation of \(g\) (sums, products, quotients, powers, \(\log\), \(\exp\)) applies its derivative rule. \(G\) is therefore the analytic gradient — the derivative one would write by hand, as DASP does — evaluated at \(\hat b\), with no step and no approximation. (A finite-difference gradient is not used: when an atom has mean zero by construction, such as the line-correction term of a derived poverty line in ipov, a step scaled on that zero is lost in rounding and the term’s derivative reads as zero.)

  • \(g\): the smooth function of the means that gives the index
  • \(b\): the vector of the estimated means, \(\hat b=(\hat b_1,\dots,\hat b_p)\)
  • \(\hat b_1\): the first estimated mean
  • \(\hat b_p\): the last estimated mean
  • \(\hat b_j\): the \(j\)-th estimated mean
  • \(\hat V_b\): the design covariance of \(\hat b\)
  • \(G\): the gradient of \(g\) at \(\hat b\)
  • \(e_j\): the unit vector of the mean \(\hat b_j\)
  • \(_j\): one of the means of \(\hat b\)

2.3 Shared estimation primitives

  • \(x\): a value of \(y\), the point at which the density is evaluated
  • \(\hat f\): the kernel estimate of the density of \(y\), \(\hat f(x)\) at \(x\)

2.3.1 Weighted quantile

\(\hat Q(p)\) is the value of \(y\) at the first cumulative effective-weight share that reaches \(p\): sort \(y\) ascending, form \(C_i=\sum_{l\le i} w_l / W\), and return \(y\) at the smallest \(i\) with \(C_i \ge p\).

  • \(C_i\): the cumulative effective-weight share up to observation \(i\), \(\sum_{l\le i} w_l/W\)

2.3.2 Kernel density (Silverman bandwidth)

Where a density of \(y\) is needed (e.g. a quantile’s influence, a poverty line’s local density), DAAP uses a weighted Gaussian kernel with the Silverman rule-of-thumb bandwidth

\[\hat f(x) = \frac{1}{h\,W}\sum_{i} w_i\,\phi\!\Bigl(\frac{x-y_i}{h}\Bigr),\qquad h = 0.9\,\min\!\Bigl(\hat\sigma,\ \tfrac{\mathrm{IQR}}{1.34}\Bigr)\,n^{-1/5},\]2.6

with \(\hat\sigma\) the weighted standard deviation, \(\mathrm{IQR}\) the weighted inter-quartile range and \(\phi\) the standard normal density.

  • \(\mathrm{IQR}\): the weighted inter-quartile range

2.3.3 Grid-free Gaussian-KDE density and moment integrals

Because the integral of a Gaussian kernel is closed-form, a KDE density at a point and its interval moments are computed with no grid and no discretization error, in \(O(n)\):

\[\hat f(x)=\frac{1}{h\,W}\sum_i w_i\,\phi\!\Bigl(\tfrac{x-y_i}{h}\Bigr),\qquad \int_a^b x^k\,\hat f(x)\,dx=\frac{1}{W}\sum_i w_i\,M_k\!\left(\tfrac{a-y_i}{h},\tfrac{b-y_i}{h}\right),\]2.7

for \(k\in\{0,1,2\}\), where \(M_k\) is the incomplete Gaussian moment (\(\Phi\)- and \(\phi\)-terms). Boundary bias near a support edge \(c\) (e.g. an income floor \(0\)) is removed by the reflection method — adding the mirrored points \(2c-y_i\) — which stays closed-form.

  • \(a\): the lower bound of the interval
  • \(b\): the upper bound of the interval
  • \(M_k\): the incomplete Gaussian moment of order \(k\)
  • \(c\): an edge of the support (e.g. an income floor \(0\))

2.3.4 Rank-dependent (Gini-type) linearization

Rank-dependent indices — the Gini and concentration family, and every curve built on cumulative ranks — need an influence function that accounts for the fact that the ranks themselves are estimated and carry sampling variance. Treating the ranks as fixed (a naïve ratio standard error) understates the variance. DAAP uses the Binder–Kovačević V-statistic linearization.

Sort the sample ascending by the ranking variable and write \(w_i\) for the effective weight in that order. With the running sums \(S_i=\sum_{l\le i} w_l\), \(L_i=\sum_{l<i} w_l y_l\), \(W=S_n\) and \(\hat\mu = W^{-1}\sum_l w_l y_l\), define the per-observation term

\[ca_i \;=\; \hat\mu \;+\; y_i\Bigl(\tfrac{2S_i-w_i}{W}-1\Bigr)\;-\;\tfrac{2L_i+w_i y_i}{W}, \qquad \xi \;=\; \frac{1}{W}\sum_i w_i\,ca_i,\]2.8

\[\theta_i \;=\; \frac{2}{W}\Bigl(\textstyle\sum_{j\ge i} w_j y_j \;-\; y_i\sum_{j\ge i} w_j\Bigr).\]2.9

The index is then formed as a ratio of two design totals with per-observation contributions

\[a_i \;=\; hs_i\bigl(ca_i + (y_i-\hat\mu) + \theta_i - \xi\bigr),\qquad b_i \;=\; 2\,hs_i\,y_i,\]2.10

and its standard error is the ratio linearization of §2.2.4 applied to \((a_i,b_i)\) with the sampling weight \(hw_i\). This single primitive supplies the standard error of the Gini, the absolute Gini, the concentration index, and — with the ranking variable changed — the Lorenz and concentration curves. Sections that use it simply cite §2.3.4 and state which \(b_i\) (relative vs absolute) applies.

  • \(S_i\): the running sum of the weights, \(\sum_{l\le i} w_l\)
  • \(S_n\): the sum of all the weights, \(W\)
  • \(L_i\): the running sum of \(w_l\,y_l\) over the observations before \(i\)
  • \(ca_i\): the per-observation term of the rank-dependent linearization
  • \(\xi\): the weighted mean of \(ca_i\)
  • \(\theta_i\): the upper-tail term, \(\frac{2}{W}\bigl(\sum_{j\ge i} w_j y_j - y_i\sum_{j\ge i} w_j\bigr)\)
  • \(a_i\): the numerator contribution of observation \(i\) to the ratio
  • \(b_i\): the denominator contribution of observation \(i\) to the ratio

3 Inequality

3.1 Inequality indices — ineq

  • \(I\): the inequality index estimated
  • \(V_i\): the total weight of observation \(i\) and of the observations ranked above it, \(\sum_{l\ge i} w_l\)
  • \(\xi\): the equally-distributed-equivalent income (\(\hat\xi\) in the Gini, \(\hat\xi(\varepsilon)\) in the Atkinson index)
  • \(AI\): the absolute Gini, \(\hat\mu-\hat\xi\)
  • \(T\): a variable whose concentration is measured
  • \(t_i\): the value of the variable whose concentration is measured, for observation \(i\)
  • \(C_T\): the concentration index of \(T\)
  • \(AC\): the absolute concentration index
  • \(\mu_T\): the mean of \(T\)
  • \(\theta\): the parameter of the generalised entropy index
  • \(\varepsilon\): the inequality aversion of the Atkinson index
  • \(CV\): the coefficient of variation
  • \(QR\): the ratio of two quantiles
  • \(SR\): the ratio of two differences of generalised Lorenz ordinates
  • \(GL(p)\): the generalised Lorenz ordinate at \(p\)
  • \(E\): an expectation (a population mean)

ineq estimates a family of inequality (and concentration) indices for one or more variables of interest, each with a design-based standard error. Individual-level inequality is obtained by weighting observation \(i\) with \(w_i = hw_i\,hs_i\).

3.1.1 What is estimated

Gini and concentration. With observations ordered by the ranking variable (the welfare variable \(y\) for the Gini, an external ranking variable for a concentration index) and \(V_i=\sum_{l\ge i} w_l\), the (relative) Gini index of \(y\) is

\[\hat I \;=\; 1-\frac{\hat\xi}{\hat\mu},\qquad \hat\xi \;=\; \sum_{i=1}^{n}\Bigl[\tfrac{V_i^2-V_{i+1}^2}{V_1^{2}}\Bigr]\,y_i .\]3.1

The absolute Gini is \(\widehat{AI}=\hat\mu-\hat\xi\). The concentration index of a variable \(T\) ranked by another variable is \(\widehat{C}_T = 1-\hat\xi_T/\hat\mu_T\) with \(\hat\xi_T\) the same functional applied to \(t_i\) under the external ranking; the absolute concentration index is \(\widehat{AC}_T=\hat\mu_T-\hat\xi_T\).

Generalised entropy.

\[\hat I(\theta)=\begin{cases} \dfrac{1}{\theta(\theta-1)\,W}\displaystyle\sum_i w_i\!\left[\Bigl(\tfrac{y_i}{\hat\mu}\Bigr)^{\theta}-1\right], & \theta\neq 0,1,\\[1.4ex] \dfrac{1}{W}\displaystyle\sum_i w_i\,\log\!\Bigl(\tfrac{\hat\mu}{y_i}\Bigr), & \theta=0\ \text{(mean log deviation)},\\[1.4ex] \dfrac{1}{W}\displaystyle\sum_i \tfrac{w_i y_i}{\hat\mu}\,\log\!\Bigl(\tfrac{y_i}{\hat\mu}\Bigr), & \theta=1\ \text{(Theil)}. \end{cases}\]3.2

Atkinson (aversion \(\varepsilon\ge 0\), \(\varepsilon\neq1\)): \(\hat I(\varepsilon)=\bigl(\hat\mu-\hat\xi(\varepsilon)\bigr)/\hat\mu\) with the equally-distributed-equivalent income

\[\hat\xi(\varepsilon)=\Bigl[\tfrac{1}{W}\textstyle\sum_i w_i\,y_i^{\,1-\varepsilon}\Bigr]^{\frac{1}{1-\varepsilon}}\!(\varepsilon\neq1), \qquad \hat\xi(1)=\exp\!\Bigl[\tfrac{1}{W}\textstyle\sum_i w_i\log y_i\Bigr].\]3.3

Coefficient of variation \(\widehat{CV}=\bigl[(\sum_i w_i y_i^2/W-\hat\mu^2)/\hat\mu^2\bigr]^{1/2}\).

Quantile / share ratios. \(\widehat{QR}(p_1,p_2)=\hat Q(p_1)/\hat Q(p_2)\), and \(\widehat{SR}(p_1,p_2,p_3,p_4)=\bigl(\widehat{GL}(p_2)-\widehat{GL}(p_1)\bigr)/\bigl(\widehat{GL}(p_4)-\widehat{GL}(p_3)\bigr)\) with \(\widehat{GL}\) the generalised-Lorenz ordinate.

3.1.2 Estimator and inference

The point estimates use the formulas of §3.1.1. The standard errors split by index type.

Gini family (gini, agini, conc, aconc) — rank-dependent. These use the Gini-type linearization of §2.3.4 directly. Order by the ranking variable (the welfare variable for gini/agini, the external ranking variable for conc/aconc), form \(ca_i\), \(\xi\), \(\theta_i\) and the contributions

\[a_i = hs_i\bigl(ca_i+(y_i-\hat\mu)+\theta_i-\xi\bigr),\qquad b_i = \begin{cases} 2\,hs_i\,y_i & \text{relative (\texttt{gini},\texttt{conc})},\\ 2\,hs_i & \text{absolute (\texttt{agini},\texttt{aconc})}, \end{cases}\]3.4

and take the design ratio standard error of §2.2.4 on \((a_i,b_i)\). Because the influence includes the \(\theta_i\) term, the sampling variance of the ranks is captured — the correct rank-dependent variance, not the fixed-rank approximation.

Moment indices (atk, entropy, covar) — delta method. Each is a smooth function of three weighted means. Define the per-observation atoms

\[a^{(1)}_i = hs_i\,f(y_i),\qquad a^{(2)}_i = hs_i,\qquad a^{(3)}_i = hs_i\,y_i,\]3.5

so that their survey means \(\bar b=(\bar b_1,\bar b_2,\bar b_3)\) give \(\widehat{E[f(y)]}=\bar b_1/\bar b_2\) and \(\hat\mu=\bar b_3/\bar b_2\). The index is \(g(\bar b)\) with

\[g_{\text{atk}}=1-\bar b_1^{\,\frac{1}{1-\varepsilon}}\,\bar b_2^{\,1+\frac{1}{\varepsilon-1}}/\bar b_3\ \ (f(y)=y^{1-\varepsilon}),\quad g_{\text{atk}}^{\varepsilon=1}=1-e^{\bar b_1/\bar b_2}\,\bar b_2/\bar b_3\ \ (f=\log),\]3.6

\[g_{\text{ent}}^{\theta\neq0,1}=\tfrac{1}{\theta(\theta-1)}\Bigl(\tfrac{\bar b_1/\bar b_2}{(\bar b_3/\bar b_2)^{\theta}}-1\Bigr)\ (f=y^{\theta}),\ \ g_{\text{ent}}^{0}=\log\tfrac{\bar b_3}{\bar b_2}-\tfrac{\bar b_1}{\bar b_2}\ (f=\log),\ \ g_{\text{ent}}^{1}=\tfrac{\bar b_1}{\bar b_3}-\log\tfrac{\bar b_3}{\bar b_2}\ (f=y\log y),\]3.7

\[g_{\text{cv}}=\bigl(\bar b_1\bar b_2/\bar b_3^{\,2}-1\bigr)^{1/2}\ \ (f(y)=y^{2}).\]3.8

The standard error is the delta method of §2.2.5 on the joint design covariance of \((\bar b_1,\bar b_2,\bar b_3)\). The atoms require \(y_i>0\) (logs and non-integer powers).

Quantile / share ratios (qr, sr) — ratio with the quantile density. A quantile has the influence \(\widehat Q(p)\)-contribution \(-\,hs_i\bigl(\mathbf 1\{y_i<\hat Q(p)\}-p\bigr)/\hat f(\hat Q(p))+hs_i\hat Q(p)\), where \(\hat f\) is the KDE density of §2.3.2 at the quantile — this folds in the sampling variance of the quantile itself. For qr the numerator/denominator contributions are those of \(\hat Q(p_1)\) and \(\hat Q(p_2)\); for sr they are the generalised-Lorenz differences with per-observation term \(hs_i\bigl(\hat Q(p)\,p+(y_i-\hat Q(p))\mathbf 1\{y_i<\hat Q(p)\}\bigr)\). In both cases the standard error is the design ratio linearization of §2.2.4.

  • \(a_i\): the numerator contribution of observation \(i\) to the ratio
  • \(b_i\): the denominator contribution of observation \(i\) to the ratio
  • \(ca_i\): the per-observation term of the rank-dependent linearization (§2.3.4)
  • \(\theta_i\): the upper-tail term of the rank-dependent linearization (§2.3.4)
  • \(\xi\): the weighted mean of \(ca_i\) (§2.3.4)
  • \(a^{(1)}_i\): the first atom of observation \(i\), \(hs_i\,f(y_i)\)
  • \(a^{(2)}_i\): the second atom of observation \(i\), \(hs_i\)
  • \(a^{(3)}_i\): the third atom of observation \(i\), \(hs_i\,y_i\)
  • \(f\): the transformation of \(y\) in the first atom, set by the moment index
  • \(\hat f\): the kernel estimate of the density (§2.3.2)
  • \(\bar b\): the vector of the survey means of the atoms, \((\bar b_1,\bar b_2,\bar b_3)\)
  • \(g\): the function of \(\bar b\) that gives the index
  • \(g_{\text{atk}}\): the Atkinson index as a function of \(\bar b\)
  • \(g_{\text{atk}}^{\varepsilon=1}\): the Atkinson index at \(\varepsilon=1\), as a function of \(\bar b\)
  • \(g_{\text{ent}}^{\theta\neq0,1}\): the generalised entropy index at \(\theta\) other than 0 and 1, as a function of \(\bar b\)
  • \(g_{\text{ent}}^{0}\): the generalised entropy index at \(\theta=0\), as a function of \(\bar b\)
  • \(g_{\text{ent}}^{1}\): the generalised entropy index at \(\theta=1\), as a function of \(\bar b\)
  • \(g_{\text{cv}}\): the coefficient of variation as a function of \(\bar b\)
  • \(e\): the exponential (the base of the natural logarithm)

3.1.3 Differences between distributions — dineq

dineq estimates the difference \(\hat d = \hat I(\text{2}) - \hat I(\text{1})\) between the same index on two distributions. Each distribution contributes the same per-observation linearization as above (the Gini \(a_i,b_i\); the moment atoms; the quantile contributions). When the two distributions are two variables (or two subpopulations) on the same sample, both linearizations are placed on the one design and the difference’s standard error is the ultimate- cluster variance of the differenced influence — so the covariance between the two indices is captured, giving a tighter (and correct) standard error than combining two independent ones. When the two distributions come from independent samples, the variance is the sum of the two design variances and the normal critical value is used (the pooled design degrees of freedom are not defined).

  • \(d\): the difference between the indices of the two distributions
  • \(a_i\): the numerator contribution of observation \(i\) to the Gini index (§3.1.2)
  • \(b_i\): the denominator contribution of observation \(i\) to the Gini index (§3.1.2)

3.2 Lorenz and concentration curves — clorenz

  • \(L(p)\): the Lorenz ordinate: the share of total welfare held by the poorest \(p\)
  • \(p\): the cumulative population share
  • \(F\): the cumulative distribution function of \(y\)
  • \(F_X\): the cumulative distribution function of the ranking variable \(X\)
  • \(GL(p)\): the generalised Lorenz ordinate, \(\mu L(p)\)
  • \(t_{\nu}\): the Student-\(t\) critical value with \(\nu\) degrees of freedom
  • \(AL(p)\): the absolute Lorenz ordinate, \(GL(p)-p\,\mu\)
  • \(C_T(p)\): the concentration ordinate of \(T\) ranked by \(X\)
  • \(T\): the variable whose concentration is drawn
  • \(t_i\): the value of the variable whose concentration is drawn, for observation \(i\)
  • \(X\): the ranking variable
  • \(x_i\): the value of the ranking variable for observation \(i\)
  • \(\mu\): the mean of \(y\)

Where an inequality index compresses a whole distribution into a single number, a curve shows the inequality ordinate by ordinate. clorenz draws Lorenz and concentration curves — and, with diclorenz, the differences between them — each with a design-based confidence band.

3.2.1 What is estimated

The Lorenz curve. Rank the population from poorest to richest and plot, against the cumulative population share \(p\), the share of total welfare held by the poorest \(p\):

\[L(p) \;=\; \frac{\sum_{i:\,F(y_i)\le p} w_i\,y_i}{\sum_i w_i\,y_i}.\]3.9

\(L(0)=0\), \(L(1)=1\), and the curve coincides with the 45° line only under perfect equality; the further it bows below the diagonal, the more unequal the distribution. The Gini index of §3.1 is exactly twice the area between the diagonal and the Lorenz curve — so the curve is the pointwise object that the Gini summarises. Two rescalings are offered: the generalised Lorenz curve \(GL(p)=\mu\,L(p)\) (cumulative welfare per capita, ending at the mean \(\mu\) — it ranks distributions by welfare, not only inequality), and the absolute Lorenz curve \(AL(p)=GL(p)-p\,\mu\) (the absolute gap from the mean line).

The concentration curve. Replace “ranked by welfare” with “ranked by another variable”. The concentration curve of a variable \(T\) ranked by \(X\) plots the cumulative share of \(T\) against the cumulative population share ordered by \(X\):

\[C_T(p) \;=\; \frac{\sum_{i:\,F_X(x_i)\le p} w_i\,t_i}{\sum_i w_i\,t_i}.\]3.10

Its area gives the concentration index of §3.1. Concentration curves are the natural tool for progressivity and for dominance testing — a transfer is pro-poor, for instance, when its concentration curve lies above the Lorenz curve of income. A deficit-share curve \(p-L(p)\) is also available.

3.2.2 Estimator and inference

The ordinate. Sort by the ranking variable (welfare for a Lorenz curve, the ranking variable for a concentration curve), accumulate the effective weight \(w_i=hw_i\,hs_i\) into the population share and \(w_i y_i\) into the welfare share, and read off \(L(p)\) (or \(GL\), \(AL\), \(C\)) on a 101-point grid \(p=0,0.01,\dots,1\) — or on the exact empirical steps.

The band. At each ordinate the curve is a ratio of two cumulative totals — cumulative welfare over total welfare — so its standard error is the ratio linearization of §2.2.4 fed to the ultimate-cluster variance of §2.2.2, computed separately at every \(p\). The per-observation influence at ordinate \(p\) is

\[a_i(p) \;=\; \frac{w_i\bigl[\,n_i(p) - L(p)\,d_i\,\bigr]}{\sum_j w_j d_j},\qquad n_i(p) = hs_i\Bigl(p\,v(p) + (y_i - v(p))\,\mathbf 1\{r_i < \hat Q_r(p)\}\Bigr),\]3.11

with the denominator \(d_i = hs_i\,y_i\) for the normalised curve (or \(hs_i\) for the generalised/absolute one), and \(\hat Q_r(p)\) the weighted \(p\)-quantile of the ranking variable (§2.3.1). The term \(v(p)\) — the welfare level at the ordinate — is what makes the band account for the fact that the rank cut \(\hat Q_r(p)\) is itself estimated:

  • for a Lorenz curve (ranked by welfare), \(v(p)=\hat Q_y(p)\) is simply the welfare quantile;
  • for a concentration curve (ranked by \(X\)), \(v(p)=\widehat{\mathbb E}[\,y \mid X = \hat Q_X(p)\,]\) is the welfare expected at the rank cut — estimated by a weighted Nadaraya–Watson kernel mean with the Silverman bandwidth of §2.3.2 (the extra smoothing step a concentration curve needs and a Lorenz curve does not).

Each ordinate’s standard error is \(\sqrt{\hat V\!\bigl(a_i(p)\bigr)}\) from the ultimate-cluster estimator, and the band is \(L(p)\pm t_{\nu}\,\mathrm{SE}(p)\) on the design degrees of freedom (§2.2.3). The whole curve is thus the ordinate estimator swept across \(p\) (the Davidson–Duclos design-based inference for Lorenz and concentration ordinates).

  • \(a_i(p)\): the influence of observation \(i\) on the ordinate at \(p\)
  • \(n_i(p)\): the numerator term of the influence
  • \(d_i\): the denominator term of observation \(i\) in the ordinate
  • \(v(p)\): the welfare level at the ordinate
  • \(r_i\): the ranking variable of observation \(i\)
  • \(Q_r(p)\): the \(p\)-quantile of the ranking variable
  • \(Q_y(p)\): the \(p\)-quantile of \(y\)
  • \(Q_X(p)\): the \(p\)-quantile of \(X\)
  • \(\mathrm{SE}(p)\): the standard error of the ordinate
  • \(\mathbb E\): an expectation

3.2.3 Differences between curves — diclorenz

diclorenz estimates the difference \(D(p)=L_2(p)-L_1(p)\) between two curves on a common grid, with its own band — the tool for curvewise dominance tests (does one distribution Lorenz-dominate another at every \(p\)?). It reuses the per-ordinate influence above, and forms the band by the two-distribution rule of §2.2.3, ordinate by ordinate:

  • same dataset (two subpopulations, or two variables) ⇒ dependent: both ordinate influences are placed on the shared design and the variance of their difference \(a_i^{(2)}(p)-a_i^{(1)}(p)\) is taken, so the covariance between the two curves is captured (Student-\(t\) band). This is tighter — and correct — when the curves share sampling noise;
  • different datasets ⇒ independent: the two ordinate variances add (normal band).

This mirrors the difference of indices dineq (§3.1.3): a curve difference is just the index difference evaluated at every ordinate.

  • \(D(p)\): the difference between the two curves at \(p\), \(L_2(p)-L_1(p)\)
  • \(L_1(p)\): the curve of the first distribution
  • \(L_2(p)\): the curve of the second distribution
  • \(a_i^{(1)}(p)\): the ordinate influence (§3.2.2) of observation \(i\) on the first curve
  • \(a_i^{(2)}(p)\): the ordinate influence (§3.2.2) of observation \(i\) on the second curve

4 Multidimensional inequality

Well-being has several dimensions — income, health, education, housing — and inequality in one need not mirror inequality in another. A multidimensional inequality index summarises them jointly and, crucially, accounts for how the dimensions are correlated: the same marginal inequalities are more troubling when the same households are disadvantaged on every dimension at once.

4.1 Multidimensional inequality — imdi

  • \(I\): the multidimensional inequality index
  • \(K\): the number of dimensions of well-being
  • \(I_k\): the S-Gini index of dimension \(k\), households ranked by that dimension
  • \(C_k\): the concentration index of dimension \(k\), households ranked by the aggregate of all dimensions
  • \(\lambda_k\): the weight of the S-Gini index of dimension \(k\) against the concentration index of the same dimension
  • \(\phi_k\): the weight of dimension \(k\) in the multidimensional index
  • \(\rho\): the rank aversion of the S-Gini (\(\rho=2\))
  • \(\mu_k\): the mean of dimension \(k\)
  • \(\mu\): the mean of the aggregate of all the dimensions
  • \(_k\): a dimension of well-being

imdi estimates the hybrid multidimensional inequality index of Araar (2009). For each dimension it blends the dimension’s own inequality with its concentration along the aggregate of all dimensions, so a single parameter tunes how strongly the index reacts to the correlation between dimensions.

4.1.1 What is estimated

For \(K\) dimensions of well-being, the index is

\[I \;=\; \sum_{k=1}^{K} \phi_k\Bigl[\,\lambda_k\,I_k + (1-\lambda_k)\,C_k\,\Bigr],\]4.1

a weighted average over dimensions of a blend of two single-dimension indices:

  • \(I_k\) — the inequality of dimension \(k\) on its own: its S-Gini index (rank aversion \(\rho=2\)), households ranked by that dimension. It ignores how dimension \(k\) lines up with the others.
  • \(C_k\) — the concentration of dimension \(k\) when households are ranked by the aggregate of all dimensions. It is large when the households that are worst off overall are also worst off on dimension \(k\), so it captures the inter-dimensional correlation.

The normative parameter \(\lambda_k\in[0,1]\) sets the mix: \(\lambda_k=1\) keeps only the marginal inequality \(I_k\) (correlation ignored), \(\lambda_k=0\) keeps only the correlation-sensitive concentration \(C_k\), and intermediate values interpolate. The dimension weights \(\phi_k\) are equal (\(1/K\), the default) or the shares \(\mu_k/\mu\) of each dimension in the aggregate. The index also reports each dimension’s contribution \(\phi_k[\lambda_k I_k+(1-\lambda_k)C_k]\) as a percentage of the total; an absolute variant uses the absolute Gini and concentration in place of the relative ones.

4.1.2 Estimator and inference

The point estimate follows the formula directly: for each dimension, compute its S-Gini (ranking by the dimension) and its concentration index (ranking by the aggregate), blend them with \(\lambda_k\), weight by \(\phi_k\), and sum.

The standard error is design-based — a contribution of DAAP, since this index is usually reported as a point estimate only. Being a smooth function of survey means, the index is amenable to the delta method of §2.2.5 once the right per-observation atoms are assembled. For each dimension those atoms are exactly the rank-dependent Gini/concentration influences of §3.1.2 (the linearization of §2.3.4): the Gini influence with households ranked by the dimension, and the concentration influence with households ranked by the aggregate. When the weights are shares, the per-dimension means \(\mu_k\) and the aggregate mean \(\mu\) enter as further atoms, so the shares carry their own sampling variance too. The delta method on the joint ultimate-cluster covariance (§2.2.2) of all these atoms returns the standard error and the Student-\(t\) interval (§2.2.3). A subgroup restriction confines the indices to the subgroup while the shares stay population-wide.

  • Araar, A. (2009). The Hybrid Multidimensional Index of Inequality. Cahiers de recherche 0945, CIRPÉE. https://papers.ssrn.com/sol3/papers.cfm?abstract_id=1496505
  • Duclos, J.-Y. and Araar, A. (2006). Poverty and Equity: Measurement, Policy and Estimation. Springer. (the S-Gini and concentration indices and their influence functions)

5 Progressivity

A tax is progressive when it takes a larger share of income from the rich than from the poor; a transfer is progressive when it gives a larger share to the poor. Progressivity is therefore about departure from proportionality — measured by comparing how a tax or transfer is distributed with how income itself is distributed — and it is what makes a tax-benefit system reduce inequality.

5.1 Progressivity indices — iprog

  • \(X\): gross income, by which households are ranked
  • \(T\): a tax
  • \(I_X\): the Gini index of gross income \(X\)
  • \(Z\): a variable whose concentration index is taken
  • \(C_Z\): the concentration index of \(Z\), households ranked by \(X\)
  • \(C_T\): the concentration index of the tax, households ranked by \(X\)
  • \(C_B\): the concentration index of the transfer, households ranked by \(X\)
  • \(C_{X-T}\): the concentration index of net income \(X-T\), households ranked by \(X\)
  • \(C_{X+B}\): the concentration index of net income \(X+B\), households ranked by \(X\)
  • \(\Pi_K\): the Kakwani index
  • \(\Pi_{RS}\): the Reynolds–Smolensky index

iprog estimates the two standard progressivity indices — Kakwani and Reynolds–Smolensky — for a tax or a transfer, each with a design-based standard error.

5.1.1 What is estimated

Let \(X\) be gross income and rank households by it. Write \(I_X\) for the Gini index of \(X\) (§3.1) and \(C_Z\) for the concentration index of a variable \(Z\) ranked by \(X\) (§3.1).

The Kakwani index measures the departure from proportionality — how much more concentrated on the rich a tax \(T\) is than income itself:

\[\Pi_K \;=\; C_T - I_X \quad\text{(tax)},\qquad \Pi_K \;=\; I_X - C_B \quad\text{(transfer $B$)}.\]5.1

A positive \(\Pi_K\) signals a progressive instrument — the tax falls more heavily on the rich than income does, or the transfer is directed more to the poor.

The Reynolds–Smolensky index measures the actual redistribution — the fall in inequality from gross to net income:

\[\Pi_{RS} \;=\; I_X - C_{X-T}\quad\text{(tax)},\qquad \Pi_{RS} \;=\; I_X - C_{X+B}\quad\text{(transfer)},\]5.2

the Gini of gross income minus the concentration of net income. Kakwani captures the design of the instrument; Reynolds–Smolensky its effect on inequality — the two differ through the average tax (or transfer) rate and any reranking.

5.1.2 Estimator and inference

Each index is a difference of two Gini/concentration indices, both ranked by gross income \(X\). Every one of those is estimated exactly as in §3.1.2 — the rank-dependent linearization of §2.3.4 — so the progressivity index is a smooth function of the survey means of the two indices’ per-observation influences. Its standard error is the delta method of §2.2.5 on the joint ultimate-cluster covariance (§2.2.2) of those influences, with the Student-\(t\) interval on the design df (§2.2.3).

  • Kakwani, N. C. (1977). Measurement of tax progressivity: an international comparison. Economic Journal 87(345), 71–80.
  • Reynolds, M. and Smolensky, E. (1977). Public Expenditures, Taxes and the Distribution of Income. Academic Press.
  • Duclos, J.-Y. and Araar, A. (2006). Poverty and Equity: Measurement, Policy and Estimation. Springer. (the concentration-index influence functions)

5.2 Progressivity curves — cprog

  • \(T\): a tax
  • \(B\): a transfer
  • \(L_X(p)\): the Lorenz curve of gross income at \(p\)
  • \(C_\bullet(p)\): the concentration curve of the fiscal instrument studied
  • \(C_T(p)\): the concentration curve of the tax, households ranked by \(X\)
  • \(C_B(p)\): the concentration curve of the transfer, households ranked by \(X\)
  • \(C_{X-T}(p)\): the concentration curve of net income \(X-T\), households ranked by \(X\)
  • \(C_{X+B}(p)\): the concentration curve of net income \(X+B\), households ranked by \(X\)
  • \(PR(p)\): the progressivity curve at \(p\)
  • \(c_i\): the sign of an ordinate in the combination, \(\pm 1\)
  • \(a_i(p)\): the influence of an ordinate at \(p\) (§3.2.2)

Where the indices summarise progressivity in one number, a progressivity curve shows it ordinate by ordinate — and supports a dominance statement that holds for a whole class of progressivity measures.

5.2.1 What is estimated

A progressivity curve compares the concentration curve \(C_\bullet(p)\) of the tax or transfer (§3.2) with the Lorenz curve \(L_X(p)\) of gross income, at every percentile \(p\). There are two criteria — tax redistribution (TR) and income redistribution (IR), the latter comparing net income with gross — and so four cases.

A tax \(T\) is TR-progressive if

\[PR(p) \;=\; L_X(p) - C_T(p) \;>\; 0 \qquad \forall\, p\in(0,1).\]5.3

A transfer \(B\) is TR-progressive if

\[PR(p) \;=\; C_B(p) - L_X(p) \;>\; 0 \qquad \forall\, p\in(0,1).\]5.4

A tax \(T\) is IR-progressive if

\[PR(p) \;=\; C_{X-T}(p) - L_X(p) \;>\; 0 \qquad \forall\, p\in(0,1).\]5.5

A transfer \(B\) is IR-progressive if

\[PR(p) \;=\; C_{X+B}(p) - L_X(p) \;>\; 0 \qquad \forall\, p\in(0,1).\]5.6

A curve that stays on one side of zero — its confidence band not crossing it — is a progressivity-dominance statement that holds over the whole distribution. Integrating the curve recovers the iprog index: twice the area under the TR curve is the Kakwani index, and under the IR curve the Reynolds–Smolensky index.

5.2.2 Estimator and inference

A progressivity curve is a linear combination of Lorenz and concentration ordinates, all on the same percentile grid and ranked by gross income (each ordinate the §3.2 estimator). Its confidence band is design-based: because the ordinates come from the same survey, their per-observation influences share the design, so the band is the ultimate-cluster standard error of the combined influence \(\sum_i c_i\,a_i(p)\) — the coefficients \(c_i\) being \(+1\) and \(-1\) for the \(L_X\) and \(C\) ordinates — evaluated at every \(p\) (§2.2.2, §3.2.2). This joint-covariance band is the correct one: it captures the covariance between the tax/transfer curve and the income Lorenz curve that a naïve “two separate bands” comparison would miss.

5.2.3 Transfer versus tax — cprogtb

cprogtb asks whether a transfer \(B\) is more progressive than a tax \(T\).

On the TR criterion, \(B\) is more progressive than \(T\) if

\[PR(p) \;=\; C_B(p) + C_T(p) - 2\,L_X(p) \;>\; 0 \qquad \forall\, p\in(0,1),\]5.7

and on the IR criterion if

\[PR(p) \;=\; C_{X+B}(p) - C_{X-T}(p) \;>\; 0 \qquad \forall\, p\in(0,1).\]5.8

It is the same linear-combination-of-ordinates estimator, with the same joint-covariance band; twice its area is the difference of the two instruments’ iprog indices.

6 Redistribution

A tax-benefit system redistributes: it turns gross income into net income and, in doing so, usually lowers inequality. This chapter measures that redistributive effect and decomposes it into the part that is genuinely equalising, the part lost to treating equals unequally, and the part lost to re-ordering households.

6.1 Horizontal inequity — hidja

  • \(\Delta\): a difference: \(\Delta I = I(X)-I(N)\) the redistributive effect, \(\Delta C\) the same in income units
  • \(C\): in \(\Delta C\), the cost of inequality, in income units

  • \(\check\varpi_i\): the rank weight of observation \(i\) shared equally within its group of pre-fiscal equals
  • \(\varpi\): the S-Gini rank weights
  • \(\check\varpi\): the rank weights shared equally within each group of pre-fiscal equals

  • \(w\): a weight
  • \(w_i\): the effective weight of observation \(i\) (§2.1)

  • \(H^{*}\): the horizontal component of the cost of inequality
  • \(R^{*}\): the reranking component of the cost of inequality

hidja decomposes the redistributive effect of a tax-benefit system — the fall in inequality from gross income to net income — into vertical equity, classical horizontal inequity and reranking (Duclos, Jalbert & Araar 2003), with design-based standard errors. The estimation follows the corrected procedure of Urban (2013).

6.1.1 What is estimated

A tax-benefit system turns gross income \(X\) into net income \(N\). Its redistributive effect is the inequality it removes,

\[\Delta I \;=\; I(X) - I(N),\]6.1

measured with the ethical Gini–Atkinson index \(I(\cdot)\) (defined below), which carries a rank- aversion parameter \(\rho>1\) and an inequality-aversion parameter \(\varepsilon\ge 0\) (the same Atkinson aversion as in §3.1). Duclos–Jalbert–Araar split the effect into three parts,

\[\Delta I \;=\; \underbrace{V}_{\text{vertical}} \;-\; \underbrace{H}_{\text{horizontal inequity}} \;-\; \underbrace{R}_{\text{reranking}},\]6.2

  • \(V\) — the equalisation the system would achieve if it treated equals equally;
  • \(H\) — the loss from the unequal treatment of pre-fiscal equals (classical horizontal inequity);
  • \(R\) — the loss from re-ordering households between the gross and the net ranking.

A parallel cost-of-inequality decomposition \(\Delta C = \mu_F - \mu_N = V^{*} - H^{*} - R^{*}\), in income units rather than index points, is also reported.

The Gini–Atkinson index. For an income vector \(y\) with effective weights \(w_i\) (§2.1), the Atkinson utility of income is \(U(y_i) = y_i^{\,1-\varepsilon}/(1-\varepsilon)\). Order the units ascending by the ranking variable and let \(S_i=\sum_{l\le i} w_l\) be the running cumulative weight (§2.3.4) and \(W=S_n\) the total. The S-Gini rank weight of unit \(i\) is

\[\varpi_i \;=\; W^{-\rho}\Bigl[(W-S_{i-1})^{\rho}-(W-S_i)^{\rho}\Bigr],\]6.3

and the ethical welfare \(\mathcal W\) and the index \(I\) are

\[\mathcal W=\sum_i \varpi_i\,U(y_{(i)}),\qquad I \;=\; 1-\frac{\bigl[(1-\varepsilon)\,\mathcal W\bigr]^{1/(1-\varepsilon)}}{\mu}.\]6.4

Because the rank weights depend on the cumulative weight, the index is weight-invariant: giving a unit weight \(w\) is the same as replicating it \(w\) times.

Strict vs relaxed horizontal inequity — relax(λ). With continuous income no two households have exactly the same gross income, so “equals” means a neighbourhood of \(X\), and \(H\) measures the net-income spread within that neighbourhood. How much of that spread is genuine inequity is a modelling choice, set by \(\lambda\in[0,1)\): the counterfactual net income keeps a share \(\lambda\) of the local spread as legitimate variation, \(N^E_i(\lambda)=\mathbb E[N\mid X_i]+\lambda\bigl(N_i-\mathbb E[N\mid X_i]\bigr)\). At \(\lambda=0\) (strict, the default) every within-neighbourhood difference counts as inequity — the textbook definition and an upper bound on \(H\); as \(\lambda\to1\) all local spread is deemed legitimate and \(H\to0\). Only \(H\) and \(V\) move with \(\lambda\) (by the same amount); \(\Delta I\), \(R\) and the indices do not. \(H\) is also sensitive to the kernel bandwidth (a wider kernel raises it), so a value of relax() and bandwidth() should be reported with the result.

6.1.2 Estimator and inference

The four building-block indices. \(X\) and \(N\) are first normalised to mean 1, and households are ordered lexicographically — first by \(X\), then within groups of equal \(X\) by \(N\). Four Gini–Atkinson indices are formed:

Index Meaning Ranking variable Rank weights
\(I(X)\) gross-income inequality \(X\) \(\varpi\)
\(I(N)\) net-income inequality (Lorenz) \(N\) \(\varpi\)
\(\check I(N^x)\) concentration of \(N\) by \(X\) \(X\) \(\check\varpi\) (tie-corrected)
\(I(N^E)\) inequality of the counterfactual \(N^E\) \(X\) \(\check\varpi\)

The pre-fiscal-equals correction. Several households can share the same gross income \(X\) (e.g. zero pre-fiscal income). They belong to the same quantile and must receive equal rank weight — but the raw \(\varpi_i\) fall with rank, so tied units would otherwise get different weights, biasing the concentration \(\check I(N^x)\). The fix (Urban 2013): within each group \(g\) of pre-fiscal equals, share the group’s total rank-weight in proportion to the weight,

\[\check\varpi_i \;=\; w_i\,\frac{\sum_{j\in g}\varpi_j}{\sum_{j\in g} w_j}\qquad (i\in g).\]6.5

Skipping this step overstates \(H\) and understates \(R\) (on Urban’s 12-unit example the concentration is \(0.4660\) instead of the correct \(0.4120\)).

The counterfactual net income (the EPI). \(I(N^E)\) needs the expected post-fiscal income \(N^E_i=\mathbb E[N\mid X=X_i]\) — the net income a household would receive given its gross income. hidja estimates it deterministically with a weighted Nadaraya–Watson kernel mean (the Gaussian kernel and Silverman bandwidth of §2.3.2),

\[N^E_i=\frac{\sum_j w_j\,K\!\bigl(\tfrac{X_j-X_i}{h}\bigr)\,N_j}{\sum_j w_j\,K\!\bigl(\tfrac{X_j-X_i}{h}\bigr)}, \qquad K(u)=e^{-u^2/2},\]6.6

with an additive shift so that \(\sum_i w_i N^E_i=\sum_i w_i N_i\) (mean preservation), and the bandwidth overridable with bandwidth().

The decomposition. The three components are differences of the four indices,

\[V=I(X)-I(N^E),\qquad H=\check I(N^x)-I(N^E),\qquad R=I(N)-\check I(N^x),\]6.7

so that \(V-H-R=I(X)-I(N)=\Delta I\) by construction (the \(I(N^E)\) terms cancel). Only \(V\) and \(H\) depend on the counterfactual; \(\Delta I\), \(R\) and the four indices do not.

Cost of inequality. In income units, with \(\gamma=\mu_{NR}/\mu_N\) and \(\xi\) the equally-distributed- equivalent income of \(N^E\),

\[\Delta C=\frac{I(X)-I(N)}{1-I(X)}\,\mu_N,\quad \mu_F=\Delta C+\mu_N,\quad \mu_{NR}=\frac{1-I(N)}{1-\check I(N^x)}\,\mu_N,\quad \mu_{NH}=\gamma\,\xi,\]6.8

with \(V^{*}=\mu_F-\mu_{NH}\), \(H^{*}=\mu_{NR}-\mu_{NH}\), \(R^{*}=\mu_N-\mu_{NR}\) and \(\Delta C=V^{*}-H^{*}-R^{*}\).

Standard errors — design bootstrap. Because a kernel enters \(N^E\), the estimator is not a smooth function of weighted totals, so its standard errors come from a design bootstrap rather than the linearization of §2.2. For \(B\) replications (nrep, default 200): resample PSUs with replacement within each stratum of the svyset design, recompute the whole decomposition, and take the standard deviation of the \(B\) replicate estimates for every component. It is reproducible under set seed; se(none) returns the point estimates only. The point estimates match Urban (2013)’s published 12-unit example exactly (to \(\sim10^{-6}\)), including the tie-corrected concentration.

7 Polarization

Polarization is not inequality. A distribution is polarized when it clusters into a few distinct groups — a shrinking middle with masses pulling towards the extremes — which can happen even while overall inequality is unchanged. Two forces drive it: people identify with those close to them and feel alienated from those far away. This chapter estimates the standard polarization indices.

7.1 Polarization indices — ipola

  • \(m\): the median (the boundary income of the split in the bipolarization index)
  • \(P^{\mathrm{ER}}\): the Esteban–Ray polarization index, the core of \(P^{\mathrm{EGR}}\)
  • \(\pi_j\): the population share of group \(j\)
  • \(\pi_k\): the population share of group \(k\)
  • \(\mu_j\): the mean income of group \(j\)
  • \(\mu_k\): the mean income of group \(k\)
  • \(\dot\mu_j\): the mean of group \(j\) divided by the overall mean, \(\mu_j/\mu\)
  • \(\dot\mu_k\): the mean of group \(k\) divided by the overall mean, \(\mu_k/\mu\)
  • \(\rho^{*}\): the optimal partition into the chosen number of groups
  • \(P\): the social polarization index
  • \(P_W(i)\): the within-group polarization of group \(i\)
  • \(P_B(i)\): the between-group polarization of group \(i\)
  • \(\mathrm{BIP}\): Araar’s separable bipolarization index
  • \(I_L\): the Gini index of the lower half
  • \(I_U\): the Gini index of the upper half
  • \(I_g\): the Gini index of half \(g\)
  • \(I_B\): the between-group Gini index
  • \(S\): the normalized between-group spread, \(2\,I_B\)
  • \(\mu_L\): the mean income of the lower half
  • \(\mu_U\): the mean income of the upper half
  • \(W_L\): the weight of the lower half
  • \(W_U\): the weight of the upper half
  • \(q\): the population share of the lower half, at which the distribution is split

ipola estimates five polarization indices — Duclos–Esteban–Ray, Foster–Wolfson, Esteban–Gradín–Ray, a within/between social-polarization decomposition, and Araar’s separable bipolarization — each with a design-based standard error.

7.1.1 What is estimated

Duclos–Esteban–Ray (DER). The most general index, built on the identification–alienation framework: each person contributes their identification (the density of people like them, \(f(y)^{\alpha}\)) times their alienation (their average income distance to everyone else),

\[\mathrm{DER}(\alpha) \;=\; \frac{\sum_i w_i\,f(y_i)^{\alpha}\,a(y_i)}{\sum_i w_i},\qquad \overline{\mathrm{DER}}(\alpha)=\frac{\mathrm{DER}(\alpha)}{2\,\mu^{\,1-\alpha}},\]7.1

where \(a(y_i)\) is the individual alienation (a Gini-type rank term), \(f\) is the income density, and \(\alpha\in[0.25,1]\) tunes how much the identification (clustering) matters. The index is reported with its decomposition into identification, alienation and their correlation.

Foster–Wolfson (FW). A bipolarization index — the spread and bipolarity around the median \(m\),

\[\mathrm{FW} \;=\; 2\bigl[\,2\bigl(\tfrac12 - L(\tfrac12)\bigr) - I\,\bigr]\,\frac{\mu}{m},\]7.2

with \(L(\tfrac12)\) the Lorenz ordinate at the median (§3.2), \(I\) the Gini index (§3.1) and \(\mu\) the mean. It rises when the distribution hollows out in the middle and piles up on either side.

Esteban–Gradín–Ray (EGR). A group polarization index. From the Esteban–Ray form \(P^{\mathrm{ER}}=\sum_{j,k}\pi_j^{1+\alpha}\pi_k\,|\mu_j-\mu_k|\) over the groups (means \(\mu_j\), shares \(\pi_j\)), it corrects for the error of grouping a continuous distribution,

\[P^{\mathrm{EGR}} \;=\; \tfrac12\Bigl(\textstyle\sum_{j,k}\pi_j^{1+\alpha}\pi_k\,|\dot\mu_j-\dot\mu_k| \;-\; \beta\,\bigl(I(f)-I(\rho^{*})\bigr)\Bigr),\]7.3

where \(\rho^{*}\) is the optimal partition into the chosen number of groups — the one that minimises within-group inequality — \(I(f)-I(\rho^{*})\) is the grouping error, and \(\beta\ge0\) weights it. Incomes are scaled by the mean (\(\dot\mu_j=\mu_j/\mu\)).

Social polarization (ip). Decomposes the DER-type polarization into within-group and between-group components across the groups of a categorical variable,

\[P \;=\; \sum_i \bigl[\,P_W(i) + P_B(i)\,\bigr],\]7.4

\(P_W(i)\) measuring the polarization inside group \(i\) and \(P_B(i)\) the alienation between groups; each group’s population share, income share and \(P_W\)/\(P_B\) are reported (requires a group variable).

Araar separable bipolarization (bip). A bipolarization index that keeps the two ingredients of a two-pole distribution as additive parts — homogeneity within each half and spread between the halves:

\[\mathrm{BIP} \;=\; \lambda_L\,(1-I_L) \;+\; \lambda_U\,(1-I_U) \;+\; \lambda_B\,S,\qquad S \;=\; 2\,I_B \;=\; \frac{\mu_U-\mu_L}{2\mu}\;\in[0,1],\]7.5

where, splitting the population at the median, \(I_L\) and \(I_U\) are the Gini indices of the lower and upper half (so \(1-I_L\), \(1-I_U\) measure how compact each pole is), and \(S\) is the normalized between-group spread — twice the between-group Gini

\[I_B \;=\; \frac{W_L}{W}\,\frac{W_U}{W}\,\frac{|\mu_U-\mu_L|}{\mu}\]7.6

(\(W_L,W_U\) the two halves’ weights, \(\mu_L,\mu_U\) their means). The factor two normalizes the spread onto \([0,1]\), so the index attains its upper bound \(1\) at the maximally bipolar distribution — two equal, internally homogeneous blocks with the lower block at zero income (a degenerate half reads as \(I_g=0\) by continuity). The ethical weights \(\lambda_L,\lambda_U,\lambda_B\ge0\) (default \(0.25,0.25,0.5\)) trade the two-pole homogeneity against the between-pole distance. Its separability — a within part plus a between part, each an axiomatically standard index — is what distinguishes it.

7.1.2 Estimator and inference

The indices share the same design-based philosophy but differ in the machinery, because two of them involve a kernel density and one an optimal partition.

Foster–Wolfson is a survey ratio of two per-observation influences — the Gini-and-Lorenz-at-median influence over the weighted-median influence — so its standard error is the ratio linearization of §3.1.2 (with the median’s density \(f(m)\) from the kernel of §2.3.2) fed to the ultimate-cluster variance of §2.2.2. It is a pure reuse of the inequality machinery.

Duclos–Esteban–Ray needs the income density \(f(y_i)^{\alpha}\) — the identification — from a weighted Gaussian kernel (§2.3.2) at a polarization-specific bandwidth (three kernel methods trade exactness for speed on large samples). With the density plugged in, the index is a smooth function of three survey means — the (density-weighted) alienation, the mean, and the count — so its standard error is the delta method of §2.2.5 on their joint covariance (validated against a design bootstrap).

Social polarization (ip) builds, for each group, a set of linearized atoms from the group, population and complement weights; one joint ultimate-cluster covariance over all of them gives every within/between component’s design standard error by the delta method.

Araar bipolarization decomposes into eight per-observation atoms — the Gini influence of each half and the two half weights and sums — evaluated at the median split; its standard error is the delta method of §2.2.5 on their joint covariance, with the spread entering as \(2\,\hat I_B\) (so its influence carries the coefficient \(2\lambda_B\)). Because the split is at the estimated median, a ninth boundary-correction atom is added — the influence function of the person-weighted median (which is proportional to \(hs_i\,(0.5-\mathbb 1\{y_i\le m\})\)), carried with the derivative \(\partial\mathrm{BIP}/\partial q\) of the index with respect to the population share \(q\) at which the distribution is split — so no density is needed and the exact design-based variance is restored (validated against the bootstrap). That derivative is computed in closed form, at the realised split (\(m\) the boundary income, \(q\) the lower share): since \(\partial\mu_L/\partial q=(m-\mu_L)/q\), \(\partial\mu_U/\partial q=(\mu_U-m)/(1-q)\) and \(I_B=q-L(q)\),

\[\frac{\partial\mathrm{BIP}}{\partial q}=-\lambda_L\,\frac{m-\mu_L-I_L(\mu_L+m)}{q\,\mu_L} -\lambda_U\,\frac{m-\mu_U+I_U(\mu_U+m)}{(1-q)\,\mu_U}+2\lambda_B\Bigl(1-\frac{m}{\mu}\Bigr).\]7.7

Esteban–Gradín–Ray first searches for the optimal partition \(\rho^{*}\) (the grouping that minimises within-group inequality), then applies the group formula with the error correction. Because the optimal partition is a non-smooth function of the data, it has no tractable linearization; its standard error is therefore obtained by a design bootstrap (resampling PSUs within strata), or the point estimate alone if no replicates are requested.

All intervals use the design degrees of freedom and the Student-\(t\) critical value (§2.2.3).

7.1.3 Differences between distributions — dipola

dipola estimates the difference in a polarization index between two distributions. It reuses each distribution’s per-observation influence and combines them by the two-distribution rule of §2.2.3 — dependent (same dataset, the joint covariance) or independent (different datasets, the variances add), exactly as dineq (§3.1.3).

8 Poverty

  • \(g_i^{0}\): the poverty gap of observation \(i\), its shortfall \((z-y_i)_{+}\) from the line

Measuring poverty asks two distinct questions: how many people are poor, and how poor are they. Both are answered relative to a poverty line \(z\) — the level of the welfare variable below which a person is counted as poor. A household with welfare \(y_i\) below the line has a poverty gap

\[g_i^{\,0} = (z - y_i)_{+} = \max(z - y_i,\,0),\]8.1

the shortfall of its welfare from the line (zero for the non-poor). Every index in this chapter is a different way of summarising these gaps across the population, and every one is reported with a design-based standard error.

Throughout, an observation is weighted by the effective weight \(w_i = hw_i\,hs_i\) of §2.1 — the sampling weight times the household size — so that the indices count individuals, not households. This chapter begins with ipov, the estimator of the standard poverty indices; it is also the reference implementation for the poverty ratio standard error that the poverty curves and decompositions reuse.

8.1 Poverty indices — ipov

  • \(\hat P\): the FGT index, \(\hat P(z;\alpha)\)
  • \(\widehat{\mathrm{EDE}}\): the equally-distributed-equivalent FGT index, \(\hat P^{1/\alpha}\)
  • \(\hat P_{\mathrm W}\): the Watts index
  • \(\hat P_{\mathrm{SST}}\): the Sen–Shorrocks–Thon index
  • \(\hat P^{*}\): the average normalised poverty gap, among the poor only
  • \(\hat G^{*}\): the Gini index of the normalised gaps \((z-y_i)_{+}/z\)
  • \(s_i\): the line-sensitivity term of observation \(i\), for a derived line
  • \(\hat p'\): the derivative of the index with respect to the poverty line
  • \(\hat P_1\): the poverty index of the first distribution
  • \(\hat P_2\): the poverty index of the second distribution
  • \(\hat P_k\): the poverty index of distribution \(k\)

ipov estimates a family of poverty measures — the Foster–Greer–Thorbecke index and its equally-distributed-equivalent form, the Watts index, and the Sen–Shorrocks–Thon index — for one or more welfare variables, each with its standard error and confidence interval.

8.1.1 What is estimated

The Foster–Greer–Thorbecke (FGT) index. The workhorse of poverty measurement. For a poverty aversion parameter \(\alpha \ge 0\),

\[\hat P(z;\alpha) \;=\; \frac{\sum_{i} w_i\,(z - y_i)_{+}^{\,\alpha}}{\sum_{i} w_i},\]8.2

the weighted average over the whole population of the poverty gap raised to the power \(\alpha\). The parameter \(\alpha\) controls how much weight is given to the depth of poverty rather than just its incidence:

  • \(\alpha = 0\) gives the headcount ratio \(\hat P(z;0)=\sum_i w_i\,\mathbf 1\{y_i<z\}/\sum_i w_i\) — the share of the population that is poor. It counts the poor but is blind to how far below the line they are.
  • \(\alpha = 1\) gives the average poverty gap — the mean shortfall, so a poorer poor population raises the index. It measures the depth of poverty.
  • \(\alpha = 2\) gives the poverty severity — because the gap is squared, a transfer from a poor person to a poorer one lowers the index, so it is sensitive to inequality among the poor.

By default the index is normalised: the gap is divided by the line, \(((z-y_i)/z)^{\alpha}\), which makes the index scale-free and confines it to \([0,1]\) (so a headcount reads as a proportion and the \(\alpha=1\) index as an average relative gap). The option type(not) reports the raw (non- normalised) gap \((z-y_i)_{+}^{\alpha}\) instead — dividing by \(z^{\alpha}\) is simply skipped. The headcount (\(\alpha=0\)) is never normalised (there is no gap to divide).

The EDE-FGT index. For \(\alpha>0\) the equally-distributed-equivalent form re-expresses the FGT index on the scale of the poverty gap itself,

\[\widehat{\mathrm{EDE}}(z;\alpha) \;=\; \bigl(\hat P(z;\alpha)\bigr)^{1/\alpha}.\]8.3

It answers “what uniform shortfall, shared by all the poor, would give the same measured poverty as the actual distribution of gaps” — a summary in poverty-line units rather than a pure number.

The Watts index. The first distribution-sensitive poverty index. Averaging the log welfare shortfall over the poor,

\[\hat P_{\mathrm W}(z) \;=\; \frac{\sum_{i} w_i\,\log(z/y_i)\,\mathbf 1\{y_i<z\}}{\sum_{i} w_i}.\]8.4

Because \(\log(z/y)\) grows without bound as \(y\to 0\), the Watts index reacts strongly to the very poorest and, like \(\alpha=2\) FGT, respects transfers among the poor.

The Sen–Shorrocks–Thon (SST) index. A composite that folds together the three dimensions of poverty — incidence, depth and inequality among the poor —

\[\hat P_{\mathrm{SST}}(z) \;=\; \hat H \,\cdot\, \hat P^{*}\,\cdot\,\bigl(1 + \hat G^{*}\bigr),\]8.5

where \(\hat H\) is the headcount, \(\hat P^{*}\) is the average normalised poverty gap computed among the poor only, and \(\hat G^{*}\) is the Gini index of the normalised gaps \((z-y_i)_{+}/z\). The final factor \((1+\hat G^{*})\) inflates the index when the gaps are unequally distributed among the poor, so the SST index rises with the inequality of poverty and not only its average.

The poverty line. The line \(z\) can be set in two ways, and the distinction matters for the standard error (§8.1.2):

  • Explicit — a fixed number (e.g. a national line), or a per-household variable (e.g. a line that varies with household composition or region). Either way the line is fixed from outside the sample.
  • Derived — a fraction of a summary of the welfare distribution itself: opl(mean) sets \(z = \pi\,\hat\mu\), opl(median) or opl(quantile) sets \(z = \pi\,\hat Q(p)\), with the fraction \(\pi\) given by prop() (default 50 %) and the quantile order by perc(). Such a line is a relative poverty line, estimated from the same data as the index.

8.1.2 Estimator and inference

  • \(\hat P\): the chosen poverty index, the weighted mean of the contributions \(g_i\)
  • \(g_i\): the contribution of observation \(i\) to the chosen index

The common form. Write \(g_i\) for the per-observation contribution of the chosen index — the (possibly normalised) FGT gap \((z-y_i)_{+}^{\alpha}\), the headcount indicator \(\mathbf 1\{y_i<z\}\), or the Watts term \(\log(z/y_i)\mathbf 1\{y_i<z\}\). Every FGT/Watts index is then simply the weighted mean of \(g_i\),

\[\hat P \;=\; \frac{\sum_i w_i\,g_i}{\sum_i w_i},\]8.6

which is the survey ratio of §2.2.4 with numerator contribution \(hs_i\,g_i\) and denominator contribution \(hs_i\) (the sampling weight \(hw_i\) multiplying both). Its standard error is therefore the ratio linearization of §2.2.4 fed to the stratified ultimate-cluster variance of §2.2.2 — the per-observation influence being \(a_i = w_i\,(g_i - \hat P)/\sum_j w_j\). All the machinery of the poverty standard errors is this one estimator; what changes from case to case is only how the poverty line contributes to the variance.

  • \(\hat P\): the FGT index, \(\hat P(z;\alpha)\)
  • \(g_i\): the FGT contribution of observation \(i\)

Why the poverty line changes the standard error. With an explicit line, \(z\) is exogenous: it adds no sampling variability, so \(\hat P\) is just the ratio above and its standard error is the plain ratio standard error. Nothing more is needed.

A derived line is different. Here \(z = \pi\,\hat\mu\) (or \(\pi\,\hat Q(p)\)) is itself estimated from the sample, so it fluctuates from sample to sample — and its fluctuations are correlated with those of the numerator, because both are computed from the same households. Treating the line as if it were fixed would understate the standard error. The estimator must therefore account for the joint variability of the index and the line, which it does with the delta method of §2.2.5.

The key quantity is the rate at which the index responds to a small change in the line. Move the line up by a tiny amount: a few households near the line cross into poverty, and the number that cross is governed by the density of welfare at the line. Formally, the derivative of the headcount with respect to \(z\) is the density \(f(z)\); for \(\alpha>0\) it is \(\alpha\,\mathbb E\!\left[(z-y)_{+}^{\alpha-1}\right]\). Concretely the estimator forms, per observation, the index numerator \(hs_i\,g_i\) together with a line-sensitivity term that carries this density,

\[\text{(mean-based line)}\qquad s_i \;=\; \hat p'\;hs_i\,(\pi\,y_i - z),\qquad \hat p' \;=\; \begin{cases} \hat f(z) & \alpha = 0,\\[0.6ex] \alpha\,\dfrac{\sum_j w_j\,(z-y_j)_{+}^{\alpha-1}}{\sum_j w_j} & \alpha > 0, \end{cases}\]8.7

where the density \(\hat f(z)\) needed when \(\alpha=0\) is the weighted Gaussian kernel estimate of §2.3.2 (Silverman bandwidth) evaluated at the line. The index and the line estimator are then written together as a smooth function of a small set of survey means — the numerator, the line-sensitivity term \(s_i\), the line’s own estimator, and the weight totals — and the delta method of §2.2.5 turns the joint covariance of those means into the standard error. A quantile-based line carries one extra piece: because the quantile \(\hat Q(p)\) is itself estimated, its influence enters through the density at the quantile \(\hat f(\hat Q(p))\), exactly as for the quantile indices of §3.1.2.

For the point estimate DAAP always recomputes the FGT index directly at the estimated line (the ratio above); the delta-method construction supplies the standard error only. The two are consistent — the delta method linearises the very same index around the estimated line.

The Sen–Shorrocks–Thon index is rank-dependent: its \((1+\hat G^{*})\) factor is a Gini index of the poverty gaps, whose ranks are estimated and carry their own sampling variance. Its standard error therefore uses the rank-dependent (Gini-type) linearization of §2.3.4, applied to the normalised poverty gaps rather than to income — producing the per-observation influence whose ratio standard error captures the variance of the gap ranks (the same reasoning as the Gini in §3.1.2, transposed to poverty gaps).

The EDE-FGT index is a smooth transform of the FGT index, \(\widehat{\mathrm{EDE}}=\hat P^{1/\alpha}\), so it needs no new variance calculation: its standard error is the FGT standard error rescaled by the chain rule,

\[\widehat{\mathrm{SE}}\bigl(\widehat{\mathrm{EDE}}\bigr) \;=\; \frac{1}{\alpha}\,\hat P^{\,1/\alpha - 1}\,\widehat{\mathrm{SE}}(\hat P).\]8.8

Confidence intervals use the design degrees of freedom and the Student-\(t\) (or bounded) critical value of §2.2.3.

Breakdown by group. With hgroup(var) the analysis is repeated within each category of the group variable — a section per group plus a Population row — so poverty can be compared across, say, rural and urban areas. Each group is a subpopulation in the sense of §2.2.4: the group indicator restricts the contributions, and the standard error is the design variance of the restricted influence. A derived line can be taken over the whole population (rel(popul), the default) or recomputed within each group (rel(group)).

8.1.3 Differences between distributions — dipov

dipov estimates the difference \(\hat D = \hat P_2 - \hat P_1\) between the same poverty index on two distributions — the change in poverty between two years, say, or the gap between two regions. Each \(\hat P_k\) is the poverty index of §8.1.2, computed with its own poverty line (explicit or derived) and its own subpopulation; the two distributions are paired with distset. The standard error follows the two-distribution rule of §2.2.3: when the two come from the same dataset (two subpopulations, or two variables) the difference is dependent and the covariance between \(\hat P_1\) and \(\hat P_2\) is captured — both per-observation influences are placed on the shared design and the variance of their difference is taken (Student-\(t\) band); when they come from different datasets they are independent and the two variances add (normal band). This is the poverty-index counterpart of dineq (§3.1.3).

8.2 FGT curves — cfgt

  • \(\mathrm{FGT}(z)\): the FGT curve: the FGT index at the poverty line \(z\)
  • \(g_i(z)\): the FGT contribution of observation \(i\) at the line \(z\) (§8.1.1)
  • \(a_i(z)\): the influence of observation \(i\) on the ordinate at \(z\)
  • \(\mathrm{SE}(z)\): the standard error of the ordinate at \(z\)
  • \(\mathrm{FGT}_1(z)\): the FGT curve of the first distribution
  • \(\mathrm{FGT}_2(z)\): the FGT curve of the second distribution

An FGT curve plots the FGT index of §8.1 not at a single poverty line but across a whole range of lines — so one picture shows how measured poverty depends on where the line is drawn, and lets two distributions be compared at every line at once.

8.2.1 What is estimated

With the poverty-aversion parameter \(\alpha\) fixed, the curve is the FGT index as a function of the poverty line \(z\):

\[\mathrm{FGT}(z) \;=\; \hat P(z;\alpha) \;=\; \frac{\sum_i w_i\,g_i(z)}{\sum_i w_i},\]8.9

where \(g_i(z)\) is the FGT contribution of §8.1.1 (the headcount indicator \(\mathbf 1\{y_i<z\}\) for \(\alpha=0\), the poverty gap for \(\alpha>0\)). At \(\alpha=0\) the curve is the poverty-incidence curve — the cumulative distribution \(F(z)\) of welfare, whose height at \(z\) is the headcount for a line at \(z\); higher \(\alpha\) traces the depth and severity curves. It is drawn on a 101-point grid of lines \(z\) from min to max, or on the exact empirical steps.

8.2.2 Estimator and inference

At every line \(z\) the ordinate is the ipov FGT index at that line, so its standard error is the ratio standard error of §8.1.2 — the ratio linearization of §2.2.4 fed to the ultimate-cluster variance of §2.2.2, with the per-observation influence

\[a_i(z) \;=\; \frac{hw_i\bigl[\,hs_i\,g_i(z) - \mathrm{FGT}(z)\,hs_i\,\bigr]}{\sum_j hw_j\,hs_j}.\]8.10

The band is \(\mathrm{FGT}(z)\pm t_{\nu}\,\mathrm{SE}(z)\), computed separately at every \(z\) (§2.2.3). An FGT curve is thus the ipov estimator swept across the poverty line — the poverty analogue of the Lorenz curve swept across the population share (§3.2.2). Because the whole band is design-based, a curve lying entirely below another with non-overlapping bands is a poverty-dominance statement over the whole range of lines.

8.2.3 Differences between curves — dicfgt

dicfgt draws the difference \(D(z)=\mathrm{FGT}_2(z)-\mathrm{FGT}_1(z)\) between two FGT curves with a band, by the two-distribution rule of §2.2.3 at each ordinate: same dataset ⇒ dependent (the differenced influence on the shared design, Student-\(t\)), different datasets ⇒ independent (the two variances add, normal). A difference band that stays on one side of zero is a curvewise poverty- dominance test.

8.3 Poverty-gap curves — cpoverty

  • \(g(p)\): the poverty gap of the person at rank \(p\)
  • \(\mathrm{CPG}(p)\): the cumulative poverty-gap (TIP) curve at \(p\)

Where an FGT curve varies the poverty line, a poverty-gap curve fixes the line \(z\) and shows how the shortfalls are distributed across the population, ranked from poorest to richest. cpoverty draws two such curves.

8.3.1 What is estimated

Order the population by welfare and index it by the cumulative population share \(p\).

The poverty-gap profile (pg) plots the gap of the person at rank \(p\):

\[g(p) \;=\; \max\!\bigl(0,\ z - \hat Q(p)\bigr)\qquad\text{(or } 1-\hat Q(p)/z \text{ normalised),}\]8.11

with \(\hat Q(p)\) the welfare quantile (§2.3.1). It starts at the poorest person’s gap and falls to zero at the headcount, where welfare reaches the line.

The cumulative poverty-gap curve (cpg), also called the TIP curve (Jenkins–Lambert), plots the running total of gaps per capita:

\[\mathrm{CPG}(p) \;=\; \frac{1}{W}\sum_{i:\,F(y_i)\le p} w_i\,\max(0,\,z-y_i),\]8.12

the generalised-Lorenz curve of the censored gaps. It rises from the origin, is concave, and flattens at the headcount — its plateau is the average poverty gap, the \(\alpha=1\) FGT index. The “three I’s” of poverty are read straight off it: its length along \(p\) is the incidence, its height the intensity, and its curvature the inequality of gaps among the poor.

8.3.2 Estimator and inference

Both are point curves (no confidence band, as in the reference implementation): each ordinate is a weighted quantile (pg) or a cumulative weighted sum of censored gaps (cpg), on a 101-point \(p\)-grid or the exact empirical steps. For a design-based band on the poverty level at the fixed line use ipov; for a band across lines use the FGT curve above.

9 Multidimensional poverty

  • \(X_i\): the achievement vector of household \(i\), \((x_{i1},\dots,x_{iK})\)
  • \(X\): the achievements of all the households
  • \(x_{ik}\): the achievement of household \(i\) in dimension \(k\)
  • \(x_{i1}\): the achievement of household \(i\) in the first dimension
  • \(x_{iK}\): the achievement of household \(i\) in the last dimension
  • \(z_k\): the deprivation threshold of dimension \(k\)
  • \(z_1\): the deprivation threshold of the first dimension
  • \(z_K\): the deprivation threshold of the last dimension
  • \(\phi_k\): the weight of dimension \(k\)
  • \(\phi_l\): the weight of dimension \(l\)
  • \(\bar\phi_k\): the normalised weight of dimension \(k\), \(\phi_k/\sum_l\phi_l\)
  • \(P\): the multidimensional poverty index \(P(X,Z)\)
  • \(p\): the individual poverty function, \(p(X_i,Z)\)
  • \(p_i\): the poverty function of household \(i\), its contribution to total poverty
  • \(\mathrm{poor}_i\): 1 if household \(i\) is identified as multidimensionally poor
  • \(_k\): a dimension
  • \(_l\): a dimension

Poverty is rarely one number. A household can be income-poor, or deprived in schooling, health, housing or basic services — and the same headcount can hide very different bundles of deprivation. The counting approach to multidimensional poverty (Atkinson, 2003) measures deprivation in each dimension against a dimension-specific threshold, then aggregates across dimensions and across households. AURA provides two commands: imdpov estimates a family of multidimensional poverty indices — including the dual-cutoff Alkire–Foster measures — and imoda maps the overlap of deprivations across (exactly) three dimensions.

Throughout, a household \(i\) is described by its achievement vector \(X_i = (x_{i1},\dots,x_{iK})\) over \(K\) dimensions (§4.1), compared with a vector of deprivation thresholds \(Z = (z_1,\dots,z_K)\). Two building blocks recur:

  • the deprivation indicator \(\;d_{ik} = \mathbb 1\{x_{ik} < z_k\}\;\) — household \(i\) is deprived in dimension \(k\);
  • the censored normalised gap \(\;g_{ik} = \max\!\left(0,\dfrac{z_k - x_{ik}}{z_k}\right)\;\) — how far below the threshold it falls, zero if not deprived.

9.1 Multidimensional poverty indices — imdpov

  • \(\alpha\): the gap-aversion parameter (with [7], the individual-poverty parameter)
  • \(\alpha_k\): the gap power of dimension \(k\) in the multiplicative FGT index

imdpov estimates eight multidimensional poverty indices — seven scalar aggregates (Chakravarty, extended Watts, multiplicative FGT, Tsui, the intersection and union headcounts, and Bourguignon–Chakravarty) and the dual-cutoff Alkire–Foster family — each with a design-based standard error.

9.1.1 What is estimated

Every index is an additive aggregate of an individual poverty function \(p(X_i,Z)\) — household \(i\)’s contribution to total poverty — averaged with the survey weights:

\[P(X,Z) = \frac{\sum_i w_i\, p(X_i,Z)}{\sum_i w_i},\qquad w_i = hw_i\,hs_i,\]9.1

the effective weight of §2.1 (the household size \(hs_i\) makes the index per-capita). The indices differ only in the poverty function \(p\); the per-dimension weights below are written \(\phi_k\) (equal, \(\phi_k=1\), by default).

[1] Chakravarty, Mukherjee and Ranade (1998) — an additive, union index (a household counts as soon as it is deprived in one dimension):

\[p(X_i,Z) = \sum_{k=1}^{K} \phi_k\, g_{ik}^{\,\alpha},\]9.2

with \(\alpha\ge 0\) the gap-aversion parameter (\(\alpha=0\) gives the weighted count of deprivations).

[2] Extended Watts — the multidimensional Watts index:

\[p(X_i,Z) = \sum_{k=1}^{K} \phi_k\, \ln\!\frac{z_k}{\min(z_k,\,x_{ik})}.\]9.3

[3] Multiplicative FGT — an intersection index (the product vanishes unless the household is deprived in every dimension), with a per-dimension power \(\alpha_k\):

\[p(X_i,Z) = \prod_{k=1}^{K} g_{ik}^{\,\alpha_k}\, d_{ik}.\]9.4

[4] Tsui (2002) — a multiplicative intersection index, with per-dimension parameters \(b_k\):

\[p(X_i,Z) = \prod_{k=1}^{K}\!\left[\left(\frac{z_k}{\min(z_k,\,x_{ik})}\right)^{\!b_k}\!\!-1\right].\]9.5

[5] Intersection headcount — the share deprived in every dimension:

\[p(X_i,Z) = \prod_{k=1}^{K} d_{ik}.\]9.6

[6] Union headcount — the share deprived in any dimension:

\[p(X_i,Z) = 1 - \prod_{k=1}^{K}(1 - d_{ik}).\]9.7

[7] Bourguignon and Chakravarty (2003) — a CES aggregator whose across-dimension parameter \(\gamma\) sets the substitutability between dimensions, with the individual-poverty parameter \(\alpha\):

\[p(X_i,Z) = \left(\sum_{k=1}^{K} b_k\, g_{ik}^{\,\gamma}\right)^{\!\alpha/\gamma}.\]9.8

[8] Alkire and Foster (2011) — the dual-cutoff family, and the default. Beyond the within-dimension thresholds \(z_k\), a second cutoff \(\kappa\) identifies who is multidimensionally poor. Let the deprivation score be the weighted count of deprivations,

\[c_i = \sum_{k=1}^{K} \phi_k\, d_{ik},\]9.9

and identify household \(i\) as poor when it reaches the cutoff,

\[\mathrm{poor}_i = \mathbb 1\{c_i \ge \kappa\}.\]9.10

With equal weights \(\phi_k=1\), \(c_i\) is simply the number of deprived dimensions and \(\kappa\) a count (e.g. \(\kappa=2\) = deprived in at least two dimensions); the default \(\kappa=0.5\) is the union. Writing \(\bar\phi_k = \phi_k/\sum_l\phi_l\) for the normalised weights, the family reports four censored measures — censored because the non-poor contribute zero:

\[H_0 = \frac{\sum_i w_i\,\mathrm{poor}_i}{\sum_i w_i}\qquad\text{multidimensional headcount},\]9.11

\[M_0 = \frac{\sum_i w_i\,\mathrm{poor}_i\sum_k \bar\phi_k\, d_{ik}}{\sum_i w_i}\qquad\text{adjusted headcount}=H_0\cdot A,\]9.12

\[M_1 = \frac{\sum_i w_i\,\mathrm{poor}_i\sum_k \bar\phi_k\, g_{ik}}{\sum_i w_i}\qquad\text{adjusted poverty gap},\]9.13

\[M_2 = \frac{\sum_i w_i\,\mathrm{poor}_i\sum_k \bar\phi_k\, g_{ik}^{2}}{\sum_i w_i}\qquad\text{adjusted FGT severity}.\]9.14

The intensity \(A = M_0/H_0\) is the average deprivation share among the poor, so \(M_0\) combines the incidence \(H_0\) and the breadth \(A\) of poverty in one number. imdpov also decomposes \(M_0,M_1,M_2\) into each dimension’s contribution and — given a group variable — into each subgroup’s contribution.

9.1.2 Estimator and inference

Each index is a single survey ratio of its per-observation atom \(p(X_i,Z)\): the numerator is \(hs_i\,p(X_i,Z)\) and the denominator \(hs_i\), both weighted by the sampling weight \(hw_i\), so household size enters exactly as in §2.2.4. Because the thresholds \(z_k\) and the cutoff \(\kappa\) are fixed constants — unlike a derived poverty line (§8.1.2) — no line-sensitivity term is needed. The standard error is therefore the ratio linearization of §2.2.4 — the influence \(a_i = w_i(p_i - \hat P)/\sum_j w_j\) — fed to the stratified ultimate-cluster variance of §2.2.2, with the design degrees of freedom and Student-\(t\) interval of §2.2.3.

For Alkire–Foster, each of \(H_0,M_0,M_1,M_2\) is one such ratio (of \(\mathrm{poor}_i\) and of the three censored scores), and the dimension and subgroup contributions are ratios of the same atoms. A group variable (hgroup) restricts the atom to each subgroup and adds an overall population row; there is no separate subpopulation option. Note that identification uses the raw-weighted score \(c_i\) while the censored measures use the normalised weights \(\bar\phi_k\) — the two coincide with equal weights.

9.2 Multiple Overlapping Deprivation Analysis — imoda

  • \(S\): a subset of the three dimensions
  • \(c_i^S\): the number of dimensions of \(S\) in which household \(i\) is deprived
  • \(M_0^S(\kappa)\): the adjusted headcount of \(S\) at the cutoff \(\kappa\)
  • \(\kappa\): the cutoff, a number of dimensions of \(S\)
  • \(d_{il}\): the deprivation indicator of household \(i\) in dimension \(l\)

imoda looks at how deprivations overlap. Fixed to three dimensions, it reports, for every non-empty combination of them, how many people are deprived — in any of the combination, in all of it, and (Alkire–Foster) at each intermediate cutoff — so the analyst sees not just how much deprivation there is but how it clusters.

9.2.1 What is estimated

With three dimensions there are \(2^3-1 = 7\) non-empty subsets \(S\) — the three single dimensions, the three pairs, and the triple. For a subset \(S\), let \(c_i^S = \sum_{k\in S} d_{ik}\) be the number of dimensions of \(S\) in which household \(i\) is deprived. imoda reports, in percent:

Union headcount — deprived in any dimension of \(S\):

\[H^{\cup}_S = \frac{\sum_i w_i\,\mathbb 1\{c_i^S \ge 1\}}{\sum_i w_i} = \frac{\sum_i w_i\bigl[\,1-\prod_{k\in S}(1-d_{ik})\,\bigr]}{\sum_i w_i}.\]9.15

Intersection headcount — deprived in all dimensions of \(S\):

\[H^{\cap}_S = \frac{\sum_i w_i\,\mathbb 1\{c_i^S = |S|\}}{\sum_i w_i} = \frac{\sum_i w_i\prod_{k\in S} d_{ik}}{\sum_i w_i}.\]9.16

Adjusted headcount at cutoff \(\kappa\) (\(\kappa = 1,\dots,|S|\)) — the Alkire–Foster \(M_0\) restricted to \(S\):

\[M_0^S(\kappa) = \frac{\sum_i w_i\,\mathbb 1\{c_i^S \ge \kappa\}\,c_i^S}{|S|\,\sum_i w_i}.\]9.17

For a single dimension the three coincide and recover its deprivation incidence. With the detail option, each pair \(\{k,l\}\) additionally reports the four Venn regions — deprived in both, in \(k\) only, in \(l\) only, or in either — as products of the deprivation indicators and their complements (e.g. \(d_{ik}(1-d_{il})\) for “\(k\) but not \(l\)”).

9.2.2 Estimator and inference

Every cell — each union, intersection, adjusted headcount and pairwise overlap region — is an independent survey ratio, estimated by the same ratio linearization of §2.2.4 fed to the ultimate-cluster variance of §2.2.2. Results are shown in percent, with the design-based standard error printed beneath each estimate (toggled by dste), and can be broken down by a group variable. The three-dimension row — union, intersection and the three \(M_0\) cutoffs — is posted for reuse by other commands.

10 Pro-poor growth

  • \(\mu_1\): the mean income of the before distribution
  • \(\mu_2\): the mean income of the after distribution
  • \(\hat P_1\): the FGT index of the before distribution
  • \(\hat P_2\): the FGT index of the after distribution
  • \(Q_1(p)\): the quantile at \(p\) of the before distribution
  • \(Q_2(p)\): the quantile at \(p\) of the after distribution
  • \(GL(p)\): the generalised Lorenz ordinate at \(p\), \(\mu\,L(p)\) (§3.2)
  • \(GL_1(p)\): the generalised Lorenz ordinate at \(p\) of the before distribution
  • \(GL_2(p)\): the generalised Lorenz ordinate at \(p\) of the after distribution

Growth can raise average income and still leave the poor behind, or lift them faster than the mean. Pro-poor growth analysis asks not just how much a distribution grew but for whom. Two lenses are used: the primal approach fixes an income level (a poverty line) and asks how poverty fell there; the dual approach fixes a population position (a percentile) and asks how the income at that rank grew. And two benchmarks are used: absolute pro-poorness compares the actual change to no change at all, while relative pro-poorness compares it to the average growth \(\bar g\) — growth is relatively pro-poor when the poor gain more than the mean.

AURA provides four commands: ipropoor estimates scalar pro-poor indices, gicur draws the growth incidence curve, and cpropoorp / cpropoord draw the primal and dual pro-poor dominance curves.

Two distributions and their inference. All four compare a before distribution (subscript 1) and an after distribution (subscript 2), declared with distset (§3.1.3). The design-based inference follows the two-distribution rule of §2.2.3: when the two come from the same sample (dependent), the influence functions share the design and the variance of the difference keeps the cross-period covariance, with a Student-\(t\) band; when they come from different samples (independent), the two variances simply add and the band is normal. The commands differ only in the estimand’s influence function — FGT ratios (§8.1) for the primal side, quantiles and generalised Lorenz ordinates (§2.3.1, §3.2) for the dual side — each fed to the stratified ultimate-cluster variance of §2.2.2. Growth is summarised by the mean growth rate

\[\bar g = \frac{\mu_2 - \mu_1}{\mu_1} = \frac{\mu_2}{\mu_1} - 1.\]10.1

10.1 Pro-poor indices — ipropoor

  • \(\hat P_{\mathrm W,1}\): the Watts index of the before distribution
  • \(\hat P_{\mathrm W,2}\): the Watts index of the after distribution
  • \(\hat P_{\mathrm W}\): the Watts index (§8.1)
  • \(H_1\): the headcount of the before distribution

ipropoor estimates, in one pass, the mean growth rate and three pro-poor indices (each also net of growth), all with design-based standard errors.

10.1.1 What is estimated

Ravallion and Chen (2003) — the mean growth rate of the poor: the fall in the Watts index per initially poor person,

\[\mathrm{RC} = \frac{\hat P_{\mathrm W,1}(z) - \hat P_{\mathrm W,2}(z)}{H_1(z)},\]10.2

where \(\hat P_{\mathrm W}\) is the Watts poverty index (§8.1) and \(H_1\) the initial headcount. It is reported alongside \(\mathrm{RC} - \bar g\) — growth was pro-poor relative to the mean when this is positive.

Kakwani and Pernia (2000) — the pro-poor index: the actual poverty change divided by the distribution-neutral change (the change that the same growth would have produced with no change in relative inequality),

\[\mathrm{KP} = \frac{\hat P_1(z;\alpha) - \hat P_2(z;\alpha)}{\hat P_1(z;\alpha) - \hat P_1\!\bigl(z\,\mu_1/\mu_2;\ \alpha\bigr)}.\]10.3

The counterfactual in the denominator scales the line to \(z\,\mu_1/\mu_2\) — equivalently, it grows every income by \(\bar g\) and re-measures period-1 poverty. \(\mathrm{KP} > 1\) means growth was pro-poor (it cut poverty by more than a distribution-neutral growth would have); \(\mathrm{KP} < 1\) means it bypassed the poor.

Poverty-equivalent growth rate (Kakwani and Son) — the distribution-neutral growth rate that would have reduced poverty as much as the actual growth did,

\[\mathrm{PEGR} = \bar g \times \mathrm{KP},\]10.4

reported with \(\mathrm{PEGR} - \bar g\). Growth was pro-poor when \(\mathrm{PEGR} > \bar g\). The FGT parameter \(\alpha\) (default \(0\), the headcount) is common to both periods.

10.1.2 Estimator and inference

Every index is a smooth function of a handful of survey means — the two Watts/FGT/headcount numerators, the two mean-income totals — so its standard error is the delta method of §2.2.5 with the analytic gradient applied to the design covariance of those means, combined across the two distributions by the rule above (dependent = one joint covariance, Student-\(t\); independent = the two covariances add, normal). One subtlety: Kakwani–Pernia’s counterfactual line \(z\,\mu_1/\mu_2\) itself depends on the estimated means, so its influence function carries an extra term — the density of the distribution at the shifted line times the influence of \(\mu_1,\mu_2\) — the delta method taken through the moving line. The six quantities (growth rate, Ravallion–Chen and \(\mathrm{RC}-\bar g\), Kakwani–Pernia, \(\mathrm{PEGR}\) and \(\mathrm{PEGR}-\bar g\)) are posted for reuse.

  • Kakwani, N. and Pernia, E. (2000). What is pro-poor growth? Asian Development Review 18(1), 1–16. (the Kakwani–Pernia index)
  • Kakwani, N. and Son, H. (2008). Poverty equivalent growth rate. Review of Income and Wealth 54(4), 643–655. (the PEGR)

10.2 Growth incidence curve — gicur

The growth incidence curve (Ravallion and Chen, 2003) plots the growth rate of income at each percentile.

10.2.1 What is estimated

At each percentile \(p\), using the weighted quantiles \(Q_1(p),Q_2(p)\) of the two distributions (§2.3.1),

\[\mathrm{GIC}(p) = \frac{Q_2(p) - Q_1(p)}{Q_1(p)} = \frac{Q_2(p)}{Q_1(p)} - 1.\]10.5

The curve is anonymous: each period is ranked by its own income, so \(\mathrm{GIC}(p)\) is the growth of the income level found at rank \(p\), not of any fixed household. Growth was (relatively) pro-poor where the curve is downward-sloping — the poor grew faster than the rich; it is drawn with a horizontal reference line at the mean growth \(\bar g\) (distribution-neutral) and the zero line (no growth).

10.2.2 Estimator and inference

\(\mathrm{GIC}(p)\) is a smooth function of the two quantiles, whose standard error uses the influence function of a weighted quantile — which involves the reciprocal density \(1/f(Q(p))\) (the quantile is sensitive to how sparse the data are at that rank), with \(f\) a weighted Gaussian kernel (§2.3.2). The delta method then combines the two distributions by the chapter rule (dependent → one joint ultimate-cluster covariance, Student-\(t\); independent → variances add, normal), giving a pointwise confidence band along the curve.

  • Ravallion, M. and Chen, S. (2003). Measuring pro-poor growth. Economics Letters 78(1), 93–99. (the growth incidence curve)
  • Son, H. H. (2004). A note on pro-poor growth. Economics Letters 82(3), 307–314. (the cumulative / second-order counterpart)

10.3 Pro-poor curves: the primal approach — cpropoorp

  • \(D(z)\): the after FGT index at the after-line minus the before FGT index at the line \(z\)
  • \(z_2\): the after-line, which encodes the benchmark
  • \(s\): the dominance order, \(\alpha=s-1\)
  • \(g_\alpha\): the FGT contribution of order \(\alpha\), \(g_\alpha(y_i;z)\) for income \(y_i\) at the line \(z\)

cpropoorp tests pro-poorness on the income-level axis: it plots the difference between the two FGT curves across poverty lines, so that a whole range of lines is checked at once — pro-poor dominance.

10.3.1 What is estimated

Over poverty lines \(z \in [0, z^{+}]\), with the FGT parameter tied to the dominance order \(s\) by \(\alpha = s-1\) (so \(s=1\) is the headcount, \(s=2\) the poverty gap, \(s=3\) the severity), the plotted difference is

\[D(z) = \hat P_2\bigl(z_2;\ \alpha{=}s{-}1\bigr) - \hat P_1\bigl(z;\ \alpha{=}s{-}1\bigr),\]10.6

where the after-line \(z_2\) encodes the benchmark:

  • absolute (app(abs)): \(z_2 = z + \mathrm{cons}\) — the line is shifted by a fixed standard \(\mathrm{cons}\) (default \(0\), the pure poverty comparison);
  • relative (app(rel)): \(z_2 = z\,\mu_2/\mu_1\) — the line is scaled by the mean growth, so only inequality changes are tested.

The change from state 1 to state 2 is \(s\)-order pro-poor over \([0,z^{+}]\) when \(D(z) < 0\) for every line — poverty is lower at state 2 at every line up to \(z^{+}\), a robust (dominance) statement that holds for a whole class of poverty measures.

10.3.2 Estimator and inference

Each FGT ordinate is a survey ratio (numerator \(hs_i\,g_\alpha(y_i;z)\), denominator \(hs_i\)), so \(D(z)\) is a difference of two such ratios and its standard error is the ratio linearization of §8.1.2 applied to the differenced influence, fed to the ultimate-cluster variance of §2.2.2 — dependent gives a Student-\(t\) band, independent adds the two variances with a normal band. The band is drawn around the curve; where its whole confidence interval lies below zero, pro-poorness is statistically significant at that line.

10.4 Pro-poor curves: the dual approach — cpropoord

  • \(D(p)\): the difference between the after and the before distribution at the rank \(p\)
  • \(E\): the expectation
  • \(y_1\): the initial income of a household
  • \(y_2\): the final income of the same household

cpropoord tests pro-poorness on the percentile axis — the general form of the growth incidence curve. It plots a difference between the two distributions at each rank \(p \in [0,1]\) (or a chosen sub-range), at first or second order and in absolute or relative form.

10.4.1 What is estimated

First order uses the quantile \(Q(p)\); second order the generalised Lorenz ordinate \(GL(p)=\mu\,L(p)\) (§3.2). Within each order, three forms are available — the raw difference, the relative growth, and the growth net of the mean:

\[ \begin{aligned} &\text{order 1 (quantile):} && D(p)=Q_2(p)-Q_1(p), && \frac{Q_2(p)-Q_1(p)}{Q_1(p)}, && \frac{Q_2(p)}{Q_1(p)}-\frac{\mu_2}{\mu_1};\\[2pt] &\text{order 2 (gen. Lorenz):} && D(p)=GL_2(p)-GL_1(p), && \frac{GL_2(p)-GL_1(p)}{GL_1(p)}, && \frac{GL_2(p)}{GL_1(p)}-\frac{\mu_2}{\mu_1}. \end{aligned} \]10.7

The difference and relative-growth forms test absolute pro-poorness; the net-of-mean forms test relative pro-poorness. The change is \(s\)-order pro-poor over the range when \(D(p) > 0\) for every \(p\) (incomes, or their cumulated total, rose at every rank) — the mirror of the primal test. A horizontal reference line marks the mean growth \(\bar g\).

cpropoord also draws non-anonymous curves (nona): instead of ranking each period by its own income, it fixes the ranking to the initial (or final) period and tracks the growth of households at each initial rank — following the same people rather than the same positions. This needs a panel (a dependent pairing), and estimates the conditional expected income \(E[y_2\mid y_1]\) by a local-polynomial kernel smoother.

10.4.2 Estimator and inference

Each ordinate — a quantile (order 1) or a generalised Lorenz ordinate (order 2) — has a known influence function (the quantile’s involves the reciprocal density \(1/f(Q(p))\); the generalised Lorenz’s is the truncated-income contribution of §3.2). The plotted difference is a smooth function of these, so its pointwise standard error is the delta method with the analytic gradient, combined across distributions by the chapter rule (dependent → joint covariance, Student-\(t\); independent → variances add, normal). The result is a confidence band around the dual curve.

11 Poverty and targeting policies

  • \(g\): a population group (§2.1)
  • \(f_g(z)\): the welfare density of group \(g\) at the poverty line \(z\)

A transfer budget is always limited, so who receives it decides how much poverty falls. Targeting analysis asks which population groups, which income sources, or which allocation of a fixed budget cut poverty the most. AURA offers four tools: itargetg and itargetc measure the marginal poverty impact of a small transfer — to a population group or to an income component; ogtpr solves for the optimal allocation of a fixed budget across groups; and itargetg2d extends group targeting to poverty measured over two dimensions.

All four build on the FGT poverty index \(\hat P(z;\alpha)\) of §8.1. A population group is indexed by \(g\) (§2.1), with population share \(\pi_g\), mean \(\mu_g\) and group FGT \(\hat P_g(z;\alpha)\).

11.1 Targeting by population groups — itargetg

itargetg measures how a marginal transfer to a population group changes poverty — in that group and in the population as a whole.

11.1.1 What is estimated

Two transfer designs are distinguished. A lump-sum transfer gives every member of the group the same extra dollar (it lowers inequality within the group); an inequality-neutral transfer scales every income proportionally (it leaves relative inequality unchanged). Their per-capita marginal impacts on the group’s FGT index are

\[\mathrm{LST}_g = \begin{cases} -\,\dfrac{\alpha}{z}\,\hat P_g(z;\alpha-1), & \alpha\ge 1,\\[6pt] -\,f_g(z), & \alpha=0,\end{cases} \qquad \mathrm{INT}_g = \begin{cases} \dfrac{\alpha\,\bigl[\hat P_g(z;\alpha)-\hat P_g(z;\alpha-1)\bigr]}{\mu_g}, & \alpha\ge 1,\\[8pt] -\dfrac{z\,f_g(z)}{\mu_g}, & \alpha=0,\end{cases}\]11.1

where \(\hat P_g\) is the normalised FGT of §8.1 (gaps divided by \(z\)) and \(f_g(z)\) is the group’s welfare density at the line (a weighted Gaussian kernel, §2.3.2). The lump-sum impact is proportional to minus the lower-order FGT — a marginal dollar helps most where there are many people just below the line (the density, for the headcount) — while the inequality-neutral impact is scaled by the group mean, since a proportional transfer costs in proportion to income.

The impact on the group’s own poverty and the impact on population poverty are both reported: the latter is the former scaled by the group’s population share \(\pi_g\), because a transfer to group \(g\) reaches only that fraction of the population. Given a range of poverty lines, the population impact is drawn as a curve with a confidence band.

11.1.2 Estimator and inference

Each impact is a survey ratio of a per-observation atom — the FGT (or density) numerator over the size denominator — so its standard error is the ratio linearization of §2.2.4 fed to the stratified ultimate-cluster variance of §2.2.2, with the design degrees of freedom and Student-\(t\) band of §2.2.3. The density \(f_g(z)\) uses the Silverman bandwidth of §2.3.2. Over a poverty-line range the same ratio is re-estimated at each line to trace the impact curve and its band. (This ratio-linearization recipe is shared by itargetc and itargetg2d below.)

  • Duclos, J.-Y. and Araar, A. (2006). Poverty and Equity: Measurement, Policy and Estimation. Springer. (the marginal-targeting framework)
  • Besley, T. and Kanbur, R. (1988). The principle of targeting. In Including the Poor, World Bank. (targeting and marginal poverty impact)
  • Foster, J., Greer, J. and Thorbecke, E. (1984). A class of decomposable poverty measures. Econometrica 52(3), 761–766. (the FGT index)

11.2 Optimal group targeting with a fixed budget — ogtpr

ogtpr turns the question around: given a fixed budget and a set of groups, what allocation reduces poverty the most? (Araar and Tiberti, 2017.)

11.2.1 What is estimated

Every member of group \(g\) receives the same universal transfer \(\tau_g\ge 0\); the planner chooses the \(\{\tau_g\}\) to minimise population FGT poverty subject to exhausting a fixed per-capita budget \(\mathcal B\),

\[\min_{\tau_g\ge 0}\ \hat P\bigl(z;\alpha \mid \{\tau_g\}\bigr) \qquad\text{subject to}\qquad \sum_g \pi_g\,\tau_g = \mathcal B,\]11.2

where each transfer lifts a recipient’s income only up to the poverty line (a dollar given to the already non-poor buys no poverty reduction). This is a constrained optimisation, not an estimator — the results are deterministic and carry no standard errors.

The solver is a greedy rule — at each step it directs budget to the group with the highest poverty reduction per dollar spent — implemented two ways. A grid scheme (faithful to the reference algorithm) searches a uniform grid of candidate transfers per group. A grid-free adaptive scheme is exact for the two regimes: for the headcount (\(\alpha=0\)) the reduction is a staircase that jumps only when a transfer closes a household’s poverty gap, so it evaluates efficiency only at those breakpoints; for \(\alpha\ge 1\) the reduction is concave, so the optimum equalises the marginal reduction per dollar across all funded groups — a common “water level” found by tuning one scalar.

ogtpr reports, per group: the initial FGT, the population share, the optimal per-member transfer \(\tau_g\), and its per-capita cost \(\pi_g\,\tau_g\) (the costs sum to \(\mathcal B\)). It then compares the poverty reduction achieved by this group targeting to the reduction that perfect (individual) targeting would achieve with the same budget; their ratio is the targeting efficiency. A poor × targeted cross-tabulation exposes leakage (non-poor who are targeted) and undercoverage (poor who are not).

  • Araar, A. and Tiberti, L. (2017). Optimal Targeting and Poverty Reduction. PEP-PMMA Technical Note, Université Laval. (the optimal group-targeting algorithm)
  • Kanbur, R. (1987). Budgetary rules for poverty alleviation. IMF Staff Papers 34(3), 523–545. (the optimality conditions)
  • Ravallion, M. and Chao, K. (1989). Targeted policies for poverty alleviation under imperfect information: algorithms and applications. Journal of Policy Modeling 11(2), 213–224. (the water-filling solution)

11.3 Bi-dimensional targeting by group — itargetg2d

  • \(y_1\): the first welfare dimension
  • \(y_2\): the second welfare dimension
  • \(y_{1i}\): the welfare of observation \(i\) in the first dimension
  • \(y_{2i}\): the welfare of observation \(i\) in the second dimension
  • \(z_1\): the poverty line of the first dimension
  • \(z_2\): the poverty line of the second dimension

itargetg2d targets groups when poverty is measured over two dimensions jointly (Duclos, Tiberti and Araar, 2018).

11.3.1 What is estimated

For two welfare dimensions \(y_1,y_2\) with lines \(z_1,z_2\) and a common \(\alpha\), the bi-dimensional index is the multiplicative (intersection) FGT — the product of the two normalised gaps over households poor in both dimensions (§9.1),

\[\hat P_g^{2\mathrm D}(\alpha) = \frac{\sum_i w_i\left(\tfrac{z_1-y_{1i}}{z_1}\right)^{\!\alpha}\left(\tfrac{z_2-y_{2i}}{z_2}\right)^{\!\alpha}\mathbf 1\{y_{1i}<z_1,\ y_{2i}<z_2\}}{\sum_i w_i}.\]11.3

A transfer to the first dimension of group \(g\) reduces this index through three channels:

  • a direct effect on the targeted dimension;
  • an indirect effect through joint deprivation — the transfer matters more where the two deprivations are correlated, so it depends on the joint (not just marginal) distribution;
  • a spillover onto the second dimension — a dollar of income also relieves, say, a health deprivation — scaled by a spillover parameter \(\psi\).

itargetg2d estimates the total impact (direct + indirect + \(\psi\cdot\)spillover) as the “impact on population”, reports its decomposition into these channels, and — with several groups — ranks them, testing pairwise whether one group’s impact significantly exceeds another’s.

11.3.2 Estimator and inference

Each channel’s impact is a survey ratio (or, for the separable benchmark that isolates the indirect covariance term, a product of survey means handled by the delta method of §2.2.5), with standard errors from the ultimate-cluster variance of §2.2.2. Because the groups are disjoint, the impact difference between two groups is estimated by stacking both groups’ influence functions into one covariance — keeping the (zero) cross-group covariance honest — and a \(z\)-test on that difference drives the significance ranking. Lump-sum and proportional designs and cost normalisation work as in itargetg.

11.3.3 References

  • Duclos, J.-Y., Tiberti, L. and Araar, A. (2018). Multidimensional poverty targeting. Economic Development and Cultural Change 66(3), 519–554. (the bi-dimensional targeting rules and their decomposition)
  • Duclos, J.-Y., Sahn, D. E. and Younger, S. D. (2006). Robust multidimensional poverty comparisons. The Economic Journal 116(514), 943–968. (the multiplicative bi-dimensional poverty index)

11.4 Targeting by income components — itargetc

  • \(\bar P\): the normalised FGT index, \(\bar P(z;\alpha)\)

itargetc asks which income source to grow to cut poverty fastest — the twin of itargetg, with the “group” being the holders of an income component.

11.4.1 What is estimated

Total welfare is the sum of income components, \(y=\sum_j y^{(j)}\). Growing component \(j\) proportionally (by a factor \(\lambda_j\)) lowers poverty at a rate given by its consumption-dominance curve (Makdissi and Wodon, 2002): the derivative of the normalised FGT index with respect to \(\lambda_j\) is minus the CD curve,

\[\left.\frac{\partial \bar P(z;\alpha)}{\partial\lambda_j}\right|_{\lambda=1} = -\,\mathrm{CD}_j(z,\alpha).\]11.4

The CD curve is an FGT-like functional of component \(j\) evaluated among households whose total welfare falls below \(z\): for the headcount (\(\alpha=0\)) it is the holders’ welfare density at the line, and for higher orders it is the holders’ FGT of order \(\alpha-1\) scaled by \(\alpha/z\) (the derivative of the normalised gap, as in \(\mathrm{LST}\) above). Two impacts can be measured, selected by the cost-normalisation option: the per-100% impact (a full proportional growth of the component, \(=-\mathrm{CD}_j\)) or the per-dollar impact (\(=-\overline{\mathrm{CD}}^{\,j}\)), the latter dividing by the transfer cost so that components can be ranked per unit of budget. As for itargetg, an impact-on-population curve with a confidence band can be drawn over a range of poverty lines.

11.4.2 Estimator and inference

Each CD ordinate is a survey ratio of the component’s marginal-impact atom over the appropriate cost denominator, so its standard error follows the same ratio linearization as itargetg (§2.2.4 → §2.2.2 → §2.2.3). The density term (\(\alpha=0\)) uses the Silverman-bandwidth kernel of §2.3.2.

  • Makdissi, P. and Wodon, Q. (2002). Consumption dominance curves: testing for the impact of indirect tax reforms on poverty. Economics Letters 75(2), 227–235. (the consumption-dominance curve)
  • Duclos, J.-Y., Makdissi, P. and Wodon, Q. (2008). Socially improving tax reforms. International Economic Review 49(4), 1505–1537. (CD curves applied to tax-reform / component targeting)
  • Duclos, J.-Y. and Araar, A. (2006). Poverty and Equity: Measurement, Policy and Estimation. Springer. (the marginal-targeting framework)

12 Poverty elasticities

  • \(g\): a population group (§2.1)
  • \(f_g(z)\): the welfare density of group \(g\) at the poverty line \(z\)

A poverty elasticity answers a policy question in one number: by how much, in proportional terms, does poverty change when average income grows by one percent, or when inequality rises by one percent? These are the poverty vertex of the growth–inequality–poverty triangle, and they build directly on the marginal poverty impacts of §11: a uniform growth is an inequality-neutral proportional transfer to everyone, and an inequality change is a mean-preserving spread that leaves the mean untouched.

AURA provides six commands. Two give the growth and inequality elasticities in closed form, with design-based standard errors (efgtgr, efgtineq); two re-estimate them by several alternative methods as mutual cross-checks (efgtgd, efgtid); and two decompose the inequality elasticity by population group and by income source (efgtwb, efgtc). The last four report point estimates only. All use the normalised FGT index \(\hat P(z;\alpha)\) of §8.1; a group \(g\) has mean \(\mu_g\), population share \(\pi_g\) and welfare density \(f_g(z)\) at the line.

12.1 FGT elasticity with respect to growth — efgtgr

12.1.1 What is estimated

The growth elasticity of poverty measures the proportional change in the FGT index when income grows by one percent, inequality-neutrally, within a group \(g\):

\[\mathrm{GREL} = \begin{cases} -\,\dfrac{z\,f_g(z)}{H}, & \alpha=0,\\[8pt] \alpha\,\dfrac{\hat P_g(z;\alpha)-\hat P_g(z;\alpha-1)}{\hat P(z;\alpha)}, & \alpha\ge 1,\end{cases}\]12.1

where \(H=F(z)\) is the population headcount and \(\hat P(z;\alpha)\) the population FGT, so the group’s marginal effect is expressed relative to total poverty. For the headcount (\(\alpha=0\)) the elasticity is largest where many people are bunched just below the line (a high density \(f_g(z)\)); for higher orders it is the gap between the FGT of order \(\alpha\) and of order \(\alpha-1\).

12.1.2 Estimator and inference

\(\mathrm{GREL}\) is a smooth function of a few survey means — the group and population FGT numerators and the group and population sizes — so its standard error is the delta method of §2.2.5 applied to their joint ultimate-cluster covariance (§2.2.2), with the design df and Student-\(t\) interval of §2.2.3. A group variable gives one elasticity per group plus a population row.

12.2 FGT elasticity with respect to inequality — efgtineq

12.2.1 What is estimated

The inequality elasticity of poverty measures the proportional change in poverty for a one-percent rise in the Gini index coming from a spread within a group \(g\). It is a ratio of the poverty response to the inequality response:

\[\mathrm{INEL} = \frac{\text{poverty response}}{\dfrac{\pi_g\,\mu_g}{\mu}\,\dfrac{C_g}{I}},\qquad \text{poverty response} = \begin{cases} \dfrac{\pi_g\,f_g(z)\,(\mu_g-z)}{H}, & \alpha=0,\\[8pt] \alpha\,\dfrac{\hat P_g(z;\alpha)+\frac{\mu_g-z}{z}\,\hat P_g(z;\alpha-1)}{\hat P(z;\alpha)}, & \alpha\ge 1,\end{cases}\]12.2

where \(I\) is the Gini index (§3.1) and \(C_g\) is the concentration coefficient of group \(g\) — the group’s contribution to inequality, computed by replacing the complement group’s incomes with the group mean \(\mu_g\). The divisor \(\frac{\pi_g\mu_g}{\mu}\frac{C_g}{I}\) converts the within-group spread into an elasticity with respect to the overall Gini.

12.2.2 Estimator and inference

Like \(\mathrm{GREL}\), \(\mathrm{INEL}\) is a smooth function of survey means — now including two rank-based Gini/concentration influence functions (§2.3.4) for the \(C_g/I\) channel — so the delta method of §2.2.5 on the joint ultimate-cluster covariance gives its design-based standard error and Student-\(t\) interval.

12.3 Growth elasticity by alternative approaches — efgtgd

  • \(g\): the growth rate of every income, \(y\to(1+g)\,y\)

12.3.1 What is estimated

efgtgd estimates the same growth elasticity by up to four independent methods, meant to cross-check one another:

  • analytical — the closed-form derivative of §12.1 (identical to efgtgr);
  • simulated — grow every income (\(y\to(1+g)\,y\)) and take the finite change in the FGT index;
  • log-model — the closed form under a fitted log-normal income distribution (undefined for \(\alpha\ge 2\));
  • numerical — a grid-free integral of the FGT-change kernel against a kernel density estimate.

It reports the elasticity (default, normalised by the poverty level) or the semi-elasticity (an absolute change), and over a range of growth rates it can draw the elasticity as a curve. These are point estimates only — the closed-form efgtgr (§12.1) is the one that carries a standard error.

12.4 Inequality elasticity by alternative approaches — efgtid

  • \(t\): the size of the mean-preserving spread \(y\to y+t\,(y-\mu)\)

12.4.1 What is estimated

efgtid does the same for the inequality elasticity, operationalising a rise in inequality as a mean-preserving spread \(y\to y+t\,(y-\mu)\) — the mean is held fixed, so only inequality moves. It offers three methods — analytical (the closed form of §12.2), simulated (the finite change under the spread) and numerical (the grid-free kernel integral) — as an elasticity or semi-elasticity, with an optional curve over the spread size. Point estimates only.

12.5 Elasticity to within- and between-group inequality — efgtwb

12.5.1 What is estimated

efgtwb decomposes the inequality elasticity by where the inequality change occurs — within groups or between them — for a given group partition and the S-Gini of rank aversion \(\rho\). For each group, and for the within-, between- and population aggregates, it reports the population share, the marginal impact on inequality (the group’s concentration contribution to the S-Gini), the marginal impact on poverty, and their ratio — the elasticity of poverty with respect to that component of inequality. Point estimates only.

12.6 Elasticity to within- and between-source inequality — efgtc

  • \(E\): the expectation

12.6.1 What is estimated

efgtc decomposes the inequality elasticity by income source rather than by group: total income is the sum of its components, and for each source — and for the within- and between-source aggregates — it reports the income share, the marginal impact on inequality (the source’s concentration coefficient, ranked by total income), the marginal impact on poverty, and their ratio. A negative elasticity flags an equalising source: growing it reduces both inequality and poverty. Point estimates only. (For the headcount, \(\alpha=0\), the poverty impact needs the conditional mean \(E[\text{source}\mid \text{income}=z]\), estimated by a kernel regression.)

13 Decomposition

A single number — a poverty, inequality or polarization index — hides where the deprivation comes from. A decomposition attributes it to interpretable parts: to population subgroups (how much of national inequality is within regions versus between them), to income sources (how much of inequality each earnings component generates), to a growth versus a redistribution effect between two dates, or to transient versus chronic poverty over a panel. Each module reports, for every part, an absolute contribution (the parts sum to the aggregate index) and a relative contribution (its share), and — wherever the decomposition is a smooth function of survey totals — a design-based standard error (Chapter 2). The exceptions are the Shapley and residual-based splits, which are exact accounting identities and are reported as point estimates.

The sections follow the order of the Decomposition menu: the FGT family (dfgtpg, dfgts, dfgtgr, dfgtg2d, dtcpov), the Alkire-Foster multidimensional decompositions (dmdafg, dmdafs), the inequality-index decompositions (dentropyg, diginig, diginis, dsineqg, dsineqs), the regression-based decomposition (rbdineq) and the polarization decompositions (dpolag, dpolas). Two axes recur throughout: by population subgroups (hgroup()) and by income sources (a varlist of components summing to total income).

13.1 FGT poverty by population subgroups — dfgtpg

  • \(P_\alpha\): the FGT index of the population
  • \(P_{\alpha,g}\): the FGT index of subgroup \(g\), computed on its members
  • \(\phi_g\): the population share of subgroup \(g\)
  • \(G\): the number of subgroups
  • \(g\): a subgroup
  • \(g_i\): the FGT kernel of observation \(i\): its normalised gap raised to the parameter of the index, the headcount indicator when that parameter is zero
  • \(z_i\): the poverty line of observation \(i\)
  • \(s_{g,i}\): the size of observation \(i\) restricted to group \(g\), \(hs_i\,\mathbf 1(i\in g)\)

dfgtpg decomposes the FGT poverty index by an exhaustive partition of the population into groups (regions, sectors, household types…), reporting each group’s contribution to total poverty with a design-based standard error.

13.1.1 What is estimated

The FGT index is additively decomposable: with the population split into \(G\) mutually exclusive, exhaustive subgroups,

\[P_\alpha \;=\; \sum_{g=1}^{G}\phi_g\,P_{\alpha,g},\]13.1

where \(\phi_g\) is subgroup \(g\)’s population share and \(P_{\alpha,g}\) its own FGT index (the FGT of §8.1 computed on the members of \(g\)). Poverty is a weighted average of the groups’ poverty. For every subgroup the table reports:

  • the group index \(P_{\alpha,g}\);
  • the population share \(\phi_g\);
  • the absolute contribution \(\phi_g\,P_{\alpha,g}\) (the column sums to \(P_\alpha\));
  • the relative contribution \(\phi_g\,P_{\alpha,g}/P_\alpha\) (the share of total poverty borne by group \(g\), the column sums to 1);

each with an asymptotic standard error. The parameter \(\alpha\) and the poverty line carry the usual FGT meaning (§8.1); the line pline() may be a fixed value or a per-observation variable (a household-specific line, e.g. an equivalised threshold).

13.1.2 Estimator and inference

Let \(y\) be the welfare variable, \(z\) the poverty line and \(hw_i\) the sampling weight (§2.1). Write the FGT kernel \(g_i=\mathbf 1(y_i<z_i)\bigl((z_i-y_i)/z_i\bigr)^{\alpha}\) (the normalised gap; the headcount indicator at \(\alpha=0\), and a non-normalised variant \((z_i-y_i)^{\alpha}\) is also available, §8.1) and \(s_{g,i}=hs_i\,\mathbf 1(i\in g)\) for the size weight restricted to group \(g\). Each of the four reported quantities is a survey ratio (§2.2.4), so it inherits a Taylor-linearized design standard error and is printed with its SE on the line below:

\[P_{\alpha,g}=\frac{\sum_i hw_i\,s_{g,i}\,g_i}{\sum_i hw_i\,s_{g,i}},\qquad \phi_g=\frac{\sum_i hw_i\,s_{g,i}}{\sum_i hw_i\,hs_i},\qquad \phi_g P_{\alpha,g}=\frac{\sum_i hw_i\,s_{g,i}\,g_i}{\sum_i hw_i\,hs_i},\]13.2

and the relative contribution is the ratio of the group’s poverty numerator to the population’s. The Population row is \(P_\alpha\) with its own SE. Each ratio’s variance is the stratified ultimate-cluster variance of its linearized contribution (§2.2.2), reproducing Stata’s svy: ratio exactly.

13.2 FGT poverty by income sources — the Shapley split — dfgts

  • \(K\): the number of income sources
  • \(y_{k,i}\): income source \(k\) of observation \(i\)
  • \(y_i\): the total income of observation \(i\)
  • \(y_k\): income source \(k\)
  • \(v\): the characteristic function of the game: \(v(S)\) is the FGT index when only the sources in \(S\) count as income
  • \(S\): a coalition of income sources
  • \(N\): the set of all the sources
  • \(C_k\): the Shapley contribution of source \(k\)
  • \(C_j\): the Shapley contribution of source \(j\)
  • \(P_\alpha\): the FGT index, \(P_\alpha(y)\) for total income
  • \(S_k\): the income share of source \(k\), \(\mu_k/\mu\)
  • \(\mu_k\): the mean of source \(k\)
  • \(g_i\): the FGT kernel of observation \(i\), \(g_i(S)\) when only the sources in \(S\) count as income
  • \(z_i\): the poverty line of observation \(i\)
  • \(\mathrm{vega}_{k,i}\): the linearised contribution of source \(k\) for observation \(i\), its coalition kernels aggregated

dfgts decomposes the FGT poverty index into the contributions of the separate income sources (labour, agriculture, transfers…) that make up total income, using the Shapley value, with a design-based standard error for each source.

13.2.1 What is estimated

Total income is the sum of \(K\) components, \(y_i=\sum_{k=1}^{K}y_{k,i}\). dfgts asks how much each source contributes to poverty — equivalently, how much poverty each source alleviates. Poverty is maximal (everyone poor) when income is zero and falls as sources are added, so the natural cooperative game has characteristic function

\[v(S)=P_\alpha\!\Bigl(\textstyle\sum_{k\in S}y_{k}\Bigr),\qquad v(\varnothing)=1,\quad v(N)=P_\alpha(y),\]13.3

the FGT computed when only the sources in the coalition \(S\) are counted as income (with no income everybody is poor, so \(v(\varnothing)=1\)). Source \(k\)’s absolute contribution is its Shapley value

\[C_k=\sum_{S\subseteq N\setminus\{k\}}\frac{|S|!\,(K-|S|-1)!}{K!}\,\bigl[v(S\cup\{k\})-v(S)\bigr],\]13.4

the average over all orders of the drop in poverty caused by adding source \(k\). The contributions are exhaustive, \(\sum_k C_k=v(N)-v(\varnothing)=P_\alpha-1\): they sum to the total alleviation of poverty. A source that lifts people out of poverty has a negative \(C_k\) (it reduces poverty); the table also reports each source’s income share \(S_k=\mu_k/\mu\) and its relative contribution — the source’s share of the total poverty change, \(C_k/(1-P_\alpha)\) (equivalently \(-C_k/\sum_j C_j\)). Because the poverty-reducing sources have \(C_k\le0\), these relative contributions are negative and sum to \(-1\). The parameter \(\alpha\) and the line pline() carry the usual FGT meaning (§8.1).

13.2.2 Estimator and inference

The \(2^{K}\) coalition FGTs are enumerated exactly (income decompositions have few sources; dfgts caps at \(K\le20\)) with the binary-indexing Shapley algorithm of Araar and Duclos (2008). Crucially, each source’s Shapley value is a linear combination of survey ratios: for every coalition the per-household FGT kernel \(g_i(S)=\mathbf 1\!\bigl(\sum_{k\in S}y_{k,i}<z_i\bigr)\bigl((z_i-\cdot)/z_i\bigr)^{\alpha}\) is aggregated into a single linearised per-household quantity, so \(C_k=\sum_i hw_i\,\text{vega}_{k,i}/\sum_i hw_i\,hs_i\) is a survey ratio and inherits the Taylor-linearized design standard error of §2.2.4 (weight / strata / PSU from the svyset). Point estimate and SE therefore reproduce a svy: ratio on the linearised aggregate; the decomposition itself is exact.

13.3 Growth and redistribution decomposition of poverty change — dfgtgr

  • \(\Delta\): the change from period 1 to period 2: \(\Delta P=P^{(2)}-P^{(1)}\)
  • \(P_\alpha^{(1)}\): the FGT index of period 1
  • \(P_\alpha^{(2)}\): the FGT index of period 2
  • \(P^{(1)}\): the FGT index of period 1
  • \(P^{(2)}\): the FGT index of period 2
  • \(P\): the FGT index as a function of the mean and the Lorenz curve, \(P(\mu,L)\)
  • \(P^{(1)}_{s}\): period 1 rescaled to period 2’s mean, \(P(\mu_2,L_1)\)
  • \(P^{(2)}_{s}\): period 2 rescaled to period 1’s mean, \(P(\mu_1,L_2)\)
  • \(\mu_1\): the mean income of period 1
  • \(\mu_2\): the mean income of period 2
  • \(L\): a Lorenz curve
  • \(L_1\): the Lorenz curve of period 1
  • \(L_2\): the Lorenz curve of period 2
  • \(G\): the growth component, period 1 the reference
  • \(D\): the redistribution component, period 1 the reference
  • \(R\): the residue, period 1 the reference
  • \(G'\): the growth component, period 2 the reference
  • \(D'\): the redistribution component, period 2 the reference
  • \(R'\): the residue, period 2 the reference
  • \(G^{\text{Sh}}\): the Shapley growth component
  • \(D^{\text{Sh}}\): the Shapley redistribution component
  • \(V_1\): the variance of the index of sample 1
  • \(V_2\): the variance of the index of sample 2

dfgtgr decomposes the change in the FGT index between two distributions (two dates, two surveys) into a growth component and a redistribution component, with a design-based standard error for every quantity.

13.3.1 What is estimated

Between period 1 and period 2, poverty changes by \(\Delta P=P_\alpha^{(2)}-P_\alpha^{(1)}\). Datt and Ravallion (1992) attribute this change to two forces:

  • Growth — the poverty change caused by the change in the mean income, holding the relative distribution (the Lorenz curve) fixed;
  • Redistribution — the poverty change caused by the change in the Lorenz curve, holding the mean fixed.

Write \(P(\mu,L)\) for the FGT under mean \(\mu\) and Lorenz curve \(L\). Scaling every income of a period multiplies its mean and leaves its Lorenz curve unchanged; let \(P^{(1)}_{s}=P(\mu_2,L_1)\) be period 1 rescaled to period 2’s mean and \(P^{(2)}_{s}=P(\mu_1,L_2)\) be period 2 rescaled to period 1’s mean. With reference period 1,

\[\underbrace{G=P^{(1)}_{s}-P^{(1)}}_{\text{growth}},\qquad \underbrace{D=P^{(2)}_{s}-P^{(1)}}_{\text{redistribution}},\qquad \underbrace{R=\Delta P-G-D}_{\text{residue}} .\]13.5

With reference period 2 the same change is attributed instead as

\[\underbrace{G'=P^{(2)}-P^{(2)}_{s}}_{\text{growth}},\qquad \underbrace{D'=P^{(2)}-P^{(1)}_{s}}_{\text{redistribution}},\qquad \underbrace{R'=\Delta P-G'-D'}_{\text{residue}} ,\]13.6

whose residue \(R'\) mirrors \(R\). The split therefore depends on which period is the reference (the residue is the interaction between growth and redistribution). To remove that arbitrariness, the Shapley value averages the two references and has no residue:

\[G^{\text{Sh}}=\tfrac12\bigl[(P^{(1)}_{s}-P^{(1)})+(P^{(2)}-P^{(2)}_{s})\bigr],\qquad D^{\text{Sh}}=\tfrac12\bigl[(P^{(2)}_{s}-P^{(1)})+(P^{(2)}-P^{(1)}_{s})\bigr],\]13.7

with \(G^{\text{Sh}}+D^{\text{Sh}}=\Delta P\) exactly. The table reports \(P^{(1)}\), \(P^{(2)}\), \(\Delta P\) and the growth / redistribution / residue components for reference 1, reference 2 and the Shapley average.

13.3.2 Estimator and inference

Each reported quantity is a smooth function of survey means (an FGT is a survey ratio, §2.2.4; the shifted lines involve the estimated means \(\mu_1,\mu_2\)), so every component carries a Taylor-linearized standard error. The inference regime follows the two-distribution declaration (distset, §1.7):

  • independent distributions (two separate surveys) — each component’s variance combines its own within-sample design variance with an independent cross term for the other sample’s mean that enters its shifted line; a difference of two independent indices has variance \(V_1+V_2\);
  • paired distributions (both welfare variables in one frame, one design) — a single joint covariance of the linearised numerators (mean_cov) carries every cross-covariance and each SE is the delta method on it (§2.2.5).

Point estimates and independent-sample SEs are validated exact against the reference implementation.

  • Shorrocks, A. F. (2013). Decomposition procedures for distributional analysis: a unified framework based on the Shapley value. Journal of Economic Inequality 11, 99–126. (the residue-free Shapley average)

13.4 Sectoral decomposition of poverty change — dfgtg2d

  • \(\Delta\): the change from period 1 to period 2: \(\Delta P=P_\alpha^{(2)}-P_\alpha^{(1)}\)
  • \(P_\alpha^{(t)}\): the FGT index in period \(t\)
  • \(t\): a period
  • \(n_k^{(t)}\): the population share of group \(k\) in period \(t\)
  • \(n_k^{(1)}\): the population share of group \(k\) in period 1
  • \(n_k^{(2)}\): the population share of group \(k\) in period 2
  • \(P_k^{(t)}\): the FGT index within group \(k\) in period \(t\)
  • \(P_k^{(1)}\): the FGT index within group \(k\) in period 1
  • \(P_k^{(2)}\): the FGT index within group \(k\) in period 2
  • \(\bar n_k\): the mean of the two periods’ population shares of group \(k\)
  • \(\bar P_k\): the mean of the two periods’ FGT indices within group \(k\)
  • \(V_1\): the variance of the index of sample 1
  • \(V_2\): the variance of the index of sample 2

dfgtg2d decomposes the change in the FGT index between two distributions into the contributions of population subgroups (sectors) — separating movement within sectors from movement between them — with design-based standard errors.

13.4.1 What is estimated

Because the FGT is additively decomposable, \(P_\alpha^{(t)}=\sum_k n_k^{(t)}P_k^{(t)}\), where \(n_k^{(t)}\) is group \(k\)’s population share and \(P_k^{(t)}\) its within-group FGT in period \(t\). The change \(\Delta P\) therefore comes from changes in these two factors. Ravallion and Huppi (1991) split it into:

  • Poverty (intra-sectoral) — poverty changes within the groups, at fixed shares: \(\sum_k n_k^{(1)}\bigl(P_k^{(2)}-P_k^{(1)}\bigr)\);
  • Population (inter-sectoral) — the effect of the shift of population between groups, at fixed within-group poverty: \(\sum_k P_k^{(1)}\bigl(n_k^{(2)}-n_k^{(1)}\bigr)\);
  • Interaction — the cross term \(\sum_k\bigl(P_k^{(2)}-P_k^{(1)}\bigr)\bigl(n_k^{(2)}-n_k^{(1)}\bigr)\).

These are the reference-1 (initial-period) weights. With reference period 2 the final-period share and poverty carry the effects and the interaction reverses sign:

\[\text{Poverty}'=\sum_k n_k^{(2)}\bigl(P_k^{(2)}-P_k^{(1)}\bigr),\quad \text{Population}'=\sum_k P_k^{(2)}\bigl(n_k^{(2)}-n_k^{(1)}\bigr),\quad \text{Interaction}'=\sum_k\bigl(P_k^{(2)}-P_k^{(1)}\bigr)\bigl(n_k^{(1)}-n_k^{(2)}\bigr).\]13.8

As with dfgtgr the split depends on the reference period; the Shapley reference (ref(0)) is the symmetric average, replacing \(n_k^{(1)}\) by the average share \(\bar n_k=(n_k^{(1)}+n_k^{(2)})/2\) and \(P_k^{(1)}\) by \(\bar P_k=(P_k^{(1)}+P_k^{(2)})/2\), and has an interaction of exactly zero. For every group the table also reports its two population shares \(n_k^{(t)}\) and its two within-group FGTs \(P_k^{(t)}\). ref(1)/ref(2) select the initial/final reference.

13.4.2 Estimator and inference

Every share, within-group FGT and component is a survey ratio or a smooth function of survey means, so its standard error is the Taylor-linearized design variance of §2.2 honouring the svyset. The two-distribution regime follows distset: independent years give a block-diagonal covariance (\(\text{Var}=V_1+V_2\)), a paired frame a single joint covariance. Each component SE is the exact delta method of its own component function (its exact gradient on that covariance, §2.2.5) — the value a stratified-PSU bootstrap confirms.

13.5 Transient and chronic poverty — dtcpov

  • \(T\): the number of periods
  • \(_t\): a period
  • \(y_{it}\): the consumption of household \(i\) in period \(t\)
  • \(\bar y_i\): the intertemporal mean consumption of household \(i\)
  • \(N\): the number of households
  • \(P\): total poverty, the FGT index averaged over the households and the periods, \(P(\alpha,z)\)
  • \(g_\alpha\): the normalised FGT kernel, \(g_\alpha(y)=((z-y)/z)_+^{\alpha}\)
  • \(P^{C}\): chronic poverty
  • \(P^{T}\): transient poverty
  • \(\Gamma\): the panel’s equally-distributed-equivalent poverty gap, \(\Gamma(\alpha,z)=[P(\alpha,z)]^{1/\alpha}\)
  • \(\gamma_i\): the equally-distributed-equivalent gap of household \(i\) over its periods
  • \(\theta_i\): the transient gap of household \(i\), \(\gamma_i(\alpha,z)-\gamma_i(1,z)\)

dtcpov decomposes total poverty measured over a panel into a chronic component (persistent poverty) and a transient component (poverty due to income fluctuations), with design-based standard errors and optional small-\(T\) bias corrections.

13.5.1 What is estimated

With \(T\) periods of consumption \(y_{it}\) for the same households, total poverty is the FGT(\(\alpha\)) averaged over households and time, \(P=\frac1N\sum_i\frac1T\sum_t g_\alpha(y_{it})\). It splits into:

  • Chronic poverty — the FGT evaluated at each household’s intertemporal mean consumption \(\bar y_i=\frac1T\sum_t y_{it}\), i.e. the poverty a household would face if its consumption had no variability: \(P^{C}=\frac1N\sum_i g_\alpha(\bar y_i)\);
  • Transient poverty — the residual \(P^{T}=P-P^{C}\), the part of poverty caused by fluctuations around the mean.

For the squared poverty gap (\(\alpha=2\)) this split is exact and additive (Jalan and Ravallion 1998).

A second, distribution-sensitive definition (Duclos, Araar and Giles 2010) replaces the arithmetic time-average by an equally-distributed-equivalent (EDE) poverty gap, writing \(g_\alpha(y)=\bigl((z-y)/z\bigr)_+^{\alpha}\) for the normalised FGT kernel. The panel’s EDE gap is \(\Gamma(\alpha,z)=\bigl[P(\alpha,z)\bigr]^{1/\alpha}\) and each household’s own EDE gap over its \(T\) periods is

\[\gamma_i(\alpha,z)=\Bigl(\tfrac1T\textstyle\sum_t g_\alpha(y_{it})\Bigr)^{1/\alpha}.\]13.9

The household’s transient gap is the extra gap caused by variability, \(\theta_i=\gamma_i(\alpha,z)-\gamma_i(1,z)\ge0\) (zero only when consumption is constant over time), so transient poverty is \(P^{T}=\sum_i w_i\theta_i/\sum_i w_i\) and chronic poverty is the residual \(P^{C}=\Gamma(\alpha,z)-P^{T}\). For \(\alpha=2\) this reproduces the Jalan-Ravallion split above; for higher \(\alpha\) it is more sensitive to the distribution of the shortfalls.

Options: cens first censors consumption at the poverty line; because \(T\) is usually small the intertemporal mean is a noisy estimate of permanent consumption, so dtcpov offers an analytical small-\(T\) bias correction (a closed-form term using the within-household variance) and a bootstrap one (resampling the \(T\) periods of each household).

13.5.2 Estimator and inference

For the Jalan-Ravallion split, each of total, chronic and transient poverty is a survey ratio \(\sum_i hw_i\,(\cdot)_i/\sum_i hw_i\,hs_i\), so its standard error is the design-based ratio linearization of §2.2.4, reading the weight / strata / PSU from the panel’s svyset. The EDE (Duclos-Araar-Giles) components are smooth functions of several survey means and instead take a delta-method standard error (§2.2.5, svy: mean + nlcom). The bias-corrected estimates apply the analytical correction (or subtract the bootstrap bias) before the same linearization: each corrected component is a ratio of its own household values (for the chronic one, chronic + correction), so both corrections get a design-based standard error. The reported bias is the naive minus the corrected chronic component, positive when the naive estimate over-states chronic poverty, whichever correction is used. Standard errors and confidence intervals are reported at the 95% level by default (both the interval type and the level are options).

13.5.3 References

  • Jalan, J. and Ravallion, M. (1998). Transient poverty in postreform rural China. Journal of Comparative Economics 26(2), 338–357.
  • Duclos, J.-Y., Araar, A. and Giles, J. (2010). Chronic and transient poverty: measurement and estimation, with evidence from China. Journal of Development Economics 91(2), 266–277.

13.6 Alkire-Foster multidimensional poverty by population subgroups — dmdafg

  • \(X\): the Alkire–Foster index decomposed, for the whole population
  • \(X_g\): the same index of group \(g\)
  • \(G\): the number of groups
  • \(g\): a population group
  • \(c_0\): the censored deprivation share of an observation (§9.1)
  • \(c_1\): the censored gap of an observation (§9.1)
  • \(c_2\): the censored squared gap of an observation (§9.1)
  • \(w\): the weight of an observation

dmdafg decomposes the dual-cutoff Alkire-Foster multidimensional poverty indices by an exhaustive partition of the population into groups, reporting each group’s contribution with a design-based standard error.

13.6.1 What is estimated

The Alkire-Foster indices \(H_0\), \(M_0\), \(M_1\), \(M_2\) (§9.1, imdpov) are additively decomposable over any population partition,

\[X=\sum_{g=1}^{G}\pi_g\,X_g,\]13.10

where \(\pi_g\) is group \(g\)’s population share and \(X_g\) its own AF index (computed on the members of \(g\) with the same deprivation cutoffs and cross-dimension cutoff). For every group and for the whole population the table reports:

  • the population share \(\pi_g\);
  • the group index \(X_g\);
  • the absolute contribution \(\pi_g X_g\) (the column sums to \(X\));
  • the relative contribution \(\pi_g X_g/X\times100\) (in percent),

each with an asymptotic standard error. \(H_0\) is the (dual-cutoff) headcount ratio, \(M_0\) the adjusted headcount, \(M_1\) the adjusted gap and \(M_2\) the adjusted squared gap; the per-observation deprivation scores and the censored \(c_0/c_1/c_2\) are exactly those of imdpov (§9.1).

13.6.2 Estimator and inference

Each quantity is a survey ratio \(\sum(w\cdot\text{num})/\sum(w\cdot\text{den})\) — the group index over its size, the absolute contribution over the population size, the relative contribution over the population numerator — so its standard error is the Taylor ratio linearization of §2.2.4 honouring the svyset weight / strata / PSU. The per-observation AF scores are reused verbatim from imdpov, so the point estimates match imdpov computed on the whole population.

  • Alkire, S. and Foster, J. (2011). Counting and multidimensional poverty measurement. Journal of Public Economics 95(7–8), 476–487.

13.7 Alkire-Foster multidimensional poverty by dimensions — the Shapley split — dmdafs

  • \(X\): the Alkire–Foster index decomposed
  • \(v_X\): the characteristic function of the game: \(v_X(S)\) is the index \(X\) when only the dimensions in \(S\) can cause deprivation
  • \(S\): a coalition of dimensions
  • \(N\): the set of all the dimensions
  • \(n\): the number of dimensions
  • \(\phi_k\): the Shapley contribution of dimension \(k\), \(\phi_k(X)\)
  • \(\mathrm{level}_l\): \(\mathrm{level}_l(k)\) is the part of \(\phi_k\) earned at the coalition level \(l\)

dmdafs decomposes each Alkire-Foster index into the contribution of every poverty dimension using the Shapley value, so that the contributions sum exactly to the index.

13.7.1 What is estimated

The value of a coalition \(S\) of dimensions is the AF index computed as if only the dimensions in \(S\) can cause deprivation — the dimensions outside \(S\) are set to their own poverty line, so they never contribute — with the deprivation weights still normalised over the full set of dimensions and the same cross-dimension cutoff. Dimension \(k\)’s absolute contribution is its Shapley value

\[\phi_k(X)=\sum_{S\subseteq N\setminus\{k\}}\frac{|S|!\,(n-|S|-1)!}{n!}\,\bigl[v_X(S\cup\{k\})-v_X(S)\bigr],\]13.11

the average marginal effect of “switching on” dimension \(k\), and \(\sum_k\phi_k=v_X(N)=X\): the contributions are exhaustive. The relative contribution is \(\phi_k/X\). Each Shapley value further splits by the coalition level \(l\) — the position at which \(k\) enters — with \(\sum_l\text{level}_l(k)=\phi_k\), showing whether a dimension matters mostly on its own or in combination with others. The decomposition is reported for each of \(H_0\), \(M_0\), \(M_1\), \(M_2\).

13.7.2 Estimator and inference

The \(2^{n}\) coalition values reuse the per-observation deprivation and gap matrices of imdpov (§9.1), enumerated with the shared coalition engine (the exact Shapley weights \(|S|!(n-|S|-1)!/n!\), also used by dfgts, diginis, dsineqs). This is an exact accounting decomposition, so dmdafs reports point estimates only (no standard error), as in the original.

13.8 Generalised entropy by population subgroups — dentropyg

  • \(I_g\): the generalised entropy index of group \(g\), \(I_g(\theta)\)
  • \(I_B\): the generalised entropy index of the between-group distribution, \(I_B(\theta)\)
  • \(f_g\): the population share of group \(g\)
  • \(f_\theta\): the transform of \(y\) in the generalised entropy index, set by \(\theta\)
  • \(G\): the number of groups
  • \(g\): a population group
  • \(w\): the sampling weight of an observation
  • \(hs\): the size of an observation (household size)

dentropyg decomposes a Generalised Entropy inequality index into a within-group and a between-group component and attributes the within part to each subgroup, with design-based standard errors.

13.8.1 What is estimated

The Generalised Entropy index \(I(\theta)\) (§3.1) is exactly additively decomposable into inequality within the groups and inequality between them,

\[I(\theta)\;=\;\underbrace{\sum_{g=1}^{G} f_g\Bigl(\tfrac{\mu_g}{\mu}\Bigr)^{\!\theta} I_g(\theta)}_{\text{Within}} \;+\;\underbrace{I_B(\theta)}_{\text{Between}},\]13.12

where \(f_g\) is the population share of group \(g\), \(\mu_g/\mu\) its mean relative to the overall mean, \(I_g(\theta)\) its own GE index, and \(I_B(\theta)\) the GE index of the between-group distribution — the distribution obtained when every individual in a group is given that group’s mean income. For every subgroup the table reports its entropy index \(I_g\), population share \(f_g\), the weight \((\mu_g/\mu)^{\theta}\), the absolute contribution \(f_g(\mu_g/\mu)^{\theta} I_g\) (the column sums to Within) and the relative contribution (absolute \(/\,I\)); then the Within, Between and Population totals. \(\theta\) selects the member of the family (0 = mean log deviation, 1 = Theil, 2 = half the squared coefficient of variation; §3.1).

13.8.2 Estimator and inference

Each per-group quantity is a smooth function of six survey means — the group and overall values of \(\sum w\,hs\), \(\sum w\,hs\,y\) and \(\sum w\,hs\,f_\theta(y)\), with \(f_\theta(y)=\log y\) \((\theta{=}0)\), \(y\log y\) \((\theta{=}1)\) or \(y^{\theta}\) — so its point estimate and standard error follow from the delta method (mean_cov + delta_se, §2.2.5), reproducing Stata’s svy: mean followed by nlcom. The Within and Between standard errors use the linearized influence functions of the two components, which account for the estimation of the overall mean \(\mu\) and of the group means \(\mu_g\) that enter the \((\mu_g/\mu)^{\theta}\) weights; both feed the ratio linearization of §2.2. The GE moment machinery is shared with ineq (§3.1).

13.9 Gini by population subgroups — diginig

  • \(G\): the Gini index of the population
  • \(g\): a subgroup
  • \(\phi_g\): the population share of group \(g\)
  • \(s_g\): the income share of group \(g\)
  • \(G_g\): the Gini index of group \(g\)
  • \(G_B\): the between-group Gini index, each individual given the mean income of his group
  • \(R\): the overlap residue (transvariation), zero only when the groups do not overlap in income

diginig decomposes the relative or absolute Gini index by population subgroups. Because the Gini is not additively decomposable, the split carries a third, overlap term (the exact approach of Araar 2006).

13.9.1 What is estimated

For a partition into subgroups \(g\) the Gini decomposes as

\[G\;=\;\underbrace{\sum_{g}\phi_g\,s_g\,G_g}_{\text{Within}} \;+\;\underbrace{G_B}_{\text{Between}}\;+\;\underbrace{R}_{\text{Overlap}},\]13.13

where \(\phi_g\) is the population share of group \(g\), \(s_g\) its income share, \(G_g\) its own Gini, \(G_B\) the between-group inequality — the Gini of the distribution in which each individual is assigned the average income of his group — and \(R\) the residue implied by group income overlap (the transvariation term, which vanishes only when the groups do not overlap in income). For every subgroup the table reports \(G_g\), \(\phi_g\), \(s_g\), the absolute contribution \(\phi_g s_g G_g\) and the relative contribution (absolute \(/\,G\)), each with a design-based standard error; the Within / Between / Overlap aggregates are point estimates only (as in the original), and the Population row is \(G\) with its SE. type(abs) decomposes the absolute Gini \(\mu\,G\) instead of the relative one.

13.9.2 What is estimated — the group contribution

A group’s absolute contribution \(\phi_g s_g G_g\) combines three forces: how large the group is (\(\phi_g\)), how rich it is (\(s_g\), its share of total income) and how unequal it is internally (\(G_g\)). A small, poor but internally equal group contributes little; a large, rich, internally unequal one contributes much. Summing these gives the within term; the between term is the inequality that would remain if every group were internally equal (all members at the group mean); the overlap term corrects for the fact that, unlike the entropy indices, ranking individuals across overlapping groups is not additive.

13.9.3 Estimator and inference

Every per-group quantity is a smooth function of eight survey means of Gini influence-function atoms (the group-masked and full-population concentration-curve atoms of §2.3.4, together with the size and size\(\times\)income atoms), so its point estimate and standard error come from the delta method (mean_cov + delta_se, §2.2.5) — the exact gradients, as in the original, and matching svy: mean + nlcom. The overall Gini and its SE are the ratio of the concentration numerator and denominator (§2.2.4). Between is the weighted Gini of the group-mean distribution and Overlap is \(G-\text{Within}-\text{Between}\), so the three aggregates reconstruct \(G\) exactly. For the absolute Gini the denominators drop the income factor (§3.1).

13.10 Gini by income sources — diginis

  • \(K\): the number of income sources
  • \(y_k\): income source \(k\)
  • \(G\): the Gini index of total income
  • \(S_k\): the income share of source \(k\), \(\mu_k/\mu\)
  • \(\mu_k\): the mean of source \(k\)
  • \(C_k\): the concentration coefficient of source \(k\), households ranked by total income
  • \(G_k\): the Gini index of source \(k\) itself
  • \(R_k\): the Gini correlation of source \(k\) with total income, \(C_k/G_k\)
  • \(\min_k\): the minimum of source \(k\)
  • \(G'\): the Gini index of total income with every source shifted to a zero floor, \(\sum_k(y_k-\min_k)\)
  • \(v\): the characteristic function of the game: \(v(S)\) is the Gini index of the income built from the sources in \(S\)
  • \(S\): a coalition of income sources

diginis decomposes the relative (or absolute) Gini index into the contributions of the income sources that make up total income, by four approaches — Rao, Lerman-Yitzhaki, Araar and Shapley — with design-based standard errors for the first two.

13.10.1 What is estimated

Total income is the sum of \(K\) components, \(y=\sum_k y_k\). Rao’s (1969) identity decomposes the Gini exactly as

\[G=\sum_{k=1}^{K}S_k\,C_k,\]13.14

where \(S_k=\mu_k/\mu\) is source \(k\)’s income share and \(C_k\) its concentration coefficient — the pseudo-Gini of source \(k\) when households are ranked by total income (so \(C_k\) is high when the source flows disproportionately to the rich, negative when it flows to the poor). Source \(k\)’s absolute contribution is \(S_k C_k\) (the column sums to \(G\)) and its relative contribution \(S_k C_k/G\). The other two analytical approaches are algebraic re-expressions of the same absolute split:

  • Lerman-Yitzhaki (1985) writes it as \(S_k\,R_k\,G_k\), where \(G_k\) is the source’s own Gini and \(R_k=C_k/G_k\) its Gini correlation with total income — separating a source’s contribution into its size, its internal inequality and its correlation with the ranking;
  • Araar (2006) splits each source’s contribution into a variation effect (the concentration of the mean-centred source) and a constant effect \(-(\min_k/\mu)\,G'\), an exact accounting of how the source shifts the Gini.

A fourth, Shapley approach (appr(sha)) treats the Gini itself as the value of a cooperative game over the sources. type(abs) decomposes the absolute Gini \(\mu G\) instead of the relative one.

13.10.2 Estimator and inference

For the Rao and Lerman-Yitzhaki approaches every reported quantity (income share, concentration coefficient, own Gini, correlation, contributions) is a smooth function of survey means of the Gini influence-function atoms of §2.3.4 — the same concentration-curve atoms used by diginig — so its point estimate and standard error follow from the delta method (mean_cov + delta_se, §2.2.5), while the income shares, concentration coefficients and the overall Gini use the ratio linearization (§2.2.4). The Araar split is reported as point estimates. The Shapley approach evaluates the coalition value \(v(S)=G\) of the income built from the sources in \(S\) (absent sources replaced by their mean — the default, which keeps total mean income fixed — or by zero), enumerated over the \(2^K\) coalitions; its contributions sum exactly to \(G\) and it is reported as point estimates.

13.11 Inequality indices by population subgroups — the Shapley split — dsineqg

  • \(v\): the index in a reference state of the two factors, \(v(\cdot,\cdot)\)
  • \(v_{11}\): the index with both factors, \(v(1,1)=I(y)\)
  • \(v_{10}\): the index with the within-group dispersion only, \(v(1,0)\)
  • \(v_{01}\): the index with the between-group dispersion only, \(v(0,1)\)
  • \(v_{00}\): the index with neither factor, \(v(0,0)=0\)
  • \(G\): the number of groups
  • \(s\): the number of groups in a coalition
  • \(S\): in \(S\)-Gini, the single-parameter Gini index (§3.1)

dsineqg decomposes an inequality index (Gini, coefficient of variation, Atkinson or Generalised Entropy) into an inter-group and an intra-group component using the Shapley value, so that — unlike the Gini’s within/between/overlap split — the two components add up exactly with no residual.

13.11.1 What is estimated

Think of inequality as the outcome of two “factors”: the dispersion of income within groups and the dispersion of the group means between groups. Eliminating a factor means neutralising that source of dispersion, which gives four reference states of the chosen index \(I\):

\[v(1,1)=I(y)\ \text{(both)},\quad v(1,0)=I\!\bigl(y\cdot\tfrac{\mu}{\mu_g}\bigr)\ \text{(within only)},\quad v(0,1)=I(\mu_g)\ \text{(between only)},\quad v(0,0)=I(\mu)=0 .\]13.15

Here \(y\cdot\mu/\mu_g\) rescales each group to the common mean \(\mu\) (removing between-group differences, keeping within-group spread) and \(\mu_g\) replaces every income by its group mean (removing within-group spread). The Shapley value of each factor averages its marginal effect over the two elimination orders,

\[\text{Inter-Group}=\tfrac12\bigl[(v_{11}-v_{10})+(v_{01}-v_{00})\bigr],\qquad \text{Intra-Group}=\tfrac12\bigl[(v_{11}-v_{01})+(v_{10}-v_{00})\bigr],\]13.16

and, being a Shapley decomposition, \(\text{Inter}+\text{Intra}=I(y)\) exactly. The intra-group total is then decomposed a second time — a Shapley value over the \(G\) groups themselves — to show each group’s contribution to within-group inequality. The table reports the Inter-Group and Intra-Group components (absolute and relative) and, beneath them, the per-group intra-group contributions. The index is chosen with index(gini|cvar|atk|ge) (with epsilon() for Atkinson and theta() for GE; §3.1).

13.11.2 Estimator and inference

The three ingredients \(I(y)\), \(I(\mu_g)\) and \(I(y\,\mu/\mu_g)\) are computed with the weighted index formulas of §3.1 (the Gini via the descending-rank \(S\)-Gini formula, the others as weighted moments), and combined by the \(\tfrac12\)-Shapley formulas above. The per-group intra split enumerates the \(2^{G}\) group coalitions and applies the exact Shapley weights \(s!\,(G-s-1)!/G!\) (the shared coalition engine also used by the source and dimension Shapley modules). This is an exact accounting decomposition, so dsineqg reports point estimates only (no standard error), as in the original.

13.12 Inequality indices by income sources — the Shapley split — dsineqs

  • \(K\): the number of income sources
  • \(v\): the characteristic function of the game: \(v(S)\) is the index of the counterfactual income, the sources in \(S\) plus the means of the others
  • \(S\): a coalition of income sources
  • \(y_k\): income source \(k\)
  • \(\bar y_k\): the mean of source \(k\)

dsineqs decomposes any of four inequality indices — Gini, coefficient of variation, Atkinson or Generalised Entropy — into the contributions of the income sources, using the Shapley value, generalising diginis’s Shapley approach beyond the Gini.

13.12.1 What is estimated

Total income is the sum of \(K\) components. The chosen index \(I\) of total income is attributed to the sources by the Shapley value of the cooperative game whose characteristic function is

\[v(S)=I\Bigl(\textstyle\sum_{k\in S}y_k+\sum_{k\notin S}\bar y_k\Bigr),\]13.17

the index computed from a counterfactual income equal to the sum of the sources in the coalition \(S\) plus the mean of the complementary sources (method(mean), which leaves total mean income unchanged; method(zero) sets the absent sources to zero instead). Replacing a source by its mean suppresses the inequality it generates, so the Shapley value averages, over all orders, the increase in \(I\) from restoring source \(k\). Source \(k\)’s absolute contribution is that Shapley value, the contributions sum exactly to \(I\), and its relative contribution is the ratio to \(I\); the marginal contribution of each source at every coalition level is also reported, along with each source’s income share. The index is chosen with index(gini|cvar|atk|ge) (epsilon() for Atkinson, theta() for GE; §3.1).

13.12.2 Estimator and inference

dsineqs composes two existing pieces: the source-Shapley coalition engine of diginis and the weighted index formulas of ineq (§3.1). The \(2^K\) coalition indices are enumerated exactly (up to 12 income sources). Being an exact accounting decomposition, it is reported as point estimates only.

13.13 Regression-based decomposition of inequality — rbdineq

  • \(X\): the covariates, \(\{x_1,\dots,x_K\}\)
  • \(x_k\): covariate \(k\)
  • \(x_1\): the first covariate
  • \(x_K\): the last covariate
  • \(K\): the number of covariates
  • \(\hat\beta_k\): the estimated coefficient of covariate \(k\)
  • \(\hat\beta_0\): the estimated constant
  • \(\hat\varepsilon\): the residual of the regression
  • \(s_k\): the predicted component of covariate \(k\), \(\hat\beta_k x_k\)
  • \(s_0\): the constant component, \(\hat\beta_0\)
  • \(s_R\): the residual component, \(\hat\varepsilon\)
  • \(\hat y\): the fitted income
  • \(\tilde y\): the fitted income without the constant, \(\sum_k s_k\)
  • \(cs_0\): the contribution of the constant, in the analytical approach
  • \(cs_R\): the contribution of the residual, in the analytical approach
  • \(v\): the characteristic function of the game: \(v(S)\) is the index of the income rebuilt from the components in \(S\)
  • \(S\): a coalition of components
  • \(g\): the number of components

rbdineq decomposes the inequality of income into the contributions of a set of explanatory covariates, by regressing income on them and Shapley-decomposing the inequality of the predicted-income components.

13.13.1 What is estimated

Regress the welfare variable on covariates \(X=\{x_1,\dots,x_K\}\) (categorical variables become dummies with the first present modality dropped; continuous variables enter directly). The fitted model splits income into predicted components \(s_k=\hat\beta_k x_k\) plus a constant \(s_0=\hat\beta_0\) and a residual \(s_R=\hat\varepsilon\). Two model forms are offered:

  • linear, \(y=\hat\beta_0+\sum_k\hat\beta_k x_k+\hat\varepsilon\): the inequality of the fitted income \(\hat y=s_0+\sum_k s_k\) is Shapley-decomposed over the \(K\) components, and the residual receives its Fields (2003) contribution \(I(y)-I(\hat y)\);
  • semilog, \(\log y=\hat\beta_0+\sum_k\hat\beta_k x_k+\hat\varepsilon\) (income \(>0\)): the reconstructed income \(y=\exp\!\bigl(s_0+\sum_k s_k+s_R\bigr)\) recovers the actual income exactly, so the residual is itself a Shapley component and the contributions sum to the inequality of the actual income; a pure constant \(\exp(s_0)\) scales all incomes equally and so contributes nothing.

Each component’s absolute contribution is its Shapley value in the game \(v(S)=I\bigl(\text{transform}(\sum_{k\in S}s_k)\bigr)\) — the index of the income rebuilt from the components in \(S\), the absent components replaced by their mean (method(mean), the default, which re-centres the coalition sum to the full mean) or by zero (method(zero)), with \(\text{transform}=\exp\) for the semilog form and the identity for the linear one; the relative contribution is the ratio to the total. The index is chosen with index(gini|cvar|atk|ge). This is the regression-based decomposition of Fields (2003) and Morduch and Sicular (2002). DASP additionally offers an analytical approach (the Wang 2004 rules: \(I(y)=cs_0+I(\tilde y)+cs_R\) with \(cs_0=I(y)-I(\hat y)\) and \(cs_R=I(\hat y)-I(\tilde y)\), the Rao decomposition for the Gini and the Shorrocks 1982 covariance decomposition for the squared CV); rbdineq implements the Shapley route.

Zeros. The semilog form needs \(\log y\), undefined at \(y\le0\). AURA never overwrites your data to force it (no silent \(0\to1\) replacement): households with non-positive income are dropped with a visible warning for the semilog regression, and how to treat them is left to you.

13.13.2 Estimator and inference

The model is fitted by weighted least squares (the sampling weight as an analytic weight, matching a weighted regress exactly). The inequality indices reuse the weighted formulas of §3.1 and the shared coalition engine enumerates the \(2^{g}\) coalitions of the \(g\) components — the regressors, the constant and (for the semilog form) the residual — capped at 14 components; a progress bar tracks the enumeration. The decomposition is an exact accounting identity, so rbdineq is reported as point estimates only.

dpolag decomposes the Duclos-Esteban-Ray polarization index into a within-group and a between-group component (Araar 2008), attributing the within part to each population group.

13.14.1 What is estimated

The DER polarization index \(P\) — the density-weighted average alienation, with polarization sensitivity \(\alpha\) (§7, ipola) — splits exactly into

\[P=\underbrace{\sum_g \varphi_g^{\,1+\alpha}\,\psi_g^{\,1-\alpha}\,R_g\,P_g}_{\text{Within (Intra)}} +\underbrace{\tilde P}_{\text{Between (Inter)}},\]13.18

where \(\varphi_g\) is group \(g\)’s population share, \(\psi_g\) its income share, \(P_g\) its own DER index, and

\[R_g=\frac{\int a_g(x)\,\pi_g(x)\,f(x)^{1+\alpha}\,dx}{\varphi_g\int a_g(x)\,f_g(x)^{1+\alpha}\,dx}\]13.19

where \(\pi_g(x)\) is the local proportion of individuals with income \(x\) who belong to group \(g\), \(f_g\) the group’s income density and \(f\) the population’s. \(R_g\) is thus the ratio of the population density to the group density weighted over the group — it captures how much group \(g\) overlaps the rest of the distribution. 13.14.2 Estimator and inference

dpolag reuses the DER building blocks of ipola — the alienation pseudo-values and the \(\alpha\)-power Gaussian kernel density with the DASP bandwidth (_der_core). Because a group’s absolute contribution depends on \(R_g P_g\), whose density factor cancels, the contributions, deficit, surplus and between components are exact even though a very small group’s displayed DER and ratio \(R_g\) are kernel-method sensitive. The kernel-density evaluation (the slow step) drives a progress bar. This is an exact accounting decomposition — point estimates only.

13.16.1 What is estimated

Let \(X\) be gross income (households ranked by it), \(I_X\) its Gini index (§3.1), and let the total tax be the sum of \(K\) sources, \(T=\sum_{k=1}^{K}T_k\). Write \(\mu_{T_k}\), \(\mu_T\), \(\mu_X\) for the means of source \(k\), the total tax and gross income, and \(C_{T_k}\) for the concentration index of source \(k\) ranked by \(X\) (§3.1). The Kakwani index of the total tax, \(\Pi_K=C_T-I_X\) (see iprog), decomposes additively over the sources:

\[\Pi_K \;=\; \sum_{k=1}^{K}\frac{\mu_{T_k}}{\mu_T}\,\bigl(C_{T_k}-I_X\bigr). \tag{Kakwani}\]13.21

Each term is source \(k\)’s tax share \(\phi_k=\mu_{T_k}/\mu_T\) times its own Kakwani index \(C_{T_k}-I_X\): a source drives the progressivity of the whole tax in proportion to how large it is and how concentrated on the rich it falls. The Reynolds–Smolensky index, which measures the actual reduction in inequality, decomposes with the same per-source term but a different weight — the source mean over the mean of net income \(\mu_X-\mu_T\):

\[\Pi_{RS} \;=\; \sum_{k=1}^{K}\frac{\mu_{T_k}}{\mu_X-\mu_T}\,\bigl(C_{T_k}-I_X\bigr) \;=\; \frac{\mu_T}{\mu_X-\mu_T}\,\Pi_K. \tag{Reynolds–Smolensky}\]13.22

The two decompositions differ only through the constant factor \(\mu_T/(\mu_X-\mu_T)=t/(1-t)\), with \(t=\mu_T/\mu_X\) the average tax rate; a source’s relative contribution \(\phi_k(C_{T_k}-I_X)/\Pi_K\) is therefore identical under either index, and the relative contributions sum to one. The command prints, per source, the tax share, \(I_X\), \(C_{T_k}\), the absolute contribution \(\phi_k(C_{T_k}-I_X)\) (Kakwani) or \(\mu_{T_k}(C_{T_k}-I_X)/(\mu_X-\mu_T)\) (Reynolds–Smolensky), and the relative contribution; the Total row’s absolute column is the whole-tax progressivity index.

13.16.2 Estimator and inference

Every ingredient — \(I_X\) and each \(C_{T_k}\), all ranked by gross income \(X\) — is a Gini/concentration index estimated exactly as in §3.1.2, through the rank-dependent linearization of §2.3.4. Each source’s share, concentration index, absolute and relative contribution is then a smooth function of the survey means of those indices’ per-observation influences, and its standard error is the delta method of §2.2.5 on the joint ultimate-cluster covariance (§2.2.2) of the influences — ranked by \(X\) and weighted as in §2.1. The linearization carries the full concentration-index influence function, the same one iprog and ineq use; the resulting standard errors match those commands exactly and agree with a survey bootstrap, while the point estimates depend only on the data, not on the design.

14 Dominance

  • \(s\): the dominance order

A single index — a headcount, a Gini, a poverty-gap — ranks two distributions only for that index. A critic can always answer “but with a different poverty line, or a more inequality-averse measure, the ranking reverses”. A dominance comparison removes that objection: it asks whether one distribution is better than another for an entire class of measures at once — every poverty index up to a given order, every inequality-averse social-welfare function, every marginal tax reform. When dominance holds the conclusion is robust; when it does not, the ranking depends on where the threshold is drawn, and the useful output is the crossing point at which the ranking flips.

The modules of this chapter deliver both. dompov and domineq test poverty and inequality dominance between two distributions and locate the crossings (the “critical poverty lines”); dombdpov extends the poverty test to two dimensions of well-being jointly; cdomc draws the consumption-dominance curves that rank indirect-tax and subsidy reforms; cdomc2d compares two such reforms directly by the difference or ratio of their curves. Because a poverty or Lorenz dominance curve is a step or piecewise-smooth function of the ordered data, the dompov/domineq tests are exact and their crossings are reported as point estimates with no standard error; the consumption-dominance modules estimate smooth survey functionals and therefore carry design-based confidence bands (Chapter 2). The sections follow the order of the Dominance menu.

14.1 Poverty dominance — dompov

  • \(P\): the FGT curve: \(P(\zeta;\alpha)\) is the FGT index at the poverty line \(\zeta\)
  • \(P_{1}\): the FGT curve of distribution 1
  • \(P_{2}\): the FGT curve of distribution 2
  • \(\zeta\): the poverty line, as it varies along the curve
  • \(z^-\): the lower bound of the range of poverty lines
  • \(z^+\): the upper bound of the range of poverty lines
  • \(a\): the lower bound of an equality range (case C)
  • \(b\): the upper bound of an equality range (case C)

dompov tests whether one distribution has unambiguously less poverty than another over a whole range of poverty lines — for every poverty index of a given order — and, where the ranking is not robust, reports the poverty lines at which the two dominance curves cross.

14.1.1 What is estimated

For a dominance order \(s\) write \(\alpha=s-1\) and let \(P(\zeta;\alpha)\) be the FGT curve (§8.1) traced as the poverty line \(\zeta\) varies. Distribution 1 dominates distribution 2 at order \(s\) over the range \([z^-,z^+]\) if and only if

\[P_{1}(\zeta;\alpha) < P_{2}(\zeta;\alpha)\qquad\forall\,\zeta\in[z^-,z^+],\qquad \alpha=s-1 .\]14.1

Order 1 (\(\alpha=0\)) compares the headcount curves (the cumulative distribution functions); order 2 (\(\alpha=1\)) the poverty-deficit curves; order 3 (\(\alpha=2\)) the poverty-severity curves. The fundamental result (Foster–Shorrocks 1988; Atkinson 1987) is that dominance of the order-\(s\) curve is equivalent to every poverty index in a broad class — all indices additive in the normalised gap and sensitive to transfers up to order \(s\) — ranking the two distributions the same way. A single robust picture replaces an unbounded family of index-by-index comparisons.

When the curves do not dominate they cross. dompov estimates the critical poverty lines — the values of \(\zeta\) at which

\[\operatorname{sign}\!\bigl(P_{1}(\zeta-\eta;\alpha)-P_{2}(\zeta-\eta;\alpha)\bigr)= \operatorname{sign}\!\bigl(P_{2}(\zeta+\eta;\alpha)-P_{1}(\zeta+\eta;\alpha)\bigr)\]14.2

for a small \(\eta\), i.e. the poverty lines at which the difference \(P_2-P_1\) changes sign. Each row of the table is one crossing, with its critical line and the dominance case holding just below it: A (distribution 1 dominates), B (distribution 2 dominates) or C (an equality range, shown as \(a\!-\!b\)). No crossing means the single overall direction is robust; many crossings mean the ranking is fragile. The two distributions are declared with distset (§1.7); hsize1()/hsize2() weight by individuals and cond1()/cond2() restrict each side to a subpopulation.

14.1.2 Estimator and inference

The comparison is exact, so no sampling variance enters: dompov reports the crossings as point estimates. Following Araar (2006), a dominance curve does not change between two successive values of the pooled welfare vector (the ordered union of the two distributions’ welfare values), so dominance need only be checked at those grid points. Between two consecutive grid values the order-\(s\) curve has a known closed shape, which fixes how a crossing inside the interval is solved:

  • order 1 — the headcount curve is a step function; a crossing lands exactly at the next pooled observation;
  • order 2 — the deficit curve is piecewise linear; at most one crossing per interval, found by a linear equation;
  • order 3 — the severity curve is piecewise quadratic; up to two crossings per interval, found by a quadratic.

dompov forms the two FGT curves on the pooled grid (each side weighted by \(w_i=hw_i\,hs_i\), §2.1), takes their difference, and records every sign change together with the case that precedes it. Two independent surveys used as the two distributions compare a change over time; the same dataset used twice with cond1()/cond2() compares two subpopulations.

14.2 Inequality dominance — domineq

  • \(L_{1}\): the Lorenz curve of distribution 1
  • \(L_{2}\): the Lorenz curve of distribution 2
  • \(\Delta\): \(\Delta(p)=L_2(p)-L_1(p)\), the difference between the two Lorenz curves

domineq tests whether one distribution is unambiguously more (or less) unequal than another for every inequality-averse measure — a Lorenz-curve comparison — and locates the percentiles at which the curves cross.

14.2.1 What is estimated

Second-order inequality dominance is a comparison of Lorenz curves \(L(p)\) (§3.2), the share of total income held by the poorest proportion \(p\). In the DASP convention, distribution 1 inequality-dominates distribution 2 at the second order if and only if

\[L_{1}(p) \le L_{2}(p)\qquad\forall\,p\in[0,1] ,\]14.3

that is, distribution 1’s Lorenz curve lies weakly below distribution 2’s throughout — distribution 1 is the more unequal of the two (a lower Lorenz curve is farther from the line of perfect equality). By the Atkinson (1970) theorem this is equivalent to every relative inequality index — every Schur-convex, scale-invariant measure — ranking distribution 1 as at least as unequal as distribution 2. When the two Lorenz curves cross, no such index-free ranking exists, and domineq returns the intersection percentiles.

Three curve types are available (type()): the ordinary Lorenz curve (nor, relative inequality), the generalised Lorenz curve \(\mu L(p)\) (gen, which additionally embeds the mean and so ranks social welfare, Shorrocks 1983), and the absolute Lorenz curve (abs, absolute inequality). Because a Lorenz curve and a concentration curve are drawn the same way, domineq doubles as a progressivity check — comparing a tax’s or transfer’s concentration curve against the Lorenz curve of gross income (Chapter 5).

14.2.2 Estimator and inference

As with dompov the ranking is exact, so the crossings are point estimates. domineq evaluates both Lorenz (or generalised/absolute-Lorenz) curves on the pooled percentile grid of the two distributions, interpolates each curve onto that common grid, forms the difference \(\Delta(p)=L_2(p)-L_1(p)\) and solves for its sign changes by linear interpolation between adjacent grid points; the degenerate end at \(p\to 1\) (where both curves meet at 1) is excluded. Each side is weighted by \(w_i=hw_i\,hs_i\) (§2.1). The two distributions are declared with distset (§1.7); as for dompov, two surveys compare a change over time and one dataset with cond1()/cond2() compares two subpopulations.

  • Shorrocks, A. F. (1983). Ranking income distributions. Economica 50(197), 3–17. (the generalised Lorenz curve and welfare dominance)
  • Araar, A. (2006). Poverty, Inequality and Stochastic Dominance, Theory and Practice: Illustration with Burkina Faso Surveys. CIRPÉE Working Paper 06-34, Université Laval. (the discrete-data implementation and critical percentiles)

14.3 Bi-dimensional poverty dominance — dombdpov

  • \(Z\): the pair of poverty lines, \((z^1,z^2)\)
  • \(z^1\): the poverty line of dimension 1
  • \(z^2\): the poverty line of dimension 2
  • \(z^k\): the poverty line of dimension \(k\)
  • \(A\): the pair of FGT parameters, \((\alpha_1,\alpha_2)\)
  • \(\alpha_1\): the FGT parameter of dimension 1
  • \(\alpha_2\): the FGT parameter of dimension 2
  • \(\alpha_k\): the FGT parameter of dimension \(k\)
  • \(s_1\): the dominance order of dimension 1
  • \(s_2\): the dominance order of dimension 2
  • \(s_k\): the dominance order of dimension \(k\)
  • \(d\): a distribution
  • \(D\): the difference surface, \(D(Z)=\widehat P_{2}(Z)-\widehat P_{1}(Z)\)
  • \(\widehat P_{d}\): the intersection bi-dimensional FGT index of distribution \(d\), \(\widehat P_{d}(Z;A)\)
  • \(\widehat P_{1}\): the bi-dimensional index of distribution 1
  • \(\widehat P_{2}\): the bi-dimensional index of distribution 2
  • \(P_{1}\): the bi-dimensional index of distribution 1
  • \(P_{2}\): the bi-dimensional index of distribution 2
  • \(y_i^{k}\): the welfare of observation \(i\) in dimension \(k\)
  • \(x_{+}\): the positive part of a number \(x\), \(\max(x,0)\)
  • \(x\): a number
  • \(z_1^{+}\): the upper bound of the poverty lines of dimension 1
  • \(z_2^{+}\): the upper bound of the poverty lines of dimension 2
  • \(\mathrm{min}_1\): the lower bound of the grid in dimension 1
  • \(\mathrm{max}_1\): the upper bound of the grid in dimension 1
  • \(\mathrm{min}_2\): the lower bound of the grid in dimension 2
  • \(\mathrm{max}_2\): the upper bound of the grid in dimension 2
  • \(V_d\): the design variance of the index of distribution \(d\)
  • \(V_1\): the variance of the index of distribution 1
  • \(V_2\): the variance of the index of distribution 2
  • \(z_{1-\gamma}\): the standard-normal critical value at the chosen level

dombdpov extends the poverty-dominance test to two dimensions of well-being jointly — say expenditure and a health or education indicator — checking whether one distribution has less “intersection” poverty than another over a whole rectangle of dimension-specific poverty lines, with a confidence band on the difference surface.

14.3.1 What is estimated

Let the two dimensions be \(k=1,2\) with poverty lines \(Z=(z^1,z^2)\) and parameters \(A=(\alpha_1,\alpha_2)\). The intersection bi-dimensional FGT index of a distribution \(d\) counts as poor only households deprived in both dimensions, weighting each by the product of its two normalised gaps:

\[\widehat P_{d}(Z;A)=\frac{\sum_{i=1}^{n} w_i\,\Bigl[\prod_{k=1}^{2}\,(z^k-y_i^{k})_{+}^{\alpha_k}\Bigr]} {\sum_{i=1}^{n} w_i},\qquad x_{+}=\max(x,0).\]14.4

Distribution 1 dominates distribution 2 at orders \((s_1,s_2)\) over the rectangle \([0,z_1^{+}]\times[0,z_2^{+}]\) if and only if

\[P_{1}(Z;A)<P_{2}(Z;A)\qquad\forall\,Z\in[0,z_1^{+}]\times[0,z_2^{+}],\qquad \alpha_k=s_k-1 .\]14.5

dombdpov evaluates the two indices on a grid of \((z^1,z^2)\) pairs and reports the difference surface \(D(Z)=\widehat P_{2}(Z)-\widehat P_{1}(Z)\) together with a lower- and upper-bound surface: dominance of distribution 1 (less bi-dimensional poverty) holds robustly over the rectangle when the lower bound stays positive throughout. Each distribution is declared with distset (§1.7); its two dimensions, an optional household size, and a subpopulation cond() are set per side; the grid is par1+1 by par2+1 points over \([\text{min}_1,\text{max}_1]\times[\text{min}_2,\text{max}_2]\).

14.3.2 Estimator and inference

At each grid node the index \(\widehat P_d(Z;A)\) is a survey ratio (§2.2.4), so it carries a Taylor-linearized design variance \(V_d\) (the stratified ultimate-cluster variance of its linearized contribution, §2.2.2). For two independent surveys the difference \(D=\widehat P_2-\widehat P_1\) has variance \(V_1+V_2\), and the confidence surfaces are

\[D(Z)\ \mp\ z_{1-\gamma}\,\sqrt{V_1(Z)+V_2(Z)},\]14.6

with \(z_{1-\gamma}\) the standard-normal critical value at the chosen level (two-sided, lower- or upper-bounded). The three surfaces (difference, lower, upper) are rendered interactively in 3-D — AURA draws them with its own threeway engine (a solid graded surface, a wire-frame grid mesh, or a 2-D map view) rather than the external plotting tool of the original implementation — and the full grid of coordinates can be listed. The paired same-frame regime (two dimensions measured on one survey) is not covered; the reference use is the comparison of two independent surveys.

14.4 Consumption dominance curves — cdomc

  • \(CD^{j}\): the consumption-dominance curve of good \(j\), \(CD^{j}(z,s)\)
  • \(\overline{CD}^{\,j}\): the per-dollar consumption-dominance curve of good \(j\)
  • \(y^{j}\): good \(j\) (an income component)
  • \(y_i\): the welfare of observation \(i\), by which households are ranked
  • \(y_i^{j}\): the consumption of good \(j\) by observation \(i\)
  • \(K\): a (Gaussian) kernel
  • \(E\): the expectation
  • \(\overline P\): the normalised FGT index, \(\overline P(z,\alpha)\)
  • \(\lambda_j\): the price factor of good \(j\) (1 at the current price)

cdomc draws the consumption-dominance curves used to evaluate indirect-tax and subsidy reforms: each curve traces, as a function of the poverty line, the first-order impact on poverty of a marginal change in the price of a good — so that comparing two goods’ curves ranks the two reforms robustly.

14.4.1 What is estimated

For a good (income component) \(y^{j}\) and dominance order \(s\), the consumption-dominance (CD) curve is

\[CD^{j}(z,s)=\begin{cases} \dfrac{\sum_{i=1}^{n} w_i\,(z-y_i)_{+}^{\,s-2}\,y_i^{j}}{\sum_{i=1}^{n} w_i} & s\ge 2,\\[2.2ex] E\!\left[y^{j}\mid y=z\right] f(z)=\dfrac{\sum_{i=1}^{n} w_i\,K(z-y_i)\,y_i^{j}}{\sum_{i=1}^{n} w_i} & s=1, \end{cases}\]14.7

where \(y\) is the ranking welfare, \(K(\cdot)\) a kernel and dominance of order \(s\) is checked with \(\alpha=s-1\). The curve is exactly the (negative of the) derivative of the poverty index with respect to the good’s price: for the normalised FGT index \(\overline P(z,\alpha)\),

\[\left.\frac{\partial \overline P(z,\alpha)}{\partial \lambda_{j}}\right|_{\lambda_j=1}=-\,CD^{j}(z,\alpha),\]14.8

so a marginal subsidy on good \(j\) (a fall in \(\lambda_j\)) reduces poverty by \(CD^{j}(z,\alpha)\) at poverty line \(z\). Consequently, if good A’s CD curve lies above good B’s over the relevant range of poverty lines, subsidising A reduces poverty by more than subsidising B for every line in that range and every poverty measure of that order — a robust targeting conclusion; where the curves cross, the better instrument depends on the line. At order 1 the curve is the good’s consumption density-weighted at the line (\(E[y^{j}\mid y=z]\,f(z)\)); at order \(s\ge 2\) it is the marginal FGT(\(\alpha\)) kernel applied to the good.

cdomc runs in two modes: a single poverty line (pline()) returns each component’s CD impact with its standard error; a range (min()/max()) draws the CD curve of each component, optionally with a confidence band (dci) and the coordinate table (lres). cnor normalises the impact by the good’s total consumption (the per-dollar curve \(\overline{CD}^{j}\), so reforms of different-sized goods are comparable); fnor normalises the FGT by the poverty line.

14.4.2 Estimator and inference

Every point of the curve is a survey ratio (§2.2.4): the numerator is the per-household kernel \(w_i\,K(z-y_i)\,y_i^{j}\) (order 1) or \(w_i\,(z-y_i)_{+}^{s-2}\,y_i^{j}\) (order \(s\ge2\)) and the denominator the population size, so each estimate inherits a Taylor-linearized design standard error (§2.2.2) and the band is \(\text{est}\mp t\,\text{se}\) with the design degrees of freedom. The order-1 kernel is Gaussian with the Silverman bandwidth \(0.9\,\min(\text{IQR}/1.34,\ \text{SD})\,n^{-1/5}\), the spread measured with the survey weights (the weighted quartiles use the step convention of the survey summary, which matters on a masked subsample). The curve grid is the DASP fixed 100-step partition by default; AURA adds partition(native) to place a point at every distinct welfare value, in the spirit of the clorenz curves (§3.2).

  • Makdissi, P. and Wodon, Q. (2002). Consumption dominance curves: testing for the impact of indirect tax reforms on poverty. Economics Letters 75(2), 227–235. (the definition and the poverty-derivative interpretation)

14.5 Difference / ratio between consumption dominance curves — cdomc2d

  • \(CD^{1}\): the consumption-dominance curve of good 1
  • \(CD^{2}\): the consumption-dominance curve of good 2
  • \(D\): \(D(z)=CD^{2}(z)-CD^{1}(z)\), the difference between the two curves
  • \(R\): \(R(z)=CD^{2}(z)/CD^{1}(z)\), the ratio of the two curves
  • \(m_1\): the numerator of the curve of good 1
  • \(m_2\): the numerator of the curve of good 2
  • \(m_3\): the denominator of the curve of good 1
  • \(m_4\): the denominator of the curve of good 2

cdomc2d compares two goods directly: for each population group it estimates the difference (or the ratio) of their consumption-dominance curves and its confidence band, and reports the gamma critical value that summarises whether one reform robustly dominates the other.

14.5.1 What is estimated

Given two goods with CD curves \(CD^{1}\) and \(CD^{2}\) (as defined for cdomc), and a population group, cdomc2d estimates, as a function of the poverty line \(z\), either the difference or the ratio

\[D(z)=CD^{2}(z)-CD^{1}(z),\qquad\qquad R(z)=\frac{CD^{2}(z)}{CD^{1}(z)} .\]14.9

\(D(z)\ge 0\) over the range means a marginal subsidy on good 2 reduces poverty by at least as much as one on good 1 for every poverty line in that range — good 2 dominates good 1 as a poverty-reducing instrument. The comparison is reported by group (hgroup()), so the ranking of the two reforms can be read separately for each subpopulation.

In curve mode cdomc2d also reports, per group, the gamma critical value — the minimum of the curve, or (with dci) of its lower-bound band, taken over the strictly positive poverty lines. Following Araar (2006), a positive gamma certifies that the dominance of one good over the other holds over the whole range (a statistically robust conclusion), whereas a gamma that dips below zero marks a crossing where the ranking reverses. A single poverty line (pline()) instead reports the difference/ratio and its SE per group; a range (min()/max()) draws the curves with an optional band and coordinate table. At a poverty line of zero there is no poverty, so the marginal impact of every good — and hence \(D\) — is zero, while the ratio \(CD^{2}/CD^{1}=0/0\) is undefined; cdomc2d therefore returns \(\text{Estimate}=\text{SE}=0\) at \(z=0\) by convention and takes the gamma over \(z>0\) only.

14.5.2 Estimator and inference

Each of \(CD^{1}(z)\) and \(CD^{2}(z)\) is a survey ratio, so the difference or ratio of the two is a smooth function of four survey means — the two goods’ numerators and denominators. cdomc2d estimates the joint design covariance of those four means (§2.2.2) and applies the delta method (§2.2.5) to the difference \(m_2/m_4-m_1/m_3\) or the ratio \((m_2/m_4)/(m_1/m_3)\), reproducing the reference’s svy: mean … ; nlcom. The pointwise band uses the design-\(t\) critical value; for a difference the \(t\)-test against zero is the pointwise dominance test at that poverty line. The order-1 kernel and its Silverman bandwidth are those of cdomc, with the numerator household size masked to the group (and to positive consumption of the good), which shifts only the order-1 bandwidth; a difference is scaled by the percentage price change, a ratio is never scaled.

  • Araar, A. (2006). Poverty, Inequality and Stochastic Dominance, Theory and Practice: Illustration with Burkina Faso Surveys. CIRPÉE Working Paper 06-34, Université Laval. (the robust-dominance critical value)

15 Distributive tools

The measurement chapters build specialised indices; this chapter collects the general-purpose survey estimators and distributional graphics that underlie them and that are useful in their own right — means and population shares (with their differences across two distributions), kernel density and distribution curves and surfaces, quantile and income-share curves, non-parametric regression, and a stand-alone hypothesis test. Every estimator here reuses the shared machinery of Chapter 2: the effective weight \(w_i=hw_i\,hs_i\) of §2.1, the stratified ultimate-cluster variance of §2.2.2 with the design degrees of freedom of §2.2.3, the ratio and mean linearizations of §2.2.4, and — for the smoothers — the weighted quantile of §2.3.1 and the Silverman kernel bandwidth of §2.3.2.

15.1 Survey means — imean

  • \(s\): the standard deviation of the variable
  • \(P\): in \(P>|t|\), the \(p\)-value of the test
  • \(d\): the difference of the two means, \(\mu_2-\mu_1\)
  • \(\mu_1\): the mean of the variable in distribution 1
  • \(\mu_2\): the mean of the variable in distribution 2
  • \(V_1\): the variance of the mean of distribution 1
  • \(V_2\): the variance of the mean of distribution 2
  • \(df_1\): the design degrees of freedom of distribution 1
  • \(df_2\): the design degrees of freedom of distribution 2

The most basic distributive statistic: the survey-weighted mean of one or more variables, optionally broken down by a group variable.

15.1.1 What is estimated

At the individual level the mean of a variable \(y\) is the ratio of two weighted totals,

\[\hat\mu \;=\; \frac{\sum_i hw_i\,hs_i\,y_i}{\sum_i hw_i\,hs_i},\]15.1

where \(hs_i\) (the hsize household size) turns the household-level sampling weight \(hw_i\) into an individual weight, so that each person, not each household, counts once. With no hsize the estimand is the ordinary household mean. Given a group variable (hgroup), imean reports the mean within each group plus an overall Population row; several variables can be averaged at once.

15.1.2 Estimator and inference

The point estimate is the weighted ratio above. Because it is a ratio of totals, its standard error is the ratio linearization of §2.2.4 fed to the ultimate-cluster variance of §2.2.2: the per-observation influence is \(a_i=hw_i\,hs_i\,(y_i-\hat\mu)/\sum_j hw_j\,hs_j\), and \(\mathrm{SE}=\sqrt{\hat V(a_i)}\) with the confidence interval on the design degrees of freedom (§2.2.3). Under simple random sampling this collapses to \(s/\sqrt n\). The output is the AURA inference table (Estimate, Std. Err., \(t\), \(P>|t|\), CI).

15.1.3 Differences between distributions — dimean

dimean estimates the difference \(d=\mu_2-\mu_1\) of the mean of a variable across the two distributions declared with distset. Var\((d)\) follows the two-distribution rule of §2.2.3: independent samples add the two variances (\(V_1+V_2\), normal band, \(df_1+df_2\)); a dependent pairing (one aligned frame, or two id-matched frames) stacks the two mean influences on the shared design and takes the variance of their difference, so the covariance between the two means is captured. A hypothesis test test(#) reports the three \(t\)-tests of \(d\) against the null.

15.2 Population shares — iprop

  • \(g\): the categorical (group) variable
  • \(g_i\): the category of observation \(i\)
  • \(\hat\pi_k\): the population share of category \(k\)
  • \(\hat\pi_k^{(1)}\): the share of category \(k\) in the initial distribution
  • \(\hat\pi_k^{(2)}\): the share of category \(k\) in the final distribution
  • \(d\): the change in the share, \(\hat\pi_k^{(2)}-\hat\pi_k^{(1)}\)
  • \(V_1\): the variance of the share in distribution 1
  • \(V_2\): the variance of the share in distribution 2
  • \(P\): in \(P>|t|\), the \(p\)-value of the test

The distributional counterpart of a mean for a categorical variable: the share of the population falling in each of its categories.

15.2.1 What is estimated

For a group variable \(g\), the share of category \(k\) is

\[\hat\pi_k \;=\; \frac{\sum_i hw_i\,hs_i\,\mathbf 1\{g_i=k\}}{\sum_i hw_i\,hs_i},\]15.2

i.e. the survey mean of the group dummy \(\mathbf 1\{g_i=k\}\), weighted by individuals through hsize. The shares sum to one over the categories; each is an estimate of the population fraction in that group.

15.2.2 Estimator and inference

Each share is the ratio of two totals, so — exactly as for imean — its standard error is the ratio linearization of §2.2.4 through the ultimate-cluster variance of §2.2.2, with the design degrees of freedom of §2.2.3. iprop prints one row per category in the AURA inference layout (Estimate, Std. Err., \(t\), \(P>|t|\), CI).

15.2.3 Differences between distributions — diprop

diprop reports, for every category, the share in the initial and the final distribution (declared with distset) and their change \(d=\hat\pi_k^{(2)}-\hat\pi_k^{(1)}\), with its standard error. As for dimean, an independent pairing adds the two variances (\(\mathrm{SE}=\sqrt{V_1+V_2}\)) while a dependent same-frame pairing forms the exact joint linearization from the stacked ratio influences, capturing the covariance between the two shares.

15.3 Density curves — cdensity

  • \(f\): the density of welfare
  • \(\hat f\): the kernel estimate of the density, \(\hat f(x)\)
  • \(\hat f'\): the derivative of the density estimate, \(\hat f'(x)\)
  • \(x\): the welfare level at which the density is evaluated
  • \(x_i\): the welfare of observation \(i\)
  • \(K_i\): the Gaussian kernel of observation \(i\), \(K_i(x)\)
  • \(K\): the kernel function, \(K(\lambda)\)
  • \(K_i^{*}\): the renormalisation factor of observation \(i\), \(K_i^{*}(x)\)
  • \(K_i^{r}\): the reflected kernel of observation \(i\), \(K_i^{r}(x)\)
  • \(\lambda_i\): the standardised distance of observation \(i\), \((x-x_i)/h\)
  • \(\lambda\): a standardised distance
  • \(P\): the vector of powers \(P(\lambda)=(1,\lambda,\lambda^2/2!,\dots,\lambda^{s-1}/(s-1)!)\)
  • \(\psi\): the correction vector, \(\psi(x)=M^{-1}l_s\)
  • \(M\): the matrix \(\int_A^B K(\lambda)P(\lambda)P(\lambda)'\,d\lambda\)
  • \(A\): the standardised lower bound of the data, \((x-\max)/h\)
  • \(B\): the standardised upper bound of the data, \((x-\min)/h\)
  • \(l_s\): the first unit vector of length \(s\), \(l_s'=(1,0,\dots,0)\)
  • \(s\): the order of the boundary correction
  • \(d\): in \(d\lambda\), the differential
  • \(\pi\): the number \(\pi\)
  • \(y_{\min}\): the sample minimum
  • \(y_{\max}\): the sample maximum

Where a histogram bins the data, a kernel density smooths it into a continuous curve \(f(x)\) — the pointwise picture of how welfare is distributed.

15.3.1 What is estimated

The survey-weighted Gaussian kernel density estimator is

\[\hat f(x) \;=\; \frac{\sum_i w_i\,K_i(x)}{\sum_i w_i},\qquad K_i(x) = \frac{1}{h\sqrt{2\pi}}\exp\!\Bigl(-\tfrac12\,\lambda_i(x)^2\Bigr),\qquad \lambda_i(x) = \frac{x-x_i}{h},\]15.3

with \(h\) the bandwidth that controls the amount of smoothing. cdensity can also plot the derivative of the density (option type(dde)) — the exact derivative of the estimator above, which for the Gaussian kernel is

\[\hat f'(x) \;=\; \frac{\sum_i w_i\,\dfrac{x_i-x}{h^{2}}\,K_i(x)}{\sum_i w_i}\]15.4

— and either a single curve for the whole population or one curve per group (popb).

Boundary-bias correction. When welfare is bounded (e.g. non-negative), the ordinary estimator is biased near the boundary. cdensity offers, following Bearse, Canals and Rilstone, a renormalisation correction of order 1, 2 or 3,

\[\hat f(x) = \frac{\sum_i w_i\,K_i^{*}(x)\,K_i(x)}{\sum_i w_i},\qquad K_i^{*}(x) = \psi(x)'\,P\bigl(\lambda_i(x)\bigr),\]15.5

where \(P(\lambda)=(1,\lambda,\lambda^2/2!,\dots,\lambda^{s-1}/(s-1)!)\) and \(\psi(x)=M^{-1}l_s\) with \(M=\int_A^B K(\lambda)P(\lambda)P(\lambda)'\,d\lambda\), \(A=(x-\max)/h\), \(B=(x-\min)/h\) and \(l_s'=(1,0,\dots,0)\); the correction removes bias to order \(h^{s}\) (border(1), border(2), border(3)). A reflection correction (bcor(reflec)) is also available: it folds the mass that leaks past each data bound back into the estimate by adding, to every kernel, its mirror images across the sample minimum \(y_{\min}\) and maximum \(y_{\max}\),

\[K_i^{r}(x) \;=\; K\!\Bigl(\tfrac{x-x_i}{h}\Bigr) + K\!\Bigl(\tfrac{x+x_i-2\,y_{\min}}{h}\Bigr) + K\!\Bigl(\tfrac{x+x_i-2\,y_{\max}}{h}\Bigr),\]15.6

and the same reflection is applied term-by-term to the derivative when type(dde). Both corrections leave the interior of the distribution essentially unchanged and only matter near the two bounds.

15.3.2 Estimator and inference

The bandwidth defaults to the Silverman rule-of-thumb of §2.3.2 on the welfare variable, and can be overridden with bwidth. cdensity is a smoother, not an index estimator: it reports the curve (and, on request, its coordinates) rather than a standard error. The evaluation runs on a grid over the requested range.

15.4 Cumulative distribution and FGT curves — cdf

The integral counterpart of the density: the share of the population below each welfare level.

15.4.1 What is estimated

With alpha(0) (the default), cdf draws the survey-weighted empirical cumulative distribution function,

\[\hat F(z) \;=\; \frac{\sum_i hw_i\,hs_i\,\mathbf 1\{z> y_i\}}{\sum_i hw_i\,hs_i},\]15.7

the proportion of individuals with welfare below \(z\) (a strict inequality, so \(\hat F\) approaches but need not reach 1 at the top). With alpha\(\ge 1\) the curve becomes an FGT poverty curve — the average normalised poverty gap of order \(\alpha\) as a function of the poverty line \(z\) — so that a single command traces the whole family of poverty indices against the line. One curve is drawn per group (hgroup) or per variable, and dif(c1) plots the difference against the first curve.

15.4.2 Estimator and inference

Each ordinate is a weighted mean of an indicator (or of the FGT contribution), so it is exact given the data; cdf reports the curve and, on request, its coordinates. No standard error is attached (dominance inference on these curves is the province of dompov/domineq).

15.4.3 References

  • Foster, J., Greer, J. and Thorbecke, E. (1984). A class of decomposable poverty measures. Econometrica 52(3), 761–766. (the FGT curve)

15.5 Quantile curves — cquantile

  • \(\bar Q(p)\): the normalised quantile, \(Q(p)/\mu\)

The inverse of the CDF: the welfare level below which a given share of the population falls.

15.5.1 What is estimated

The quantile function at percentile \(p\) is \(Q(p)=F^{-1}(p)\), where \(p=F(y)\). For a discrete, weighted sample with observations ordered \(y_1\le\dots\le y_n\) and cumulative weight share \(F(y_i)\), cquantile reads \(Q(p)\) by linear interpolation of the sorted welfare against the cumulative weight share (pinning \(Q(0)\) to the floor when the range starts at zero). Two rescalings are offered: the normalised quantile \(\bar Q(p)=Q(p)/\mu\) (type(nor)) and the centred quantile \(Q(p)-\mu\) (type(abs)). A curve is drawn per group or per variable; dif(c1) shows the difference against the first.

15.5.2 Estimator and inference

The ordinate is the weighted quantile of §2.3.1 evaluated on a percentile grid over the requested range. Like the other curves it is a point object — a quantile curve that lies everywhere above another first-order dominates it — and carries no standard error.

15.5.3 References

  • Davidson, R. and Duclos, J.-Y. (2000). Statistical inference for stochastic dominance and for the measurement of poverty and inequality. Econometrica 68(6), 1435–1464. (the quantile function and first-order dominance)

15.6 Income shares by quantile group — quinsh

  • \(g\): a quantile group
  • \(s_g\): the income share of quantile group \(g\)

A transparent, non-parametric read on inequality: how total welfare divides between successive slices of the population.

15.6.1 What is estimated

Rank the population by welfare and split it into partition equal-population quantile groups (quartiles by default, quintiles, deciles…). The income share of group \(g\) is the fraction of total welfare it holds,

\[s_g \;=\; \frac{\sum_{i\in g} hw_i\,hs_i\,y_i}{\sum_i hw_i\,hs_i\,y_i},\]15.8

and the shares sum to one. With type(cum) the cumulative shares are reported instead (the running total up to each group — a discretised Lorenz ladder, so the last group reaches 1). The bottom-versus-top contrast is a quick complement to the Gini of §3.1 and the Lorenz curve of clorenz; vname() writes each observation’s quantile-group id back as a variable.

15.6.2 Estimator and inference

The population split uses the cumulative weight share (§2.3.1), so the groups hold equal shares of individuals; the shares are then exact ratios of weighted welfare totals. quinsh is a descriptive table, reported to fixed decimals.

  • Cowell, F. A. (2011). Measuring Inequality (3rd ed.). Oxford University Press. (quantile-group shares as an inequality description)

15.7 Non-parametric regression — cnpe

  • \(Y\): the dependent variable
  • \(X\): the conditioning variable
  • \(x\): a value of the conditioning variable, a point of the grid
  • \(x_i\): the value of the conditioning variable of observation \(i\)
  • \(E\): the expectation
  • \(\widehat{E}\): the estimated expectation
  • \(d\): in \(dE[Y\mid X=x]/dx\), the derivative
  • \(K_i\): the Gaussian kernel of observation \(i\), \(K_i(x)\)
  • \(K\): the kernel function
  • \(\alpha\): the intercept of the local fit
  • \(\beta\): the slope of the local fit
  • \(v_i\): the error of the local fit for observation \(i\)
  • \(\widehat V\): the asymptotic variance of the estimate at \(x\), \(\widehat V(x)\)
  • \(R\): \(R(K)=\int K(u)^2\,du\), the roughness of the kernel
  • \(\hat\sigma\): \(\hat\sigma^2(x)\) is the variance of the dependent variable when the conditioning variable equals \(x\)
  • \(\hat m\): \(\hat m(x)\) is the estimated mean of the dependent variable when the conditioning variable equals \(x\)
  • \(f\): the density of \(X\)
  • \(\hat f\): the kernel estimate of the density of \(X\), \(\hat f(x)\)

The conditional mean of one variable given another, estimated by kernel regression without assuming a functional form — and, on request, its local derivative.

15.7.1 What is estimated

cnpe estimates \(E[Y\mid X=x]\) (option type(npr), the default) or its derivative \(dE[Y\mid X=x]/dx\) (type(dnp)) over a grid of \(x\), weighted by \(w_i=hw_i\,hs_i\), with a Gaussian kernel \(K_i(x)=\exp(-\tfrac12((x-x_i)/h)^2)\). Two estimators are offered.

Nadaraya–Watson (approach(nw)) is the kernel-weighted local mean,

\[\widehat{E}[Y\mid X=x] \;=\; \frac{\sum_i w_i\,K_i(x)\,y_i}{\sum_i w_i\,K_i(x)}.\]15.9

Local linear/polynomial (approach(lle), the default) fits, at each \(x\), the weighted least-squares problem

\[K_i(x)^{1/2}y_i \;=\; \alpha\,K_i(x)^{1/2} + \beta\,K_i(x)^{1/2}(x_i-x) + v_i,\]15.10

whose intercept and slope are the two estimands: \(\widehat{E}[Y\mid X=x]=\alpha\) and \(\widehat{dE[Y\mid X]/dx}=\beta\). The local approach is far less biased at the boundaries. Curves may be drawn per group (hgroup) and the abscissa may be the welfare level (rtype(lvl)) or the percentile scale (rtype(prc)).

15.7.2 Estimator and inference

The bandwidth defaults to the Silverman rule of §2.3.2, with the wider \(n^{-1/7}\) rate for the derivative; band() overrides it. A confidence band (dci) uses the standard Nadaraya–Watson asymptotic variance (Härdle 1990; Fan and Gijbels 1996),

\[\widehat V(x) \;=\; \frac{R(K)\,\hat\sigma^2(x)}{n\,h\,\hat f(x)} \;=\; \frac{\sum_i w_i\,K_i(x)\,(y_i-\hat m(x))^2}{\sqrt 2\,\bigl(\sum_i w_i K_i(x)\bigr)^2} \quad\text{for the Gaussian kernel},\]15.11

which correctly widens where the data are sparse (tails, boundaries). This is a deliberate correction of the reference implementation, whose band lacks the \(1/(h\,f(x))\) scaling and is therefore too narrow in low-density regions; the point estimates and curves are identical either way. The improvement over the reference is the partition(#|native) control on the number of grid points.

15.9 Hypothesis test on an estimate — datest

  • \(\theta\): the parameter tested
  • \(\hat\theta\): the estimate
  • \(\theta_0\): the hypothesised value
  • \(\alpha\): one minus the confidence level, \(100(1-\alpha)\%\)
  • \(z\): the test statistic, \((\hat\theta-\theta_0)/\mathrm{ste}\)
  • \(\mathrm{ste}\): the standard error of the estimate, ste()
  • \(H_0\): the null hypothesis
  • \(H_1\): the alternative hypothesis
  • \(Z\): the reference random variable of the test
  • \(p\): in \(p\)-value, the probability of the test
  • \(P\): in \(P>|z|\), the two-sided \(p\)-value
  • \(c\): the critical value of the interval

A stand-alone utility — no dataset needed — for testing any estimate that has been obtained elsewhere.

15.9.1 What is estimated

Given an estimate est(), its standard error ste() and a hypothesised value \(\theta_0\) (the positional argument), datest reports the estimate with its \(100(1-\alpha)\%\) confidence interval and the three tests of the estimate against the null. The test statistic is \(z=(\hat\theta-\theta_0)/\mathrm{ste}\), referred either to the normal law (default) or the Student-\(t\) law with df() degrees of freedom (dist(tstud)); the significance level is slevel% (default 5). The three tests are written in the order of the axis, each \(H_0\) holding the equality:

\[H_0:\theta\ge\theta_0 \text{ vs } H_1:\theta<\theta_0,\qquad H_0:\theta=\theta_0 \text{ vs } H_1:\theta\ne\theta_0,\qquad H_0:\theta\le\theta_0 \text{ vs } H_1:\theta>\theta_0,\]15.14

with the \(p\)-values \(\Pr(Z<z)\), \(\Pr(|Z|>|z|)\) and \(\Pr(Z>z)\), each with its reject decision at the chosen level. The table above them tests the estimate against 0, as a table of coefficients does: its \(P>|z|\) is the two-sided \(p\)-value of \(z=\hat\theta/\mathrm{ste}\). (DASP wrote \(\Phi(z)\) there, 1.0000 for \(z=6.6\), and wrote the two one-sided tests with a strict \(H_0\) and each other’s probability; AURA corrects both.) dgr(1) draws the reference density with the critical range shaded and vertical markers at \(\hat\theta\) and \(\theta_0\).

15.9.2 Estimator and inference

The confidence interval is \(\hat\theta\pm c\cdot\mathrm{ste}\) with \(c\) the normal or Student-\(t\) critical value for the chosen level and conf() mode (two-sided, lower- or upper-bounded). datest is the natural companion to nlcom and to the difference commands, letting the analyst test a transformed or hand-computed estimate without re-running the estimation.

15.10 Disaggregating grouped data — ungroup

  • \(p_k\): the population share at the top of class \(k\)
  • \(p_{k-1}\): the population share at the top of class \(k-1\)
  • \(\mu_k\): the relative mean income of class \(k\)

ungroup generates disaggregated micro-data from aggregate distributive information. The aggregate information is a small table of cumulative income shares — the Lorenz ordinates \(L(p)\) — at a handful of population shares \(p\); for instance

Percentile \(p\) 0.10 0.30 0.50 0.60 0.90 1.00
Lorenz \(L(p)\) 0.02 0.10 0.13 0.30 0.70 1.00

The command turns that table back into a synthetic sample of individual incomes, so that any DAAP index — Gini, FGT, Lorenz and concentration curves — can be computed when only a published Lorenz table is at hand.

15.10.1 What is estimated

The user sets the total number of observations nobs to generate (1000 by default), and may in addition oversample the bottom and/or top of the distribution by asking for a given number of observations (bnobs, tnobs) over a given population percentage (pbot, ptop).

  • If only the total is set, the generated data are self-weighted — the observations are spread uniformly over percentiles.
  • If a count is set for the bottom and/or top tail, the data are not self-weighted and a weight variable _w is provided alongside the income variable _y. For example, with 1900 observations of which the bottom 10% carry 1000, the weights equal \(1/1000\) for the bottom 1000 observations and \(1/100\) for the rest (the weights being normalised to sum to one).

The generated income vector is named _y and the weight vector _w. The number of observations generated need not equal the size of the sample originally used to produce the aggregated table; ungroup cannot in itself recover the sampling errors that the original micro-data would have implied. Any size above (number of classes \(+\,1\)) is admissible, but relatively large sizes are preferable for bias reduction. The generated file is written to disk and added to the workspace; lorenz(1) overlays the Lorenz curves of the aggregated data (each individual given the mean income of its group) and of the reconstructed data as a visual check.

The slope of the Lorenz curve over a class gives its relative mean income, \(\mu_k = \bigl(L(p_k)-L(p_{k-1})\bigr)/(p_k-p_{k-1})\), which is the target the reconstruction must reproduce.

15.10.2 Estimator and inference

Two stages, following Shorrocks & Wan (2009), produce the sample.

15.10.2.1 Stage I — an initial distribution of incomes and percentiles

  • \(n\): the number of observations generated (nobs)
  • \(F\): the vector of the generated percentiles
  • \(F_i\): the percentile of observation \(i\)
  • \(p_{bot}\): the population share of the oversampled bottom
  • \(p_{top}\): the population share of the oversampled top

I.1 — the percentile grid. From the requested total and any bottom/top counts, a vector of percentiles \(F\) is generated. With nobs \(=n\) spread equally, the midpoints \(F_i=(i-\tfrac12)/n\) are used (the shift by \(0.5/n\) avoids \(F=1\) at the last point). When a tail is oversampled, its observations are packed into \([0,p_{bot}]\) (bottom) or \([1-p_{top},1]\) (top) with a finer step, the middle covering \([p_{bot},1-p_{top}]\); each observation’s weight equals its percentile step, and the weights sum to one.

  • \(F\): the vector of the generated percentiles
  • \(m\): the number of classes
  • \(x\): an income
  • \(\mu\): the mean of log income, in the log-normal form
  • \(\sigma\): the standard deviation of log income

I.2 — the parametric form. The chosen form is fitted to the tabulated Lorenz curve and evaluated on \(F\); \(m\) is the number of classes.

Log-normal (lnorm, default) and normal (norm). If \(x\) is log-normal with unit mean and log-variance \(\sigma^2\), then \(L(p)=\Phi\!\bigl((\ln x-(\mu-\sigma^2))/\sigma\bigr)\) and \(p=\Phi\!\bigl((\ln x-\mu)/\sigma\bigr)\). Taking \(\mu=1\), the log-income standard deviation is estimated by averaging the class-by-class values

\[\sigma \;=\; \frac{1}{m-1}\sum_{k=1}^{m-1}\Bigl[\Phi^{-1}(p_k)-\Phi^{-1}\bigl(L(p_k)\bigr)\Bigr],\]15.15

after which \(Q(F)=\exp\!\bigl(\sigma\,\Phi^{-1}(F)\bigr)\) for the log-normal, or \(Q(F)=\sigma\,\Phi^{-1}(F)\) shifted to be non-negative for the normal (Aitchison & Brown 1957; Kolenikov & Shorrocks 2005).

  • \(a\): the first coefficient of the generalised quadratic Lorenz curve
  • \(b\): the second coefficient of the generalised quadratic Lorenz curve
  • \(c\): the third coefficient of the generalised quadratic Lorenz curve
  • \(e\): \(a+b+c+1\)
  • \(m\): \(b^2-4a\)
  • \(n\): \(-2be-4c\)

Generalised quadratic Lorenz curve (gqlc). Assuming \(L(1-L)=a(p^2-L)+b\,L(p-1)+c(p-L)\), the coefficients \(a,b,c\) are obtained by regressing \(L(1-L)\) on \((p^2-L)\), \(L(p-1)\) and \((p-L)\) without an intercept (the last point \((1,1)\) dropping out). The quantile is

\[Q(p) \;=\; -\frac{b}{2}\;-\;\frac{2mp+n}{4\sqrt{\,mp^2+np+e^2\,}}, \qquad e=a+b+c+1,\;\; m=b^2-4a,\;\; n=-2be-4c.\]15.16

The generalised-quadratic form is a least-squares fit, so it need not pass exactly through the tabulated points; on strongly unequal tables it can fit loosely (the Stage-II adjustment then restores the group means).

  • \(\theta\): the scale parameter of the Beta Lorenz curve
  • \(\gamma\): the first shape parameter of the Beta Lorenz curve
  • \(\delta\): the second shape parameter of the Beta Lorenz curve

Beta Lorenz curve (belc). Assuming \(\log(p-L)=\log\theta+\gamma\log p+\delta\log(1-p)\), the parameters are fitted by that regression and the quantile is the derivative of the Kakwani–Podder curve \(L(p)=p-\theta p^\gamma(1-p)^\delta\),

\[Q(p) \;=\; 1-\theta\,p^{\gamma}(1-p)^{\delta}\left[\frac{\gamma}{p}-\frac{\delta}{1-p}\right]\]15.17

(Datt 1998).

  • \(F\): the distribution function of the Singh–Maddala distribution, \(F(x)\)
  • \(f\): the density of the Singh–Maddala distribution, \(f(x)\)
  • \(x\): an income
  • \(a\): the first shape parameter of the Singh–Maddala distribution
  • \(b\): the scale parameter of the Singh–Maddala distribution
  • \(q\): the second shape parameter of the Singh–Maddala distribution

Singh–Maddala (sima). The distribution function is \(F(x)=1-\bigl[1+(x/b)^{a}\bigr]^{-q}\) with density \(f(x)=(aq/b)\bigl(1+(x/b)^{a}\bigr)^{-(q+1)}(x/b)^{a-1}\) and quantile \(Q(p)=b\bigl((1-p)^{-1/q}-1\bigr)^{1/a}\). The parameters \(a,b,q\) are estimated by maximum likelihood over the class mean incomes (Jenkins 2008).

  • \(F\): the vector of the generated percentiles

Uniform (unif). \(Q(F)=F\) — the least informative start, relying entirely on the adjustment. In every form the incomes are finally rescaled to unit mean.

15.10.2.2 Stage II — adjustment to match the aggregated data (optional)

With adjust on (the default) the initial incomes are corrected by the Shorrocks & Wan (2009) two-pass procedure:

  • Adjustment 1 re-maps the incomes, piecewise-linearly through the group means, so that each class recovers its original mean income \(\mu_k\);
  • Adjustment 2 smooths the distribution across the class boundaries.

After the adjustment every form reproduces the table’s group means exactly, so the forms differ only in how they interpolate within each class. ungroup produces a sample, not an estimate, and carries no standard error of its own — the inference comes from the index subsequently applied to the reconstructed micro-data.

16 Benefit analysis

Who gains from public spending on a service — schooling, health, transfers? Benefit incidence analysis places the users, and the money that follows them, on the welfare distribution. bian describes the average benefit as it stands today; imbi estimates the marginal benefit — the share an extra unit of spending would reach — from the way coverage varies across regions.

16.1 Average benefit incidence — bian

  • \(g\): a welfare group
  • \(s_g\): the share of the service’s users found in group \(g\)
  • \(\mathrm{frq}_i\): the number of users of the service in household \(i\)
  • \(\mathrm{sz}_i\): the number of members of household \(i\) eligible for the service
  • \(r_g\): the rate of participation of the eligible in group \(g\)
  • \(u\): the unit subsidy, the public expenditure divided by the number of users
  • \(D\): the public expenditure on the service

How the benefit of an existing public service is distributed across welfare groups.

16.1.1 What is estimated

Rank the population by welfare and split it into quantile groups (quintiles by default, or quartiles / deciles, or the categories of a group variable). For each service — up to six can sit side by side — bian reports, group by group:

  • the share of the service’s users found in group \(g\),

\[s_g \;=\; \frac{\sum_{i\in g} hw_i\,\mathrm{frq}_i}{\sum_i hw_i\,\mathrm{frq}_i},\]16.1

where \(\mathrm{frq}_i\) is the number of users in household \(i\) and \(hw_i\) the sampling weight; the shares sum to one;

  • the rate of participation — take-up among the eligible \(\mathrm{sz}_i\),

\[r_g \;=\; \frac{\sum_{i\in g} hw_i\,\mathrm{frq}_i}{\sum_{i\in g} hw_i\,\mathrm{sz}_i};\]16.2

  • with approach(2), the average benefit in money. Let the unit subsidy be the public expenditure divided by the number of users, \(u = D \big/ \sum_i hw_i\,\mathrm{frq}_i\) (computed within each area when ini() gives an area indicator). The benefit at the level of the eligible is \(u\,r_g\) — it falls with income exactly as participation does — while at the level of the users it is the flat unit subsidy \(u\) each attendee receives. A companion table gives each group-and-sector’s proportion of the total benefit.

A service is pro-poor when a larger share of its benefit reaches the bottom groups. bian is the accounting complement to the Lorenz and concentration tools: it says not just how much inequality there is, but who a given programme serves.

16.1.2 Estimator and inference

The population split uses the cumulative weight share (§2.3.1), so the groups hold equal shares of individuals; every quantity is then an exact ratio of weighted totals. bian is a descriptive table reported to fixed decimals — no standard errors — and each service is ranked by its own eligible weight \(hw_i\,\mathrm{sz}_i\), so the groups are comparable across services.

16.2 Marginal benefit incidence — imbi

  • \(g\): a welfare quintile of a region
  • \(\pi_{kg}\): the participation rate of quintile \(g\) in region \(k\)
  • \(u_i\): the number of users of the service in household \(i\)
  • \(e_i\): the number of members of household \(i\) eligible for the service
  • \(\bar\pi_{k,-g}\): the participation rate of the rest of region \(k\), quintile \(g\) excluded
  • \(\alpha_g\): the intercept of quintile \(g\)
  • \(\beta_g\): the slope of quintile \(g\), how its take-up moves with the region’s coverage
  • \(\varepsilon_{kg}\): the error of quintile \(g\) in region \(k\)
  • \(\mathrm{MB}_g\): the marginal benefit incidence of quintile \(g\)
  • \(\mathrm{MB}\): the marginal benefit incidence
  • \(q\): the number of quantile groups (5 for quintiles)
  • \(\alpha\): the intercepts \(\alpha_g\) of the quintiles
  • \(\beta\): the slopes \(\beta_g\) of the quintiles
  • \(a_1\): the intercept of the first quintile, in the non-linear fit
  • \(a_5\): the intercept of the fifth quintile, in the non-linear fit
  • \(b_1\): the slope of the first quintile, in the non-linear fit
  • \(b_4\): the slope of the fourth quintile, in the non-linear fit
  • \(b_5\): the slope of the fifth quintile, fixed by the adding-up restriction

How an extra unit of public spending would be shared across welfare groups — recovered from the cross-regional variation in coverage (Ajwad & Quentin, 2007).

16.2.1 What is estimated

Average incidence (bian) describes today’s spending; the marginal question is different — as a programme expands, which groups capture the new places? imbi answers it without a panel, using the variation in coverage across regions. Within each region the population is split into welfare quintiles, and for region \(k\) and quintile \(g\) the participation rate (users over eligible, weighted) is

\[\pi_{kg} \;=\; \frac{\sum_{i\in k,g} hw_i\,u_i}{\sum_{i\in k,g} hw_i\,e_i}.\]16.3

Each quintile’s rate is related to the participation of the rest of its region, \(\bar\pi_{k,-g}\) (the same ratio computed over the region excluding quintile \(g\)),

\[\pi_{kg} \;=\; \alpha_g + \beta_g\,\bar\pi_{k,-g} + \varepsilon_{kg}.\]16.4

The slope \(\beta_g\) measures how strongly quintile \(g\)’s take-up moves with the region’s overall coverage: a large \(\beta_g\) means that group captures much of any expansion. The marginal benefit incidence of quintile \(g\) is the monotone transform

\[\mathrm{MB}_g \;=\; \frac{5\,\beta_g}{4+\beta_g}\qquad(\text{general } q\text{: } q\beta_g/(q-1+\beta_g)),\]16.5

and the slopes obey the adding-up restriction \(\sum_{g}\beta_g/(q-1+\beta_g)=1\), which pins down the fifth slope from the other four. Values of \(\mathrm{MB}_g\) above one mark groups that would gain more than an equal share of the extra spending; a schedule that falls with the quintile is a pro-poor expansion.

16.2.2 Estimator and inference

The within-region quintiles use the cut-point convention (Stata’s xtile): the cut points are the welfare values at which the cumulative weight share first reaches \(k/5\), so a household sits one group above every cut point it exceeds. The panel of region × quintile rates is fitted first by a weighted least-squares start regression (weights \(\sum_{i\in k,g} hw_i\)), then by a constrained non-linear regression that imposes the adding-up restriction, so the five \((\alpha_g,\beta_g)\) are identified jointly; the reported \(\alpha\) and \(\beta\) are the non-linear estimates. With drr (default on) both regressions are printed — the weighted-OLS start values and the constrained non-linear fit, the latter with Gauss-Newton standard errors on the free parameters \(a_1..a_5,\,b_1..b_4\) (\(b_5\) being fixed by the restriction). imbi reports the point schedule from a cross-sectional identification, not a design-variance estimate.

The alternative appr(dlle) replaces the parametric slopes by the derivative of a non-parametric regression of the region-and-quintile rate on the regional mean rate, drawn as a curve per quintile through cnpe (with reference lines at the overall participation rate and at \(\mathrm{MB}=1\)).
