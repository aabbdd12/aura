Installation notes

Install, update, remove

Install

Run the installer and choose to install for you alone (no administrator rights) or for all users. AURA appears in the Start menu, and a desktop icon if you ask for one. A double-click on an html log (.hlog) opens it in the AURA Viewer.

Update

Install the new version over the old one, in the same mode as before (for you, or for all users): it replaces it. Your settings, scripts, startup profile and packages, kept in your AURA folder, stay as they are. Help → Check for Updates tells you when a new version is out.

Remove

Use Add or remove programs in Windows' settings. Your AURA folder — settings, scripts, packages — is left in place; delete it yourself if you no longer need it.
