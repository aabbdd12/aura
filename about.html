About

An open workbench for applied research

AURA — Applied Unified Research Analytics — is a command-driven environment for statistics, econometrics and distributive analysis, free and open, built on the Python scientific stack.

The project

Concise commands, an open foundation

AURA's command language is inspired in part by established statistical software — concise syntax, if / in / weight clauses, stored results — but AURA is its own design, computed with the libraries researchers already trust: pandas, NumPy, SciPy, statsmodels, linearmodels and matplotlib.

It brings together the everyday work of applied analysis and complete packages for distributive analysis (DAAP) and price-reform simulation (SUBSIM), with a dialog box for every command and every action written as a command, so that the analysis can be run again.

AURA is written by Dr. Abdelkrim Araar.

How to cite

Using AURA in your work?

A citation helps other researchers find AURA and supports the project. Cite the version you used.

@software{aura2026,
  title  = {AURA: Applied Unified Research Analytics},
  author = {Araar, Abdelkrim},
  year   = {2026},
  note   = {Version 1.6, GPL-3.0-or-later},
  url    = {https://aabbdd12.github.io/aura/}
}

Report a problem

Found a bug, or missing a command?

Open an issue on GitHub: say what you did, what you expected, and what AURA showed — the command, its output, and the version (Help → About).
